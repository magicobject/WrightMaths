# Wright Maths Tuition — deployment notes

## What's in here
Static site: `index.html`, `about.html`, `lessons.html`, `resources.html`, `contact.html`,
`404.html`, plus `css/style.css`, `img/favicon.svg`, `robots.txt`, `sitemap.xml`,
`_headers` and `_redirects`. No build step — this is plain HTML/CSS.

`404.html` is a branded "page not found" page matching the rest of the site. Cloudflare
Pages automatically detects and serves any root-level `404.html` for unmatched routes —
no extra setup needed, just make sure it's uploaded alongside the other files.

`_headers` and `_redirects` are Cloudflare Pages configuration files, read automatically
on deploy (same rule: they must sit at the root of what you upload). `_headers` sets a
few sensible security headers plus long-cache rules for `css/` and `img/`. `_redirects`
is included but currently has no active rules — Cloudflare's automatic 404 handling
covers this site's needs already; it's there ready for later (e.g. forcing `www.`).

## Before you go live
1. Register your chosen domain (see the domain suggestions Claude gave you) and find/replace
   `wrightmaths.uk` throughout the HTML files with your real domain if you pick a
   different name.
2. Update the contact form: `mailto:` forms don't work for everyone (some phones/desktops
   have no default mail client). Once the site is live, consider swapping the form's `action`
   for a free service like Formspree or Cloudflare's own Pages Functions/Turnstile setup so
   messages land reliably — happy to wire this up for you.
3. Double check the DBS wording in `about.html` matches how you want to describe your check
   (e.g. add the certificate number or issue date if you want more transparency).

## Deploy on Cloudflare Pages
1. Log in to the Cloudflare dashboard → **Workers & Pages** → **Create application** → **Pages**.
2. Choose **Upload assets** (simplest, no Git needed) and drag in this whole folder — or
   connect a GitHub repo containing these files if you'd rather deploy via Git pushes.
3. Framework preset: **None**. Build command: none. Output directory: `/` (root).
4. Once deployed, go to your Pages project → **Custom domains** → add your registered domain,
   and follow Cloudflare's instructions to point its DNS (usually already on Cloudflare) at
   the Pages project.
5. Cloudflare issues a free SSL certificate automatically — no extra steps needed.

## After launch — basic local SEO checklist
- Create a free **Google Business Profile** for "Wright Maths Tuition" with category
  "Tutoring service", your service area (Leominster + surrounding towns), and a link to
  the site. This is the single biggest factor in showing up for searches like
  "maths tuition Leominster".
- Get listed on a couple of national tutor directories (e.g. Tutorful, MyTutor, First Tutors)
  — they rank well and usually link back to your own site.
- Ask any early parents/students for a short Google review once you have a Business Profile.
- Keep the Resources page updated occasionally — fresh content is a small but real ranking signal.
