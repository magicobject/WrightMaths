Proof: direct, exhaustion, counterexample

A pattern that works for ten numbers might fail on the eleventh. A proof is an argument that works for every number at once. This page shows you three tools. Proof by deduction uses algebra to cover every case in one go. Proof by exhaustion splits the cases up and checks each one. A counterexample is a single example that shows a claim is false. You will also learn the signs that mathematicians use to join the steps.

Where you will use this: in every “show that” and “prove that” question, in any topic. It comes back in Proof by contradiction, and in the proof of the sum of an arithmetic series. It also helps you decide whether a claim is worth proving or worth testing.

1. What a proof is

A {term:statement} is a sentence that is true or false. “The sum of two even numbers is even” is a statement about every pair of even numbers. You could check ten pairs, or a thousand, and still not know it holds for the next pair.

A {term:proof} is a chain of steps that shows a statement is true in every possible case. Each step follows from the one before. Checking examples is not a proof. It only gives you evidence.

Key idea: a proof has three parts.

  • Assumptions. What you start from. These are the facts you are given and the meanings of the words. For example, an even number is 2 times an integer.
  • Steps. Each line follows from the line before. You can give the reason for each one.
  • Conclusion. A sentence that says what you have shown, in the words of the question.

Four signs help you write the steps. Learn what each one says.

  • The sign ⇒ means {term:implies|implies}. “A ⇒ B” reads “if A is true, then B is true”.
  • The sign ⇐ points the other way. “A ⇐ B” reads “A is true if B is true”.
  • The sign ⇔ means {term:if-and-only-if|if and only if}. It says that both directions hold, so A and B are either both true or both false.
  • The sign ∴ means {term:therefore|therefore}. It joins a reason to the result that follows.

The {term:converse} of “if A, then B” is “if B, then A”. A true statement can have a false converse. So you must check each direction on its own.

Worked example: the three parts of a proof

Prove that the sum of two even numbers is even.

  1. Assumption. Let the two even numbers be {m:2a} and {m:2b}, where a and b are integers. An even number is 2 times an integer.
  2. Step. Add them: {m:2a+2b=2(a+b)}.
  3. Step. The sum {m:a+b} of two integers is an integer.
  4. Conclusion. The sum is 2 times an integer, so it is even. ∴ the sum of two even numbers is even.

Worked example: one direction only

Is it correct to write {m:x=4} ⇒ {m:x^2=16}? Is it correct to write {m:x=4} ⇐ {m:x^2=16}?

  1. If {m:x=4}, then {m:x^2=4^2=16}. So {m:x=4} ⇒ {m:x^2=16} is true.
  2. Now try the other direction. If {m:x^2=16}, then x could be 4 or {m:-4}. The value {m:x=-4} makes {m:x^2=16} true and {m:x=4} false.
  3. So {m:x=4} ⇐ {m:x^2=16} is false.
  4. Only one direction holds, so you must not write ⇔.

Worked example: both directions

  2. Divide both sides by 3: {m:3x=12} ⇔ {m:x=4}. Multiplying by 3 undoes it.
  3. Every step can be undone, so ⇔ is correct. The equation {m:3x-1=11} is true if and only if {m:x=4}.

2. The language of sets

Proofs often talk about a collection of numbers. A set is a collection of things, and each thing in it is an element. {term:set-notation|Set notation} writes a set with curly brackets. You can list the elements, such as {1, 2, 3}. Or you can give a rule, such as {{m:x}: {m:x>2}}. The colon reads “such that”. Order and repeats do not matter.

Key idea: set signs and intervals.

  • The sign ∈ means {term:element-of|“is an element of”}. Write {m:3} ∈ {1, 2, 3}. The sign ∉ means “is not an element of”.
  • The sign ∪ is the {term:union|union}. A ∪ B holds everything that is in A or in B or in both.
  • The sign ∩ is the {term:intersection|intersection}. A ∩ B holds only what is in both A and B.
  • The sign ∅ is the {term:empty-set|empty set}. It is the set with no elements.
  • An {term:interval-notation|interval} such as [−1, 4) is also a set: all the numbers from {m:-1} up to, but not including, 4.

Worked example: an equation and its solution set

Join {m:x^2=4} and the set {{m:-2}, 2} with the right sign.

  1. If {m:x^2=4}, then {m:x=2} or {m:x=-2}. So x is an element of {{m:-2}, 2}.
  2. If x is an element of {{m:-2}, 2}, then {m:x^2=4}, because {m:(-2)^2=4} and {m:2^2=4}.
  3. Both directions hold, so {m:x^2=4} ⇔ {m:x} ∈ {{m:-2}, 2}.

Compare {m:x=2} ⇒ {m:x} ∈ {{m:-2}, 2}. This one is true, but the reverse is false: {m:x=-2} is in the set and is not 2. So you cannot write ⇔ there.

Worked example: union and intersection

3. Proof by deduction with integers

{term:proof-by-deduction|Proof by deduction} starts from known facts and uses algebra to reach the result. To prove something about all {term:integer|integers} of one kind, write them with letters.

Key idea: write each kind of number with a letter.

  • An {term:even-number|even number} is {m:2n}. An {term:odd-number|odd number} is {m:2n+1}. Here n is any integer.
  • {term:consecutive-integers|Consecutive integers} are {m:n}, {m:n+1}, {m:n+2}, and so on.
  • A {term:multiple} of 3 is {m:3n}. A multiple of 8 is {m:8n}.
  • Use a different letter for each number that can vary independently. Two even numbers are {m:2a} and {m:2b}, not {m:2n} and {m:2n}.

At the end, show that your result has the form you need. For “is even”, write it as 2 times an integer. For “is a multiple of 3”, write it as 3 times an integer. Then say so in a sentence.

Worked example: two odd numbers

Prove that the sum of two odd numbers is even.

  1. Let the numbers be {m:2a+1} and {m:2b+1}, where a and b are integers. They use different letters because they can be different numbers.
  2. Add them: {m:(2a+1)+(2b+1)=2(a+b+1)}.
  3. The number {m:a+b+1} is an integer, so the sum is 2 times an integer.
  4. Conclusion: the sum of two odd numbers is even.

Worked example: factorise first

Prove that {m:n^2-n} is even for every integer n.

  1. Factorise: {m:n^2-n=n(n-1)}.
  2. The numbers n and {m:n-1} are consecutive integers. Consecutive integers alternate between even and odd. So one of them is even.
  3. An even number times any integer is even. Write the even factor as 2k. Then the product is {m:2k*m=2km}, which is 2 times an integer.
  4. Conclusion: {m:n^2-n} is even for every integer n. Check with {m:n=6}: {m:6^2-6=30}, which is even.

Worked example: consecutive integers

Prove that the sum of any three consecutive integers is a multiple of 3.

  1. Let the integers be n, {m:n+1} and {m:n+2}.
  2. Add them: {m:n+(n+1)+(n+2)=3n+3}.
  3. Factorise: {m:3n+3=3(n+1)}.
  4. The number {m:n+1} is an integer, so the sum is 3 times an integer. It is a multiple of 3.

Worked example: squares

Prove that the square of an odd number is odd.

  1. Let the odd number be {m:2n+1}.
  2. Square it: {m:(2n+1)^2=4n^2+4n+1}.
  3. Take out a factor of 2 from the first two terms: {m:4n^2+4n+1=2(2n^2+2n)+1}.
  4. The number {m:2n^2+2n} is an integer, so the result is 2 times an integer plus 1. It is odd.

Worked example: a harder form

Prove that {m:(2n+1)^2-1} is a multiple of 8 for every integer n.

  1. Expand and simplify: {m:(2n+1)^2-1=4n(n+1)}.
  2. The numbers n and {m:n+1} are consecutive, so one of them is even. So {m:n(n+1)=2k} for some integer k.
  3. Then {m:4n(n+1)=4*2k=8k}.
  4. Conclusion: {m:(2n+1)^2-1} is a multiple of 8. Check with {m:n=3}: {m:7^2-1=48}, and {m:48=8*6}.

4. Proving identities and that an expression is always positive

Many proofs are about algebra, not about integers. The command words {term:show-that|show that} mean you must write every step. When you show that two expressions are equal for every value of the letters, you prove an {term:identity-sign|identity}. Start with one side. Change it step by step until it equals the other side. Do not work on both sides at once.

To show that an expression is always positive, use {term:completing-the-square|completing the square}. It writes the expression as a square plus a number. A square is never negative, so the expression is at least that number. The full method is in Quadratics.

Key idea: a square is never negative.

  • For every real number x, {m:(x-p)^2>=0}. It equals 0 only when {m:x=p}.
  • So {m:(x-p)^2+q} is at least q. If q is positive, the expression is always positive.
  • For a negative x squared term, write {m:-(x-p)^2+q}. It is at most q. If q is negative, the expression is always negative.

Worked example: an identity

Show that {m:(n+3)^2-(n-3)^2} is equal to {m:12n} for every n.

5. Proof by exhaustion

{term:proof-by-exhaustion|Proof by exhaustion} splits every possibility into a small number of cases, then checks each case. The cases must cover everything, with no gaps. There are two kinds.

  • A short list of values. For example, all the numbers from 91 to 99. You check each one.
  • Cases that cover every integer. For example, every integer is {m:3k}, {m:3k+1} or {m:3k+2}, where k is an integer. This gives three cases, and it covers infinitely many integers.

The second kind works by the remainder on division. Dividing by 3 leaves remainder 0, 1 or 2. So every integer fits exactly one of the three forms.

Key idea: exhaustion works when you can list the cases and each one can be checked.

  • Say how you split the cases, and why they cover every possibility.
  • Check every case. Do not stop at the ones that work.
  • Finish with a sentence that says the statement is true in all cases.

6. Disproof by counterexample

A statement that says “for every number” is false if one number breaks it. That number is a {term:counterexample}. One counterexample is enough to disprove a statement. A thousand examples that work do not prove it.

Key idea: a counterexample must do two things.

  • It must satisfy the conditions of the claim. If the claim is about integers, a counterexample must be an integer.
  • It must make the claim false. Show the working that proves this.

Flip it: always true, or one example that is false

A claim about every number has two possible outcomes. It is always true, and you need a proof. Or it is false, and you need one counterexample. The two jobs are opposites. Do not try to do both at once.

Forwards

Backwards

Disproving a claim. Find one case that satisfies the conditions and breaks the claim. Show the working.

How do you tell which job you have? Test a few small values first. If one fails, you have a counterexample and you can stop. If they all work, look for a reason. A reason might become a proof.

Why it works

  • Letters cover every case. When you write an even number as {m:2n}, the letter n stands for every integer at once. So one calculation with n is a calculation for all of them.
  • One counterexample is enough. A statement that says “every” fails the moment one case fails. This is why a counterexample is shorter than a proof.
  • Examples are not a proof. A list of examples only tests the cases you chose. The expression {m:n^2+n+41} gives a prime for 39 values in a row, then fails.
  • Exhaustion needs cases with no gaps. Every integer leaves remainder 0, 1 or 2 when divided by 3. So the three forms {m:3k}, {m:3k+1} and {m:3k+2} cover every integer.
  • A square is never negative. Multiplying two numbers with the same sign gives a positive number. Zero times zero is zero. This is why {m:(x-3)^2+1} is at least 1.
  • Only one direction. Squaring both sides of an equation loses information, because {m:3} and {m:-3} give the same square. So {m:x=3} ⇒ {m:x^2=9}, but the reverse fails.

Common traps

  • Treating a list of examples as a proof.
  • Using the same letter for two numbers that can differ, such as {m:2n} and {m:2n} for two even numbers.
  • Writing ⇔ when only ⇒ holds, especially after squaring both sides.
  • Leaving a gap in a proof by exhaustion, such as missing the case {m:3k+2}.
  • Using a counterexample that does not satisfy the conditions of the claim, such as a fraction when the claim is about integers.
  • Giving a counterexample without the working that shows it breaks the claim.
  • Working on both sides of an identity at once. Start with one side, and change it until it equals the other.
  • Completing the square with the wrong number at the end. Expand your answer to check it.
  • Stopping a proof without a conclusion. Say what you have shown, in the words of the question.
  • Assuming the converse of a true statement is true.
