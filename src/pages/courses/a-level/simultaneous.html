Simultaneous equations

Some questions give you two equations that must both be true. You find the numbers that fit both. This page shows two methods for straight-line equations. Then it solves a straight line together with a curve. You will see each answer as a point where two graphs meet. You will also learn to count the points without solving.

Where you will use this: in Circles, to find where a line meets a circle. Also in Differentiation, to find where a tangent meets a curve. You use it too when you build an equation from known points.

1. Two linear equations

{term:simultaneous-equations|Simultaneous equations} are two or more equations that must be true at the same time. You find the values of the letters that fit all of them.

A {term:linear-equation|linear equation} has each letter only to the power 1. No two letters are multiplied together. So {m:3x+2y=12} is linear. {m:x^2+y=3} is not linear, and neither is {m:xy=4}.

The graph of a linear equation in x and y is a straight line. Two straight lines usually cross at one point. This is the {term:point-of-intersection|point of intersection}. It is on both lines, so its x and y fit both equations.

Key idea: the solution is the point where the two lines cross. You can find it without drawing the lines. There are two methods.

Method 1: substitution

{term:substitution} means replacing a letter by an expression that is equal to it. Use it when one equation has a letter on its own.

Key idea: to solve by substitution, follow these steps. First, write one letter on its own in one equation. Second, replace that letter in the other equation. Put the expression in brackets. Third, solve for the one letter that is left. Fourth, put the answer into the simpler equation to find the other letter. Last, check the pair in both equations.

Worked example: substitution

Solve {m:y=2x-1} and {m:3x+2y=12}.

  1. The first equation has y on its own: {m:y=2x-1}.
  2. Replace y in the second equation by {m:(2x-1)}: {m:3x+2(2x-1)=12}.
  3. Expand the bracket: {m:3x+4x-2=12}. So {m:7x=14} and {m:x=2}.
  4. Put {m:x=2} into {m:y=2x-1}. This gives {m:y=2*2-1=3}.
  5. Check in the second equation: {m:3*2+2*3=12}. This is true.

The solution is {m:x=2} and {m:y=3}. As a point, it is {m:(2, 3)}. This is the crossing point in the figure.

Often no letter is on its own. Then rearrange one equation first. Choose the letter with no number in front of it, so that you avoid fractions.

Worked example: rearrange first

  2. Replace x in the second equation by {m:(7-2y)}: {m:3(7-2y)-y=7}.
  3. Expand: {m:21-6y-y=7}, so {m:21-7y=7}. Then {m:-7y=-14} and {m:y=2}.
  4. Put {m:y=2} into {m:x=7-2y}. This gives {m:x=7-4=3}.
  5. Check in the second equation: {m:3*3-2=7}. This is true.

The solution is {m:x=3} and {m:y=2}.

Method 2: elimination

{term:elimination} removes one letter by adding or subtracting the two equations. Use it when both equations look like {m:ax+by=c}. Here a, b and c are numbers.

Key idea: to eliminate a letter, make its {term:coefficient|coefficients} the same size in both equations. The coefficient is the number in front of the letter. If the two terms have the same sign, subtract the equations. If they have opposite signs, add the equations. Then solve for the letter that is left.

Worked example: add the equations

Solve {m:3x+2y=11} and {m:5x-2y=13}.

  2. Add the left sides, and add the right sides: {m:8x=24}. So {m:x=3}.
  3. Put {m:x=3} into the first equation: {m:9+2y=11}. So {m:y=1}.
  4. Check in the second equation: {m:5*3-2*1=13}. This is true.

The solution is {m:x=3} and {m:y=1}.

Worked example: subtract the equations

  2. Subtract the second equation from the first. Subtract the right sides in the same order: {m:4x=20-12=8}. So {m:x=2}.
  3. Put {m:x=2} into the first equation: {m:14+2y=20}. So {m:y=3}.
  4. Check in the second equation: {m:3*2+2*3=12}. This is true.

When there is not one solution

Two lines need not cross at one point. They can be parallel, or they can be the same line.

Worked example: no solution

  2. Subtract {m:2x} from both sides: {m:1=4}.
  3. This is never true, whatever x is.

Suppose you reach a statement that is always true, such as {m:0=0}. Then the two equations describe the same line. Every point on the line is a solution. There are infinitely many solutions. For example, {m:4x-2y=6} is {m:2x-y=3} with every term doubled.

Worked example: infinitely many solutions

Solve {m:x+2y=3} and {m:2x+4y=6}.

  1. Make x the subject of the first equation: {m:x=3-2y}.
  2. Replace x in the second equation: {m:2(3-2y)+4y=6}.
  3. Expand: {m:6-4y+4y=6}, so {m:6=6}.
  4. This is always true, whatever y is.

There are infinitely many solutions. The second equation is the first doubled. So both are the same line. Any y gives a solution, such as {m:(3, 0)} and {m:(1, 1)}.

2. A line and a quadratic

Now one equation is {term:linear-equation|linear} and the other is a {term:quadratic|quadratic}. Here a quadratic equation means the highest total power of the letters is 2. So it may contain {m:x^2}, {m:y^2} or {m:xy}. Its graph is a curve. The solutions are the points where the line meets the curve.

{term:elimination|Elimination} does not work well here. Adding the equations leaves a squared term behind. Use {term:substitution} instead.

Key idea: to solve a line and a quadratic, start with the linear equation. Write one letter on its own. Replace that letter in the quadratic. Rearrange to {m:ax^2+bx+c=0} and solve. Then use the linear equation to find the other letter for each solution. Write each answer as a pair.

Worked example: a line and a parabola

Solve {m:y=x^2-4x+3} and {m:y=x-1}.

  1. Both equations give y. So the two expressions for y are equal: {m:x^2-4x+3=x-1}.
  2. Move everything to one side: {m:x^2-5x+4=0}.
  3. Factorise: {m:(x-1)(x-4)=0}. So {m:x=1} or {m:x=4}.
  4. Find y from the line {m:y=x-1}. {m:x=1} gives {m:y=0}. {m:x=4} gives {m:y=3}.
  5. Check in the curve: {m:1-4+3=0} and {m:16-16+3=3}. Both are true.

The solutions are {m:x=1, y=0} and {m:x=4, y=3}. As points, they are {m:(1, 0)} and {m:(4, 3)}.

Use the linear equation to find y. It gives one y for each x. A circle can give two y values for one x. Only one of them is on the line.

Why it works

  • Solutions are meeting points. A point is on a graph when its coordinates fit the graph’s equation. So a point is on both graphs exactly when its coordinates fit both equations. That is what a solution of the pair is.
  • Substitution. Equal things can be swapped for each other. So replacing y by the expression that equals y keeps every solution.
  • Elimination. Adding two true equations gives a true equation. You add equal amounts to equal amounts. Multiplying both sides by a number that is not zero also keeps it true. Multiplying by 0 would lose information.
  • No solution or infinitely many. Lines with the same gradient and different y-intercepts never meet. The equations contradict each other. Lines with the same gradient and the same y-intercept are the same line. Every point on it works.
  • A line and a quadratic. Replacing y turns the pair into one quadratic in x. Its solutions are the x-coordinates of the common points. The line then gives exactly one y for each x.
  • The discriminant. The discriminant counts the solutions of the quadratic: two, one repeated, or none. Each solution is one common point. A repeated solution means the line touches the curve without crossing it.
  • Working backwards. A quadratic with solutions p and q is {m:(x-p)(x-q)}. So known meeting points give the factors, and the factors give the unknown numbers.

Common traps

  • Stopping after the first letter. A solution needs both x and y.
  • Subtracting the left sides but adding the right sides. Do the same to both sides.
  • Forgetting that subtracting a negative term adds. {m:3x-(-2x)} is {m:5x}.
  • Multiplying only the left side of an equation. Multiply the number on the right too.
  • Dropping brackets when you substitute. {m:3x+2(2x-1)} is {m:7x-2}, not {m:3x+4x-1}.
  • Writing {m:(1-x)^2} as {m:1-x^2}. It is {m:1-2x+x^2}.
  • Using elimination on a line and a curve. Use substitution.
  • Finding y from the curve, or from the wrong x. Use the linear equation, and keep each x with its own y.
  • Dividing both sides by x in {m:x^2=5x}. The value of x could be 0, so you lose the solution {m:x=0}. Factorise instead.
  • Thinking a discriminant of 0 means no solutions. It means exactly one, so the line is a tangent.
  • Giving the pair as (y, x). Coordinates always have x first.
