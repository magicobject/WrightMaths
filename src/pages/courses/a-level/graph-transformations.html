Transformations of graphs

A transformation changes a graph in a regular way. It moves the graph, stretches it or flips it. Each change to the equation does one thing to the graph. This page shows you which change does what. You find where a point goes, you write the equation of the new graph, and you sketch it. You meet the graph of {m:y=frac(a, x+b)+c}, which is the graph of {m:frac(a, x)} moved. Then you use the same rules on trigonometric and exponential graphs.

Where you will use this: in Functions in Year 2, where the inverse of a function is a reflection. It also leads on to Differentiation from first principles. Any question that says “sketch the graph of {m:y=f(x+2)}” or “describe the transformation” uses the rules on this page.

1. Translating a graph: f(x) + a and f(x + a)

The graph of {m:y=f(x)} shows every point {m:(x, y)} where y is the output of the {term:function} f for the input x. To transform the graph, you change the equation. A {term:translation-of-graph|translation} slides the whole graph. It does not turn it or change its size.

Here is the graph that the cubic examples on this page use. It is {m:y=f(x)}, where {m:f(x)=(x+1)(x-1)(x-3)}.

First add a number outside the function: {m:y=f(x)+3}. Every y-value is 3 bigger. So every point goes up 3, and the whole graph moves up 3.

Now add a number inside, next to x: {m:y=f(x+1)}. The number changes the input. To get the same output as before, you need an input that is 1 smaller. So every point goes 1 to the left. A number inside the bracket moves the graph the opposite way to what you might expect.

Check it with a point. The point {m:(1, 0)} is on {m:y=f(x)}, because {m:f(1)=0}. On {m:y=f(x+1)}, the input {m:x=0} gives {m:f(0+1)=f(1)=0}. So the point {m:(0, 0)} is on the new graph. The point moved from {m:x=1} to {m:x=0}, which is 1 to the left.

Key idea: a number added to a function moves the graph. It does not turn it or change its size.

  • {m:y=f(x)+a} moves the graph up by a. If a is negative, it moves the graph down.
  • {m:y=f(x+a)} moves the graph left by a. If a is negative, it moves the graph right.
  • A number outside the bracket changes the y-values. A number inside changes the x-values, and it works the opposite way.
  • The point {m:(p, q)} on {m:y=f(x)} goes to {m:(p, q+a)} on {m:y=f(x)+a}. It goes to {m:(p-a, q)} on {m:y=f(x+a)}.

2. Stretching a graph: af(x) and f(ax)

A {term:stretch-of-graph|stretch} makes a graph taller, shorter, wider or narrower. It works in one direction only. The size of a stretch is its {term:scale-factor|scale factor}: the number that lengths are multiplied by.

Multiply the whole function by a number: {m:y=2f(x)}. Every y-value is doubled. The point {m:(p, q)} goes to {m:(p, 2q)}. This is a stretch in the y-direction with scale factor 2. A point on the x-axis has {m:q=0}, and {m:2*0=0}, so the crossing points of the x-axis do not move. A point that does not move is an {term:invariant-point|invariant point}.

Now multiply x by a number inside the bracket: {m:y=f(2x)}. To get the old output you need an input that is half as big. So every x-coordinate is halved. The point {m:(p, q)} goes to {m:(frac(p, 2), q)}. This is a stretch in the x-direction with scale factor {m:frac(1, 2)}. The graph is squashed towards the y-axis. A point on the y-axis has {m:p=0}, so the y-intercept does not move.

Key idea: a number multiplying the function stretches the graph up and down. A number multiplying x stretches it left and right, and it works the opposite way.

  • {m:y=a*f(x)} is a stretch in the y-direction with scale factor a. The point {m:(p, q)} goes to {m:(p, a*q)}. The roots do not move.
  • {m:y=f(a*x)} is a stretch in the x-direction with scale factor {m:frac(1, a)}. The point {m:(p, q)} goes to {m:(frac(p, a), q)}. The y-intercept does not move.
  • If a is between 0 and 1, {m:a*f(x)} squashes the graph down, and {m:f(a*x)} stretches it wider.

  2. For {m:y=f(2x)}, divide the x-coordinate by 2: {m:4/2=2}. The y-coordinate stays. The point is {m:(2, 6)}.

3. Reflecting a graph: -f(x) and f(-x)

A {term:reflection-of-graph|reflection} flips the graph over a line, like a mirror. Two reflections matter here: in the x-axis and in the y-axis.

Put a minus sign outside: {m:y=-f(x)}. Every y-value changes sign. The point {m:(p, q)} goes to {m:(p, -q)}. Points above the x-axis go below it, and points below go above. This is the reflection in the x-axis. The crossing points of the x-axis have {m:q=0}, and the opposite of 0 is 0, so they do not move.

Put a minus sign inside: {m:y=f(-x)}. To get the old output you need the opposite input. So every x-coordinate changes sign. The point {m:(p, q)} goes to {m:(-p, q)}. This is the reflection in the y-axis. The y-intercept does not move.

Key idea: a minus sign outside flips the graph up and down. A minus sign inside flips it left and right.

  • {m:y=-f(x)} is the reflection of {m:y=f(x)} in the x-axis. The point {m:(p, q)} goes to {m:(p, -q)}. The roots do not move.
  • {m:y=f(-x)} is the reflection of {m:y=f(x)} in the y-axis. The point {m:(p, q)} goes to {m:(-p, q)}. The y-intercept does not move.
  • A point that is on the line of reflection is an invariant point.

Flip it: from the change to the new graph, and back again

So far you have started with a graph and worked out what a change does to it. Now go the other way. Start with the old graph and the new graph, and find the change.

Forwards

From a change to a point. Solve the inside of the bracket for the new x-coordinate. Put the old y-coordinate through the outside steps for the new y-coordinate.

Backwards

From two matching points to the change. The x-coordinates give the numbers inside the bracket. The y-coordinates give the numbers outside it.

Why it works

  • The graph is every pair (x, y) with y = f(x). Changing the equation changes which pairs are on the graph. Every rule on this page comes from asking which pairs satisfy the new equation.
  • A number outside changes y directly. In {m:y=f(x)+3}, the output is 3 more than before for the same x. So every point goes up 3. In {m:y=2f(x)} every output is doubled, and in {m:y=-f(x)} every output changes sign.
  • A number inside changes the input, so it works in reverse. In {m:y=f(x+3)}, the point that gave the output f(0) used to be at {m:x=0}. Now it needs {m:x+3=0}, so it is at {m:x=-3}. The inside rule always undoes the number: add becomes subtract, multiply becomes divide.
  • Roots stay under a stretch or reflection in the y-direction. A root has {m:y=0}, and {m:a*0=0} and {m:-0=0}. In the same way, the y-intercept stays under a change that only touches x, because {m:a*0=0}.
  • The asymptotes move with the graph. A translation moves every point, and the asymptotes are lines that the points get close to. So the asymptotes of {m:frac(a, x)} move by the same amounts as the curve: {m:x=0} moves to {m:x=-b} and {m:y=0} moves to {m:y=c}.
  • The order matters. A reflection or a stretch multiplies the size of everything before it, including an earlier translation. So moving up 3 and then reflecting is not the same as reflecting and then moving up 3.

Common traps

  • Moving {m:f(x+3)} to the right. A number inside the bracket moves the graph the opposite way: it moves left.
  • Treating {m:f(2x)} as a stretch with scale factor 2. The scale factor is {m:frac(1, 2)}: each x-coordinate is halved.
  • Changing the x-coordinate for {m:2f(x)}. The 2 is outside, so it changes the y-coordinate.
  • Writing {m:f(2x)} for {m:x^2-5} as {m:2x^2-5}. Replace x by {m:2x} and square it: {m:(2x)^2=4x^2}.
  • Forgetting that {m:-f(x)} changes every term, including the constant: {m:-(x^2+3)=-x^2-3}.
  • Reading the asymptote of {m:frac(3, x+2)} as {m:x=2}. It is {m:x=-2}, where the bottom is 0.
  • Treating the number added at the end as the vertical asymptote. In {m:frac(a, x+b)+c} it gives the horizontal asymptote {m:y=c}.
  • Breaking a bracket like {m:f(2x-4)} into a move of 4. Take out the 2 first: {m:f(2(x-2))} moves 2.
  • Drawing a branch across an asymptote, or forgetting to label both asymptotes with their equations.
  • Giving a point as (y, x). A point is written with x first.
