Vectors in two dimensions

A vector is a journey: how far across and how far up or down. It is also an arrow: a length and a direction. This page shows you both views and how to move between them. You will write vectors as columns and in i, j notation. You will add and subtract them, find their magnitude and direction, and use position vectors. Then you will use vectors to prove that lines are parallel, that points are collinear and that a point divides a line in a given ratio.

Where you will use this: in Vectors in three dimensions, which adds a third direction to everything here. It also helps in Straight lines, because the vector between two points gives the gradient and the distance. Any geometry question that says “prove” or “show that” can use a vector proof.

1. Vectors and column vectors

A {term:scalar} is a number with size only. A {term:vector} has a size and a direction. You draw a vector as an arrow. The length of the arrow shows the size, and the arrow points the way.

Where you draw the arrow does not matter. Two arrows with the same length and the same direction are the same vector.

A {term:column-vector|column vector} writes the journey as two numbers in brackets. The top number is the move across. The bottom number is the move up. A negative number means left or down. These two numbers are the {term:component|components} of the vector.

Key idea: a vector is a journey. It says how to get there, not where you start.

  • {m:col(4, -2)} means 4 across to the right and 2 down.
  • The vector does not change when you move the arrow to a new starting point.
  • To find where a journey ends, add the vector to the starting point.

Worked example: reading a vector from an arrow

Write the vector a as a column vector.

  1. The arrow goes from the point {m:(1, 4)} to the point {m:(5, 2)}.
  2. Across: {m:5-1=4}. The arrow goes to the right, so the top number is {m:4}.
  3. Up or down: {m:2-4=-2}. The arrow goes down, so the bottom number is {m:-2}.
  4. So a = {m:col(4, -2)}.

Worked example: where does a journey end?

  2. Add the up move to the y-coordinate: {m:-1+4=3}.
  3. The point finishes at {m:(-1, 3)}.

There is a second way to write a vector. The vector {m:col(1, 0)} is called i. It goes 1 across. The vector {m:col(0, 1)} is called j. It goes 1 up. This is {term:i-j-notation|i and j notation}. Every vector in two dimensions is some number of i plus some number of j.

Key idea: the number in front of i is the top of the column. The number in front of j is the bottom.

{m:col(3, -2)} = 3i − 2j. Do not leave out the letters: write 3i − 2j, not 3 − 2.

The {term:negative-vector|negative of a vector} has the same length and the opposite direction. You change the sign of both components. If a = {m:col(4, -2)}, then −a = {m:col(-4, 2)}.

2. Adding, subtracting and multiplying vectors

To add two vectors, add their components. Add the tops, then add the bottoms. Drawn as arrows, this is the {term:vector-addition|triangle law}. Start the second arrow at the head of the first. The sum goes from the start of the first to the end of the second. The sum is also called the {term:resultant}.

If both vectors start at the same point, use the {term:parallelogram-law|parallelogram law}. Complete the parallelogram. The diagonal from the common point is the sum.

Worked example: adding

Find a + b when a = {m:col(3, 1)} and b = {m:col(2, 3)}.

  1. Add the tops: {m:3+2=5}.
  2. Add the bottoms: {m:1+3=4}.
  3. So a + b = {m:col(5, 4)}. This is the dashed arrow in the figure above.

Worked example: adding in i, j notation

Find a + b when a = 3i + 2j and b = −i + 4j.

  1. Add the i parts: {m:3+(-1)=2}.
  2. Add the j parts: {m:2+4=6}.
  3. So a + b = 2i + 6j.

To subtract a vector, take away its components. This is the same as adding the negative of the vector. {term:vector-subtraction|Subtracting} follows the same order as numbers: a − b means start with a.

Worked example: subtracting

Find a − b when a = {m:col(6, 1)} and b = {m:col(2, -3)}.

  1. Subtract the tops: {m:6-2=4}.
  2. Subtract the bottoms: {m:1-(-3)=4}. Subtracting {m:-3} adds 3.
  3. So a − b = {m:col(4, 4)}.

A {term:scalar-multiple|scalar multiple} is a vector times a number. Multiply every component by the number. A positive number changes the length and keeps the direction. A negative number also reverses the direction.

Key idea: two vectors are {term:parallel-vectors|parallel} when one is a scalar multiple of the other. The components must be in the same ratio.

If b = ka, the vectors are parallel. If k is negative, they point in opposite directions.

Worked example: are they parallel?

  3. So {m:col(-6, 9)} = {m:-3} times {m:col(2, -3)}. The vectors are parallel, and they point in opposite directions.

3. Magnitude, unit vectors and direction

The {term:magnitude} of a vector is its length. Write it |a|. The components of a vector are the two short sides of a right-angled triangle. The vector is the longest side. So you use Pythagoras’ theorem.

Key idea: if a = {m:col(x, y)}, then |a| = {m:sqrt(x^2+y^2)}.

The signs disappear when you square. A magnitude is never negative.

Worked example: an exact magnitude

Find the exact magnitude of a = {m:col(5, 2)}. Then give it to 3 significant figures.

  1. |a| = {m:sqrt(5^2+2^2)=sqrt(25+4)=sqrt(29)}.
  2. {m:sqrt(29)~=5.385164}, so to 3 significant figures it is 5.39.

Worked example: a negative component

Find |a| when a = {m:col(-4, 3)}.

  1. Square each component: {m:(-4)^2=16} and {m:3^2=9}. The square of a negative number is positive.
  2. |a| = {m:sqrt(16+9)=sqrt(25)=5}.

Worked example: a root that simplifies

  1. |2i − 6j| = {m:sqrt(2^2+(-6)^2)=sqrt(4+36)=sqrt(40)}.
  2. {m:sqrt(40)=sqrt(4)*sqrt(10)=2sqrt(10)}. To 3 significant figures this is 6.32.

A {term:unit-vector} has magnitude 1. To find the unit vector in the direction of a, divide a by its magnitude. It is written a with a small hat, “a hat”.

Key idea: the unit vector in the direction of a is a divided by |a|. Any vector is its magnitude times its unit vector.

Worked example: a unit vector

4. Position vectors and the vector between two points

A {term:position-vector|position vector} goes from the origin O to a point. Its components are the coordinates of the point. The point A at {m:(2, 4)} has position vector {m:vec(OA)} = a = {m:col(2, 4)}.

Now take two points, A and B. To go from A to B, you can go back to the origin and then out to B. That is the journey {m:vec(AO)} followed by {m:vec(OB)}. The result is the {term:displacement}.

Key idea: {m:vec(AB)} = b − a. It is the end minus the start.

5. Geometric proof with vectors

A {term:vector-proof|vector proof} uses vectors to show a fact about a shape. The method has three steps.

Key idea: choose two vectors as your base, such as a and b. Write every other vector in the diagram using only those two. Then compare.

  • To show two lines are parallel, show that one vector is a scalar multiple of the other.
  • To show three points are {term:collinear}, show that two vectors between them are parallel and that they share a point.
  • To find a ratio of lengths, use the scale factor between the two vectors.

To write a vector, find a path from its start to its end along vectors you know. Going along a known vector adds it. Going against it subtracts it.

Why it works

  • A vector is a journey. It records how far across and how far up, with no starting point. That is why two arrows of the same length and direction are the same vector.
  • Adding follows the journey. Going along a and then along b is the same as one journey, the sum. Adding components does the same thing to the across parts and the up parts.
  • End minus start. The journey from A to B can go back to the origin and out again: {m:vec(AO)} then {m:vec(OB)}. That is −a + b, so {m:vec(AB)} = b − a.
  • Magnitude is Pythagoras. The across part and the up part meet at a right angle. The vector is the longest side of the triangle.
  • A unit vector separates direction from size. Dividing by the magnitude leaves length 1 and the same direction. Multiplying by a number then sets any length you like.
  • Parallel means a scalar multiple. A scalar multiple keeps the direction (or reverses it) and changes only the length. Sharing a point as well puts both vectors on one line.
  • A ratio is a fraction of a journey. AP : PB = m : n puts P a fraction {m:frac(m, m+n)} of the way along AB. Walk that fraction of {m:vec(AB)} from A.

Common traps

  • Finding {m:vec(AB)} as start minus end. It is end minus start.
  • Giving the across number and the up number in the wrong order. The across number is on top.
  • Forgetting to change the sign of both components of a negative vector.
  • Adding magnitudes: |a + b| is not |a| + |b|, unless the vectors point the same way.
  • Subtracting the squares of the components when finding a magnitude. Add them.
  • Giving the acute angle as the direction without checking which way the vector points.
  • Dividing by the sum of the components, instead of by the magnitude, to make a unit vector.
  • Putting the ratio the wrong way round. In AP : PB = 1 : 3, P is nearer to A.
  • Claiming points are collinear because two vectors are parallel, without saying they share a point.
  • Leaving out the vector letters: write 3i − 2j, not 3 − 2.
