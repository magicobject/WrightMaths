Inequalities

An equation says two things are equal. An inequality says one is bigger than the other. Its answer is usually a whole range of values, not one number. This page shows you how to solve linear and quadratic inequalities. You will write answers on a number line, in set notation and in interval notation. You will also shade regions on a graph.

Where you will use this: in the discriminant, to find the values of k for which a quadratic has real roots. Also in Differentiation, to find where a curve is rising. It comes back in The modulus function. It helps whenever a question asks for “the values of x for which”.

1. Linear inequalities

An {term:inequality} compares two values. It says one is less than, or greater than, the other. There are four signs. The sign {m:<} means less than. The sign {m:>} means greater than. The sign {m:<=} means less than or equal to. The sign {m:>=} means greater than or equal to.

A {term:strict-inequality|strict inequality} uses {m:<} or {m:>}. The end value is not a solution. The signs {m:<=} and {m:>=} do include the end value.

To solve an inequality is to find every value of x that makes it true. A linear inequality has x to the power 1 only, with no {m:x^2}. You solve it like a linear equation. You do the same to both sides.

Key idea: three rules keep an inequality true.

  • Add or subtract the same number on both sides. The sign stays.
  • Multiply or divide both sides by a positive number. The sign stays.
  • Multiply or divide both sides by a negative number. The sign reverses.

To see why, start with the true statement {m:-2<3}. Multiply both sides by {m:-1}. The two numbers become 2 and {m:-3}. Now 2 is the greater number, so you must write {m:2>-3}. Multiplying by a negative number swaps the order of numbers on the number line.

2. Number lines, set notation and interval notation

An {term:inequality} such as {m:x<3} has many solutions. There are three ways to write them all down. Each way shows the same numbers.

On a number line, a filled circle means the end value is included. An open circle means it is not. A thick line shows every number that is a solution. The arrowheads show that the line carries on.

The word and joins two inequalities that must both be true at once. The numbers {m:x>=-1} and {m:x<4} are both true from {m:-1} up to just below 4. Write this as one chain: {m:-1<=x<4}. Put the smaller number on the left. Make both signs point the same way.

The word or joins two inequalities where at least one must be true. For example, {m:x<-2} or {m:x>=3}. You cannot write this as one chain. No number is both less than {m:-2} and at least 3.

Set notation describes a collection of numbers with a rule. It uses curly brackets. The colon reads “such that”. So {{m:x}: {m:x<3}} reads “the set of all x such that x is less than 3”. Here x is any {term:real-number|real number}, that is any number on the number line.

The {term:union|union sign} {m:union} joins two sets into one. It means “or”. The {term:intersection|intersection sign} {m:intersect} keeps only what is in both sets. It means “and”.

Interval notation writes the two end values in brackets. An {term:interval} is all the numbers between two end values. A square bracket means the end value is included. A round bracket means it is not. The sign for infinity, ∞, is not a number, so it always has a round bracket.

Key idea: the same numbers, written four ways.

  • {m:x<3}: {{m:x}: {m:x<3}} and (−∞, 3).
  • {m:x>=-1}: {{m:x}: {m:x>=-1}} and [−1, ∞).
  • {m:-1<=x<4}: {{m:x}: {m:-1<=x<4}} and [−1, 4).
  • {m:x<-2} or {m:x>=3}: {{m:x}: {m:x<-2}} {m:union} {{m:x}: {m:x>=3}} and (−∞, −2) ∪ [3, ∞).

3. Quadratic inequalities

A {term:quadratic} inequality has an {m:x^2} term, for example {m:x^2-x-6<0}. You cannot solve it by doing the same to both sides. Use the graph instead. Quadratics showed how to find the {term:root|roots} and sketch the parabola.

The reason is that a curve cannot go from below the x-axis to above it without crossing. So the expression {m:x^2-x-6} can change sign only at its roots. Between two neighbouring roots it keeps one sign.

The values of x where the two sides are equal are the {term:critical-values}. They mark where the answer starts and stops.

Key idea: solve a quadratic inequality in five steps.

  1. Rearrange so that one side is 0.
  2. Solve the matching equation. Its roots are the critical values.
  3. Sketch the parabola. Mark the critical values on the x-axis.
  4. Read the graph. For “greater than 0”, take where the curve is above the axis. For “less than 0”, take where it is below.
  5. Write the answer. The critical values are included only if the sign is {m:<=} or {m:>=}.

5. Regions on a graph

An inequality in x and y describes a {term:region} of the graph. A region is a set of points. Every point in the region makes the inequality true.

The edge of the region is its {term:boundary}. To find the boundary, replace the inequality sign with an equals sign. For {m:y>2x-1} the boundary is the line {m:y=2x-1}. Draw it as in Straight lines.

A {term:strict-inequality|strict inequality} uses {m:<} or {m:>}. Points on its boundary are not included, so draw the boundary dashed. An inequality with {m:<=} or {m:>=} includes its boundary, so draw it solid.

A line splits the graph into two sides. All the points on one side make the inequality true. All the points on the other side make it false. So one test point tells you which side to shade.

Key idea: shade a region in four steps.

  1. Replace the sign with an equals sign. Draw the boundary.
  2. Make the boundary dashed for {m:<} or {m:>}. Make it solid for {m:<=} or {m:>=}.
  3. Choose a test point that is not on the boundary. The origin {m:(0, 0)} is the easiest, unless the boundary passes through it.
  4. Put the test point into the inequality. If it is true, shade the side with the test point. If it is false, shade the other side.

Why it works

  • The sign reverses. A negative multiplier reflects the number line, so left and right swap. The smaller number becomes the larger one.
  • Circles on a number line. A filled circle says “this number is a solution”. An open circle says “this number is the edge, and it is not one”.
  • Quadratic inequalities. A smooth curve cannot go from below the x-axis to above it without crossing. So the expression changes sign only at its roots.
  • The discriminant. In the quadratic formula, the square root of {m:b^2-4ac} must be real. If {m:b^2-4ac} is negative, there is no real root.
  • One test point. A line splits the plane into two sides. Every point on one side gives the same true or false answer. So one test point decides the whole side.
  • Dashed and solid. A solid line says “points on this line are in the region”. A dashed line says “they are not”. It matches the filled and open circles on a number line.

Common traps

  • Not reversing the sign when you multiply or divide by a negative number.
  • Reversing the sign when you divide by a positive number.
  • Dividing both sides by x. It could be negative or zero.
  • Taking the square root of both sides of {m:x^2>a}. It loses the negative solutions.
  • Writing two separate pieces as one chain, such as {m:-2>x>3}.
  • Using the wrong region for a quadratic. Greater than 0 is above the axis. Less than 0 is below.
  • Forgetting that a negative {m:x^2} term turns the parabola upside down.
  • Including the critical values when the sign is strict, or leaving them out when it is not.
  • Putting a square bracket next to infinity. Infinity always has a round bracket.
  • Using {m:<=} when you need two different real roots. A discriminant of 0 gives one repeated root.
  • Drawing a solid line for a strict inequality, or a dashed line for one with equal to.
