Functions and graphs

A function is a rule with an input and an output, and its graph is a picture of every input and output at once. Learn to use f(x), to join and undo functions, to recognise the main graphs, to read answers from them and to move them around, and then run it backwards: from an equation to its graph, and from a graph back to its equation.

Where you will use this: the power lost in a cable, the time for pumps to fill a tank, the best size for a fenced plot, and how fast a van loses value.

Reading f(x) and graphs

f(x) is read “f of x”. It means the output when the input is x. It does not mean f times x.

f(3) means: put 3 in for x. Work out the answer.

The graph of y = f(x) plots every input along the x-axis and its output up the y-axis.

Where a graph crosses the x-axis, y = 0. Where it crosses the y-axis, x = 0.

1. Function notation

A {term:function} is a rule that turns each input into one output. We give it a name, often f, and write f(x) = 2x + 3 for the rule “double the input, then add 3”.

f(4) means “use 4 as the input”. You {term:substitute|put in} 4 for x: f(4) = 2 × 4 + 3 = 11. The bracket holds the input, so f(4) is an output, a number.

To go the other way, f(x) = 15 means “the output is 15, so what was the input?” That is an equation: 2x + 3 = 15, so x = 6.

Key idea: f(a) means put a in for x. f(x) = b means the output is b, so solve to find x. If the rule has x² in it, there may be two inputs.

Worked example

f(x) = 3x − 2. Work out f(5) and f(−2), and find x when f(x) = 10.

  1. f(5) = 3 × 5 − 2 = 15 − 2 = 13.
  2. f(−2) = 3 × (−2) − 2 = −6 − 2 = −8.
  3. 3x − 2 = 10, so 3x = 12 and x = 4. Check: f(4) = 12 − 2 = 10. ✓

2. Joining and undoing functions

A {term:composite-function} joins two functions: the output of one becomes the input of the next. fg(x) means f(g(x)). Do g first, then f. The function nearest x goes first.

Order matters. With f(x) = 2x + 1 and g(x) = x², fg(x) = 2x² + 1, but gf(x) = (2x + 1)². These are different.

The {term:inverse-function} f−1(x) undoes f. For example, if f(x) = 3x − 5 then f(3) = 4, so f−1(4) = 3. To find it, write down the steps of f and undo them in the reverse order: f(x) = 3x − 5 multiplies by 3 and then takes away 5, so f−1 adds 5 and then divides by 3: f−1(x) = (x + 5)/3.

The −1 here is not a power. It does not mean 1/f(x).

Key idea: in fg(x), do g first. For the inverse, reverse the steps and use the opposite operations. Check with f(f−1(x)) = x.

Worked example

f(x) = 2x + 3 and g(x) = x − 1. Find fg(x), gf(x) and f−1(x).

  1. fg(x) = f(x − 1) = 2(x − 1) + 3 = 2x + 1.
  2. gf(x) = g(2x + 3) = 2x + 3 − 1 = 2x + 2.
  3. f doubles then adds 3, so f−1 takes away 3 then halves: f−1(x) = (x − 3)/2.

3. Quadratic graphs

The graph of a {term:quadratic}, such as y = x² − 4x + 3, is a smooth curve called a {term:parabola}. If the x² term is positive the parabola is U-shaped. If it is negative the parabola is upside down.

To draw it, fill in a table of values and plot the points.

y830−1038

Four things to read from the graph:

  • The {term:root-of-equation|roots} are where the graph crosses the x-axis (y = 0). Here x = 1 and x = 3, from (x − 1)(x − 3) = 0.
  • The {term:y-intercept} is where the graph crosses the y-axis (x = 0). Its value is the number on its own in the equation: 3.
  • The {term:axis-of-symmetry|line of symmetry} is halfway between the roots (when the graph crosses the x-axis twice): x = 2. The curve is a mirror image on each side.
  • The {term:turning-point} is on the line of symmetry. Put x = 2 into the equation: y = 4 − 8 + 3 = −1. So it is (2, −1), the lowest point.

Key idea: when the graph crosses the x-axis twice, the turning point is halfway between the roots. Find the roots by factorising, take the middle x, then put it into the equation to find y.

Worked example

For y = x² − 2x − 3, find the roots, the y-intercept and the turning point.

  1. Factorise: (x − 3)(x + 1) = 0, so the roots are x = 3 and x = −1.
  2. The y-intercept is the number on its own: −3.
  3. Halfway between −1 and 3 is x = 1. y = 1 − 2 − 3 = −4. The turning point is (1, −4).

4. Three more graphs to know

You need to recognise the shape of each of these from its equation.

The cubic y = x³

A {term:cubic} graph is an S-shape. It goes down on the left, passes through the origin and goes up on the right. Odd powers keep the sign: (−2)³ = −8.

The reciprocal y = 1/x

The {term:reciprocal} graph comes in two pieces. When x is far from 0, y is close to 0. When x is close to 0, y is far from 0. The graph never touches either axis: the axes are its {term:asymptote|asymptotes}. You cannot work out 1/0, so there is no point at x = 0.

The exponential y = kx

An {term:exponential} graph has the letter x in the power. For y = 2x, each step of 1 to the right doubles y. It always crosses the y-axis at (0, 1), because any number to the power 0 is 1, and it is always above the x-axis. When k is bigger than 1 it grows, getting steeper. When k is between 0 and 1 it falls instead.

Key idea: cubic: S-shape through the origin. Reciprocal: two pieces, never touching the axes. Exponential: always above the x-axis, through (0, 1), getting steeper.

Worked example

Which of y = x³, y = 1/x and y = 2x has a graph that goes through (0, 1)?

  1. y = x³: when x = 0, y = 0. It goes through the origin, not (0, 1).
  2. y = 1/x: x = 0 gives 1/0, which cannot be worked out. It does not meet the y-axis at all.
  3. y = 2x: when x = 0, y = 20 = 1. So it is the exponential.

5. Reading solutions from a graph

The graph of y = x² − 4x + 3 gives answers to many equations. To {term:solve} x² − 4x + 3 = a number, draw a horizontal line at that height and read the x-values where it meets the curve.

  • x² − 4x + 3 = 0: use the x-axis (y = 0). x = 1 or 3.
  • x² − 4x + 3 = 3: use the line y = 3. x = 0 or 4.
  • x² − 4x + 3 = −1: the line y = −1 only touches the lowest point. x = 2 only.
  • x² − 4x + 3 = −2: the line y = −2 misses the curve. No solutions.

Key idea: solving f(x) = a means finding where the line y = a meets the curve. The answers are the x-values of those points. A line can meet a parabola twice, once or never.

Worked example

Use the graph to solve x² − 4x + 3 = 3.

  1. Draw the horizontal line y = 3.
  2. It meets the curve at (0, 3) and (4, 3).
  3. Read the x-values: x = 0 or x = 4. Check: 16 − 16 + 3 = 3. ✓

6. Moving graphs around Higher

You can change a graph without drawing it again. Take f(x) = x² − 4x + 3, whose lowest point is (2, −1). Each change below moves or flips the whole graph. Following one point, such as the lowest point, shows what it does. In every picture the dashed curve is y = f(x).

y = f(x) + a: up or down

Adding a number outside the brackets changes every y-value. f(x) + 2 moves the graph up 2.

y = f(x + a): left or right

Adding a number inside the brackets changes x, and it moves the graph the opposite way to how it looks. f(x + 1) moves the graph left 1. f(x − 1) would move it right 1. The roots of f(x + 1) are 1 and 3 each shifted 1 left: 0 and 2.

y = −f(x): flip over the x-axis

Every y-value changes sign, so the graph is flipped upside down.

y = f(−x): flip over the y-axis

Every x-value changes sign, so the graph is reflected in the y-axis.

Key idea: outside the brackets changes y and does what it says (+ means up). Inside the brackets changes x and does the opposite (+ means left). A minus outside flips over the x-axis. A minus inside flips over the y-axis.

Worked example

  1. f(x − 3): inside the brackets, so x changes the opposite way. Move right 3: x = 2 + 3 = 5.
  2. + 4 outside the brackets: move up 4: y = −1 + 4 = 3.
  3. The lowest point is (5, 3).

Flip it: from the equation to the graph, and back

So far you have started with an equation and found features of the graph. Now run it backwards: you know the features, and you write the equation.

Forwards

y = x² − 4x + 3

Factorise: roots 1 and 3. y-intercept 3. Turning point (2, −1). Draw the curve.

Backwards

A curve crossing the x-axis at 1 and 3

Roots 1 and 3 give y = (x − 1)(x − 3). Multiply out: y = x² − 4x + 3.

The same idea works for other graphs. If y = kx passes through (3, 8), then k3 = 8, so k = 2. If y = a/x passes through (4, 3), then 3 = a/4, so a = 12. Put one point into the equation and solve for the missing number.

Key idea: a root at x = p means a bracket (x − p). The roots have the opposite sign to the numbers in the brackets. Check your equation against the y-intercept.

Why it works

  • A function is a machine. f(x) is the output for the input x. The graph collects every input and output as a point (x, f(x)).
  • Order matters in a composite. fg means “g first” because f is applied to what g gives out. Putting your shoes on and then your socks is not the same as socks and then shoes.
  • An inverse runs the machine backwards. It does the opposite steps in the opposite order. That is why f−1(f(x)) = x.
  • A parabola is symmetrical. The two roots are the same distance either side of the line of symmetry, so the turning point is halfway between them.
  • Solving by graph means finding where two graphs meet. The line y = a is every point with height a. Where it meets the curve, f(x) = a.
  • Inside the brackets, the movement is the opposite way. For f(x + 1) to give the same output as f(x), x must be 1 smaller, so the graph shifts left.

Common traps

  • Treating f(x) as f times x.
  • Doing f first in fg(x). The function next to x goes first.
  • Squaring a negative input without brackets and getting a negative answer.
  • Finding f−1(x) by changing signs but keeping the order of the steps.
  • Giving only one solution for x² = k, or reading the y-value instead of the x-value off a graph.
  • Moving f(x + a) to the right. Inside the brackets it moves left.
  • Drawing y = 1/x so that it touches or crosses an axis. It never does: the axes are its asymptotes.
  • Reading 2x as 2 × x.
