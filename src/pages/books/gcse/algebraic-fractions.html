Algebraic fractions

An algebraic fraction is a fraction with letters in it. It follows the same rules as the fractions you already know: cancel, multiply, divide, add and subtract.

Where you will use this: two taps or pipes filling one tank, two workers sharing a job, and two resistors in parallel in an electrical circuit. In each one, the rates add as fractions.

1. What is an algebraic fraction?

An {term:algebraic-fraction} is a {term:fraction} with algebra on the top, the bottom, or both. Here are three: {frac:3/x}, {frac:2x/5} and {frac:x + 1/x − 2}.

The bottom of a fraction can never be zero. So {frac:x + 1/x − 2} only makes sense when x is not 2. We usually just agree that x is not a number that makes the bottom zero.

You simplify them the same way as number fractions: find something that divides into both the top and the bottom, and {term:cancel|cancel} it. To cancel 6 from {frac:12/18} you divide both by 6 and get {frac:2/3}. In the same way:

{frac:6x/9} = {frac:2x/3} and {frac:12x²/8x} = {frac:3x/2}

Key idea: you can only cancel a factor (something multiplied), never a term (something added). In {frac:x + 5/x} the x on top is added to 5, so it cannot be cancelled. In {frac:5x/x} the x is multiplied, so it can.

Worked example

Simplify {frac:12x²/8x}.

  1. Numbers first: 12 and 8 both divide by 4. {frac:12/8} = {frac:3/2}.
  2. Letters: x² ÷ x = x (x² is x × x, so one x cancels).
  3. So {frac:12x²/8x} = {frac:3x/2}.

2. Simplifying by factorising

When the top or the bottom has more than one term, you cannot cancel straight away. First {term:factorise} the top and the bottom. Then cancel any brackets that match.

{frac:3x + 6/x + 2} = {frac:3(x + 2)/x + 2} = 3

Key idea: factorise, then cancel whole brackets. The tools you already have: take out a common factor, quadratics like x² + 5x + 6 = (x + 2)(x + 3), and the {term:difference-of-two-squares}: x² − 9 = (x + 3)(x − 3).

Worked example

Simplify {frac:x² + 5x + 6/x² + 3x}.

  1. Top: x² + 5x + 6 = (x + 2)(x + 3).
  2. Bottom: x² + 3x = x(x + 3).
  3. The bracket (x + 3) is on the top and the bottom. Cancel it.
  4. The answer is {frac:x + 2/x}. Notice you cannot cancel the x here: on the top it is added to 2.

Worked example: difference of two squares

Simplify {frac:x² − 16/x² + x − 12}.

  1. Top: x² − 16 = (x − 4)(x + 4).
  2. Bottom: x² + x − 12 = (x + 4)(x − 3), because 4 × (− 3) = − 12 and 4 + (− 3) = 1.
  3. Cancel (x + 4). The answer is {frac:x − 4/x − 3}.

Now you finish it

Simplify {frac:x² − 9/x² + 3x}.

  1. Top: x² − 9 = (x + 3)(x − 3). Bottom: x² + 3x = x(___).
  2. Cancel the matching bracket. What is left?
Check my answer

Bottom: x(x + 3). Cancel (x + 3): {frac:x − 3/x}.

3. Multiplying and dividing

Multiplying fractions: multiply the tops and multiply the bottoms. Then cancel. It is quicker to cancel before you multiply.

{frac:x/3} × {frac:6/x²} = {frac:6x/3x²} = {frac:2/x}

Dividing: flip the second fraction (swap its top and bottom) and multiply. The flipped fraction is the {term:reciprocal}.

{frac:x + 1/x − 2} ÷ {frac:x + 1/4} = {frac:x + 1/x − 2} × {frac:4/x + 1} = {frac:4/x − 2}

Key idea: multiply tops, multiply bottoms, and cancel matching factors. To divide, flip the second fraction first. If a bracket is on the top and the bottom, it cancels.

Worked example: multiply

Work out {frac:x/5} × {frac:10/x²}.

  1. Multiply the tops: x × 10 = 10x. Multiply the bottoms: 5 × x² = 5x².
  2. {frac:10x/5x²}: the numbers give {frac:10/5} = 2 and x ÷ x² = {frac:1/x}.
  3. The answer is {frac:2/x}.

Worked example: divide

Work out {frac:x²/8} ÷ {frac:x/2}.

  1. Flip the second fraction and multiply: {frac:x²/8} × {frac:2/x}.
  2. Multiply: {frac:2x²/8x}. Numbers: {frac:2/8} = {frac:1/4}. Letters: x² ÷ x = x.
  3. The answer is {frac:x/4}.

Now you finish it

Work out {frac:x/4} ÷ {frac:x/8}.

  1. Flip the second fraction and multiply: {frac:x/4} × {frac:8/___}.
  2. {frac:8x/4x} = ___.
Check my answer

{frac:x/4} × {frac:8/x} = {frac:8x/4x} = 2.

4. Adding and subtracting

When the bottoms are the same, add the tops: {frac:3/x} + {frac:2/x} = {frac:5/x}.

When the bottoms are different, use a {term:common-denominator}. Write each fraction with the same bottom, then add the tops.

{frac:1/x} + {frac:1/3} = {frac:3/3x} + {frac:x/3x} = {frac:3 + x/3x}

Key idea: find a bottom that both bottoms go into, multiply each top by the same thing as its bottom, then add or subtract the tops. When you subtract, put the whole top in a bracket so the minus sign reaches every term.

Worked example: add

Write {frac:x + 1/2} + {frac:x + 2/3} as a single fraction.

  1. The common denominator is 6.
  2. {frac:x + 1/2} = {frac:3(x + 1)/6} and {frac:x + 2/3} = {frac:2(x + 2)/6}.
  3. Add the tops: 3x + 3 + 2x + 4 = 5x + 7.
  4. The answer is {frac:5x + 7/6}.

Worked example: subtract

Write {frac:x + 1/2} − {frac:x − 1/3} as a single fraction.

  1. The common denominator is 6: {frac:3(x + 1)/6} − {frac:2(x − 1)/6}.
  2. Subtract the tops, with brackets: 3(x + 1) − 2(x − 1) = 3x + 3 − 2x + 2 = x + 5.
  3. The answer is {frac:x + 5/6}. The minus sign changes both signs inside (x − 1): − 2x and + 2.

  1. The common denominator is 5x.
  2. {frac:1/x} = {frac:5/5x} and {frac:1/5} = {frac:___/5x}.
Check my answer

Bigger bottoms Higher

Sometimes the bottoms are brackets. The common denominator is the two brackets multiplied together. If a bottom can be factorised, do that first: it may share a bracket with the other bottom.

{frac:1/x + 1} + {frac:1/x + 2} = {frac:x + 2/(x + 1)(x + 2)} + {frac:x + 1/(x + 1)(x + 2)} = {frac:2x + 3/(x + 1)(x + 2)}

Key idea: leave the bottom factorised, and expand only the top. Then check whether the top factorises and cancels with the bottom.

Worked example: a bottom that factorises

Write {frac:x/x² − 4} + {frac:1/x + 2} as a single fraction.

  1. Factorise the first bottom: x² − 4 = (x − 2)(x + 2). The second bottom (x + 2) is already part of it.
  2. The common denominator is (x − 2)(x + 2). Write {frac:1/x + 2} = {frac:x − 2/(x + 2)(x − 2)}.
  3. Add the tops: x + (x − 2) = 2x − 2.
  4. The answer is {frac:2x − 2/(x − 2)(x + 2)}, or {frac:2(x − 1)/(x − 2)(x + 2)}.

5. Solving equations with fractions

To solve an equation with fractions, get rid of the fractions. Multiply every term on both sides by the common denominator. Then solve as usual.

{frac:x/3} + {frac:x/4} = 7 → multiply by 12 → 4x + 3x = 84 → x = 12

Key idea: multiply every term by the common denominator. If x ends up on the bottom, you may get an x² term. Then it is a {term:quadratic}: move everything to one side and factorise.

Worked example: linear

Solve {frac:3/x} = {frac:6/x + 2}.

  1. Multiply both sides by x(x + 2): 3(x + 2) = 6x.
  2. Expand: 3x + 6 = 6x. So 6 = 3x and x = 2.
  3. Check: {frac:3/2} and {frac:6/4} are both 1.5. ✓

Worked example: leading to a quadratic

Solve x + {frac:6/x} = 5.

  1. Multiply every term by x: x² + 6 = 5x.
  2. Move everything to one side: x² − 5x + 6 = 0.
  3. Factorise: (x − 2)(x − 3) = 0, so x = 2 or x = 3.
  4. Check x = 2: 2 + 3 = 5. ✓ Check x = 3: 3 + 2 = 5. ✓

Now you finish it

Solve {frac:x/2} + {frac:x/3} = 10.

  1. Multiply every term by 6: 3x + ___x = ___.
  2. So ___x = 60 and x = ___.
Check my answer

6 × {frac:x/2} = 3x, 6 × {frac:x/3} = 2x, 6 × 10 = 60. So 5x = 60 and x = 12.

Why it works

  • Cancelling is dividing by 1. {frac:(x + 3)/(x + 3)} = 1 for any x where the bottom is not zero. That is why a matching bracket can go, but only if it multiplies the whole top and the whole bottom.
  • Letters are numbers. Put x = 5 into {frac:x + 5/x} and you get 2, not 5. Checking with a number is a quick way to catch a wrong cancelling.
  • A common denominator changes how a fraction looks, not its value. Multiplying the top and the bottom by the same thing is multiplying by 1.
  • Dividing by a fraction is multiplying by its reciprocal. Dividing by {frac:1/2} asks “how many halves fit?”, and that is multiplying by 2.
  • Rates add. If A does {frac:1/4} of a job an hour and B does {frac:1/12}, together they do {frac:1/3} an hour. It is the rates (fractions per hour) that add, never the times.

Common traps

  • Cancelling a term instead of a factor: {frac:x + 5/x} is not 5.
  • Adding fractions by adding the tops and the bottoms.
  • Forgetting to put the second top in a bracket when subtracting.
  • Flipping the first fraction instead of the second when dividing.
  • Multiplying only some terms by the common denominator when solving an equation.
  • Writing the bottom without brackets: 1/2x means {frac:1/2} × x, but 1/(2x) is {frac:1/2x}.
