    Answers for Integration as reverse differentiation
    No.QuestionAnswerMarks
    1Differentiate y = x^4. Type dy/dx like 5x^2.4x^3
    Working: Multiply by the power, 4, and take 1 off the power: dy/dx = 4x^3. At x = 1 the curve has gradient 4.
    2Differentiate y = 3x^2 + 5x - 7. Type your answer like 4x^3+2.6x+5 (also accept: 5+6x)
    Working: dy/dx = 6x + 5 + 0 = 6x + 5. The -7 only moves the curve down. It does not change the gradient.
    3Write 1/x^2 as a power of x. Type your answer like x^3.x^(-2) (also accept: x^-2)
    Working: 1/x^n = x^(-n), so 1/x^2 = x^(-2).
    4Write sqrt(x) as a power of x. Type your answer like x^(1/3).x^(1/2) (also accept: x^0.5)
    Working: sqrt(x) = x^(1 / 2), because x^(1 / 2) * x^(1 / 2) = x^1 = x.
    5Expand (x + 2)^2. Type your answer like x^2+3x+1. [Figure: A curve and its derivative, one above the other]x^2+4x+4 (also accept: 4+4x+x^2)
    Working: (x + 2)(x + 2) = x^2 + 2x + 2x + 4 = x^2 + 4x + 4.
    6The graph shows dy/dx for a straight line y = F(x) that passes through the origin. Write down F(x). Type your answer like 4x. [Figure: The graph of a derivative]3x
    Working: The derivative is 3 everywhere, so the line has gradient 3. Through the origin, F(x) = 3x. Check: the derivative of 3x is 3.
    7A curve has dy/dx = 2x. Which of these could be the equation of the curve?y equals x squared plus 7 y = x^2 + 7
    Working: The derivative of x^2 + 7 is 2x + 0 = 2x. Check the others: 2x^2 gives 4x, and x gives 1.
    8Find a function whose derivative is 7x^6. Give the simplest one, with nothing added. Type your answer like x^3.x^7
    Working: Try x^7. Its derivative is 7x^6. Check: the 7 comes down in front and the power drops to 6.
    9Find a function whose derivative is 6x^2. Give the simplest one, with nothing added. Type your answer like 5x^2.2x^3
    Working: The derivative of x^3 is 3x^2. We need twice that, so use 2x^3. Check: the derivative of 2x^3 is 6x^2.
    10The derivative of F(x) is 12x^3. Find the simplest F(x), with nothing added. Type your answer like 5x^2. [Figure: Curves with the same gradient at x equals 1]3x^4
    Working: The derivative of x^4 is 4x^3. We need three times that, so F(x) = 3x^4. Check: 3 * 4x^3 = 12x^3.
    11The curves y = x^3 + 8 and y = x^3 - 5 have the same gradient at every value of x. Find that gradient at x = 2.12
    Working: dy/dx = 3x^2. At x = 2 it is 3 * 2^2 = 3 * 4 = 12. Both curves have gradient 12 there, because the constants 8 and -5 disappear when you differentiate.
    12Two different functions have the same derivative. What must be true about the two functions?They differ by a constant: one graph is the other moved up or down
    Working: Two functions with the same derivative differ only by a constant. Their graphs are the same shape, one moved up or down.
    13Both curves have dy/dx = 2x. The lower curve is y = x^2. The upper curve crosses the y-axis at (0, 5). Write down the equation of the upper curve. Type your answer like x^2+1. [Figure: Two curves with the same derivative]x^2+5 (also accept: 5+x^2)
    Working: The curves differ by a constant, so the upper curve is y = x^2 + c. At x = 0 it is at height 5, so c = 5. The equation is y = x^2 + 5.
    14The curve y = x^2 + c passes through the point (0, 4). Find the number c.4
    Working: 4 = 0^2 + c, so c = 4. The curve is y = x^2 + 4.
    15How many different functions have the derivative 2x? [Figure: The rule for integrating a power of x]As many as there are numbers: one for each value of c
    Working: The functions with derivative 2x are x^2 + c, and c can be any real number. So there is one function for each value of c.
    16How do you read integral of x^3 dx?The integral of x cubed with respect to x
    Working: integral of x^3 dx is read "the integral of x cubed with respect to x". Its value is x^4/4 + c.
    17Find integral of x^4 dx. Use the letter c for the constant. Type your answer like x^3/3+c.x^5/5+c (also accept: (1/5)x^5+c, 0.2x^5+c)
    Working: The power 4 becomes 5. Divide by 5: integral of x^4 dx = x^5/5 + c. Check: the derivative of x^5/5 is x^4.
    18Find integral of x^10 dx. Use the letter c for the constant. Type your answer like x^3/3+c.x^11/11+c (also accept: (1/11)x^11+c)
    Working: 10 + 1 = 11, so integral of x^10 dx = x^11/11 + c. Check: the derivative of x^11/11 is x^10.
    19Find integral of x dx. Use the letter c for the constant. Type your answer like x^3/3+c.x^2/2+c (also accept: (1/2)x^2+c, 0.5x^2+c)
    Working: x = x^1, so the new power is 2. integral of x dx = x^2/2 + c. Check: the derivative of x^2/2 is (2x)/2 = x.
    20Why can you not use the rule integral of x^n dx = x^(n + 1)/(n + 1) + c when n = -1?The new power is 0, so the rule would divide by 0
    Working: n + 1 = -1 + 1 = 0. The rule divides by n + 1, so it would divide by 0. That is not possible. integral of x^(-1) dx has a different answer, which you meet in Year 2.
    21The number 1 is x^0. Use the rule with n = 0 to find integral of 1 dx. Type your answer like x^3/3+c. [Figure: Integrate a sum one term at a time]x+c (also accept: c+x)
    Working: integral of x^0 dx = x^1/1 + c = x + c. Check: the derivative of x + c is 1.
    22Find integral of 6x^2 dx. Use the letter c for the constant. Type your answer like 3x^2+c.2x^3+c (also accept: c+2x^3)
    Working: integral of 6x^2 dx = (6x^3)/3 + c = 2x^3 + c. Check: the derivative of 2x^3 is 6x^2.
    23Find integral of (3x^2 + 8x) dx. Use the letter c for the constant. Type your answer like x^3+2x+c.x^3+4x^2+c (also accept: c+x^3+4x^2, 4x^2+x^3+c)
    Working: integral of 3x^2 dx = x^3 and integral of 8x dx = 4x^2. So integral of (3x^2 + 8x) dx = x^3 + 4x^2 + c. Check: the derivative is 3x^2 + 8x.
    24Find integral of 5 dx. Use the letter c for the constant. Type your answer like 3x+c.5x+c (also accept: c+5x)
    Working: integral of 5 dx = 5x + c. Check: the derivative of 5x is 5.
    25Find integral of (4x^3 - 9x^2 + 2x - 1) dx. Use the letter c for the constant. Type your answer like x^3+2x^2-x+c.x^4-3x^3+x^2-x+c (also accept: c+x^4-3x^3+x^2-x)
    Working: 4x^3 gives x^4. -9x^2 gives -3x^3. 2x gives x^2. -1 gives -x. So the integral is x^4 - 3x^3 + x^2 - x + c.
    26Find integral of(x^3/2) dx. Use the letter c for the constant. Type your answer like x^3/6+c. [Figure: Three steps for integrating an expression that is not yet a sum of powers]x^4/8+c (also accept: (1/8)x^4+c, 0.125x^4+c)
    Working: integral of(x^3/2) dx = 1/2 * x^4/4 + c = x^4/8 + c. Check: the derivative of x^4/8 is (4x^3)/8 = x^3/2.
    27Find integral of (x + 1)^2 dx. Expand first. Use the letter c for the constant. Type your answer like x^3/3+x+c.x^3/3+x^2+x+c (also accept: (1/3)x^3+x^2+x+c, (x+1)^3/3+c, (1/3)(x+1)^3+c)
    Working: (x + 1)^2 = x^2 + 2x + 1. Integrate each term: x^3/3 + x^2 + x. So the integral is x^3/3 + x^2 + x + c. Check: the derivative is x^2 + 2x + 1.
    28Find integral of x(2x + 3) dx. Expand first. Use the letter c for the constant. Type your answer like x^3/3+x^2/2+c.2x^3/3+3x^2/2+c (also accept: (2/3)x^3+(3/2)x^2+c, 3x^2/2+2x^3/3+c, (3/2)x^2+(2/3)x^3+c, 2x^3/3+1.5x^2+c, c+2x^3/3+3x^2/2)
    Working: x(2x + 3) = 2x^2 + 3x. 2x^2 gives (2x^3)/3. 3x gives (3x^2)/2. So the integral is (2x^3)/3 + (3x^2)/2 + c.
    29Find integral of((x^3 + 4)/x^2) dx. Divide first. Use the letter c for the constant. Type your answer like x^2/2+3/x+c.x^2/2-4/x+c (also accept: (1/2)x^2-4/x+c, x^2/2-4x^(-1)+c, (1/2)x^2-4x^(-1)+c, -4/x+x^2/2+c, -4x^(-1)+x^2/2+c, c+x^2/2-4/x)
    Working: (x^3 + 4)/x^2 = x + 4x^(-2). x gives x^2/2. 4x^(-2) gives (4x^(-1))/(-1) = -4x^(-1). So the integral is x^2/2 - 4/x + c.
    30Find integral of(1/x^3) dx. Use the letter c for the constant. Type your answer like x^(-2)/5+c.-1/(2x^2)+c (also accept: -x^(-2)/2+c, -(1/2)x^(-2)+c, -0.5x^(-2)+c, c-1/(2x^2))
    Working: 1/x^3 = x^(-3). The new power is -3 + 1 = -2. Divide by -2: integral of x^(-3) dx = x^(-2)/(-2) + c = -1/(2x^2) + c. Check: the derivative of -(1/2)x^(-2) is x^(-3).
    31Find integral of sqrt(x) dx. Use the letter c for the constant. Type your answer like 3x^(5/2)/5+c.2x^(3/2)/3+c (also accept: (2/3)x^(3/2)+c, (2x^(3/2))/3+c, 2x^1.5/3+c, (2/3)x^1.5+c)
    Working: sqrt(x) = x^(1 / 2). The new power is 3/2. integral of sqrt(x) dx = x^(3 / 2)/(3 / 2) + c = (2/3)x^(3 / 2) + c. Check: the derivative of (2/3)x^(3 / 2) is x^(1 / 2).
    32Find integral of(4/x^2) dx. Use the letter c for the constant. Type your answer like 3/x+c.-4/x+c (also accept: -4x^(-1)+c, -4x^-1+c, c-4/x)
    Working: 4/x^2 = 4x^(-2). integral of 4x^(-2) dx = (4x^(-1))/(-1) + c = -4/x + c. Check: the derivative of -4x^(-1) is 4x^(-2).
    33Find integral of (x^2 - 1/x^2) dx. Use the letter c for the constant. Type your answer like x^3/3+2/x+c. [Figure: Check an integral by differentiating it]x^3/3+1/x+c (also accept: (1/3)x^3+1/x+c, x^3/3+x^(-1)+c, (1/3)x^3+x^(-1)+c, 1/x+x^3/3+c, x^(-1)+x^3/3+c)
    Working: x^2 gives x^3/3. -x^(-2) gives (-x^(-1))/(-1) = x^(-1). So the integral is x^3/3 + 1/x + c. Check: the derivative of x^(-1) is -x^(-2).
    34A student writes integral of (8x^3 + 2x) dx = 2x^4 + x^2 + c. Differentiate the student's answer. Type the result like 4x^3+1.8x^3+2x (also accept: 2x+8x^3)
    Working: The derivative of 2x^4 + x^2 + c is 8x^3 + 2x. This is the integrand, so the student's integral is correct.
    35Which of these integrals is wrong? Differentiate each answer to check.the integral of 2x plus 5 with respect to x equals x squared plus 5, plus c integral of (2x + 5) dx = x^2 + 5 + c
    Working: The derivative of x^2 + 5 + c is 2x, not 2x + 5. Integrate the 5 as well: it becomes 5x. The correct integral is x^2 + 5x + c.
    36A student writes integral of 5x^4 dx = 5x^5 + c. Differentiate the student's answer. Type the result like 4x^3.25x^4
    Working: The derivative of 5x^5 is 5 * 5x^4 = 25x^4. This is not 5x^4, so the student's integral is wrong.
    37The student's integral of 5x^4 was wrong. Write the correct integral. Use the letter c for the constant. Type your answer like x^3+c. [Figure: One curve of the family passes through a given point]x^5+c (also accept: c+x^5)
    Working: integral of 5x^4 dx = (5x^5)/5 + c = x^5 + c. Check: the derivative of x^5 is 5x^4.
    38The graph shows dy/dx for a curve. The curve passes through (0, 1). Find the equation of the curve. Type your answer like x^3-2x+5. [Figure: The graph of dy by dx for a curve]x^2-4x+1 (also accept: 1-4x+x^2, -4x+x^2+1)
    Working: The line passes through (0, -4) and (2, 0), so its gradient is 2 and dy/dx = 2x - 4. Integrate: y = x^2 - 4x + c. At (0, 1): 1 = 0 - 0 + c, so c = 1. The curve is y = x^2 - 4x + 1.
    39A curve has dy/dx = 3x^2 and passes through (1, 4). Find the equation of the curve. Type your answer like x^2+1.x^3+3 (also accept: 3+x^3)
    Working: y = x^3 + c. At (1, 4): 4 = 1 + c, so c = 3. The curve is y = x^3 + 3.
    40A function has f'(x) = 8x - 3 and f(2) = 10. Find f(x). Type your answer like 2x^2+x+1.4x^2-3x (also accept: -3x+4x^2)
    Working: f(x) = 4x^2 - 3x + c. f(2) = 10: 10 = 4 * 4 - 3 * 2 + c = 16 - 6 + c = 10 + c, so c = 0. So f(x) = 4x^2 - 3x.
    41A curve has dy/dx = 12x^2 - 2x + 1 and passes through (−1, −3). Find the equation of the curve. Type your answer like 2x^3-x+5.4x^3-x^2+x+3 (also accept: 3+4x^3-x^2+x, 4x^3+x-x^2+3, x-x^2+4x^3+3)
    Working: y = 4x^3 - x^2 + x + c. At (−1, −3): -3 = 4 * (-1)^3 - (-1)^2 + (-1) + c = -4 - 1 - 1 + c = -6 + c. So c = 3. The curve is y = 4x^3 - x^2 + x + 3.
    42A function has f'(x) = 6sqrt(x) and f(4) = 40. Find f(x). Type your answer like 2x^(3/2)+1.4x^(3/2)+8 (also accept: 4x^1.5+8, 8+4x^(3/2), 8+4x^1.5)
    Working: 6x^(1 / 2) integrates to 6 * (2/3)x^(3 / 2) = 4x^(3 / 2). So f(x) = 4x^(3 / 2) + c. 4^(3 / 2) = (sqrt(4))^3 = 8, so f(4) = 4 * 8 + c = 32 + c = 40. Then c = 8, and f(x) = 4x^(3 / 2) + 8.
    43A curve y = f(x) has f'(x) = 3x^2 - 6x. It passes through (0, 2). Find f(2). [Figure: Integrating a power of a bracket that holds a linear expression]-2
    Working: f(x) = x^3 - 3x^2 + c. At (0, 2): 2 = 0 - 0 + c, so c = 2. Then f(x) = x^3 - 3x^2 + 2, and f(2) = 8 - 12 + 2 = -2.
    44Find integral of (x + 4)^3 dx. Use the letter c for the constant. Type your answer like (x+1)^3/3+c.(x+4)^4/4+c (also accept: (1/4)(x+4)^4+c, ((x+4)^4)/4+c)
    Working: The new power is 4. a = 1. So integral of (x + 4)^3 dx = (x + 4)^4/4 + c.
    45Find integral of (2x + 1)^5 dx. Use the letter c for the constant. Type your answer like (x+1)^3/3+c.(2x+1)^6/12+c (also accept: (1/12)(2x+1)^6+c, ((2x+1)^6)/12+c)
    Working: The new power is 6 and a = 2, so divide by 6 * 2 = 12. integral of (2x + 1)^5 dx = (2x + 1)^6/12 + c.
    46Find integral of (5x - 3)^2 dx. Use the letter c for the constant. Type your answer like (x+1)^3/3+c.(5x-3)^3/15+c (also accept: (1/15)(5x-3)^3+c, ((5x-3)^3)/15+c)
    Working: The new power is 3 and a = 5, so divide by 3 * 5 = 15. integral of (5x - 3)^2 dx = (5x - 3)^3/15 + c.
    47Find integral of sqrt(2x + 1) dx. Use the letter c for the constant. Type your answer like (x+1)^(3/2)/2+c. [Figure: Differentiate, then integrate](2x+1)^(3/2)/3+c (also accept: (1/3)(2x+1)^(3/2)+c, ((2x+1)^(3/2))/3+c, (2x+1)^1.5/3+c, (1/3)(2x+1)^1.5+c)
    Working: sqrt(2x + 1) = (2x + 1)^(1 / 2). The new power is 3/2 and a = 2. Dividing by 3/2 * 2 = 3: integral of sqrt(2x + 1) dx = (2x + 1)^(3 / 2)/3 + c.
    48Differentiate y = x^5 + 3x. Then integrate your answer. Type the final result, using the letter c for the constant. Type your answer like x^2+c.x^5+3x+c (also accept: c+x^5+3x, 3x+x^5+c)
    Working: dy/dx = 5x^4 + 3. Then integral of (5x^4 + 3) dx = x^5 + 3x + c. This is the start, plus c.
    49Integrate 20x^3, then differentiate your answer. Type the final result like 5x^2.20x^3
    Working: integral of 20x^3 dx = 5x^4 + c. Then the derivative of 5x^4 + c is 20x^3. You are back where you started, exactly.
    50You differentiate y = x^2 + 7, then integrate the result. The final answer is x^2 + c. What happened to the 7?It was lost when differentiating. The c could stand for it, but nothing in the working says which number c is
    Working: Differentiating gives 2x, with no 7. Integrating gives x^2 + c. The c can stand for any number, including 7, but nothing in the working says which number c is.
    51A function F has F'(x) = 10x^4 and F(0) = 0. Find F(x). Type your answer like 3x^2.2x^5
    Working: integral of 10x^4 dx = 2x^5 + c. F(0) = 0: 0 = 0 + c, so c = 0. So F(x) = 2x^5.
    52Anna says: integral of 6x^2 dx = 6x^3 + c. What went wrong?She did not divide by the new power, 3
    Working: The derivative of 6x^3 + c is 18x^2, not 6x^2. She added 1 to the power but did not divide by the new power. The correct integral is (6x^3)/3 + c = 2x^3 + c.
    53Ben says: integral of (x^2 + 3x) dx = x^3/3 + (3x^2)/2. What went wrong?He did not write +c
    Working: Both terms are right. What is missing is +c. The answer is a family of functions, not one function. The correct integral is x^3/3 + (3x^2)/2 + c.
    54Cara says: integral of x^(-3) dx = x^(-2)/2 + c. What went wrong?She divided by 2. The new power is -2, so she should divide by -2
    Working: The derivative of x^(-2)/2 is (-2x^(-3))/2 = -x^(-3). It has the wrong sign. The new power is -2, so she should divide by -2. The correct integral is -x^(-2)/2 + c.
    55Dev says: integral of (x + 1)^2 dx = x^3/3 + x + c, because (x + 1)^2 = x^2 + 1. What went wrong?(x + 1)^2 is not x^2 + 1. It has a middle term, 2x

    56Eli says: integral of sqrt(x) dx = x^(3 / 2)/3 + c. What went wrong?He divided by 3. He should divide by 3/2
    Working: The new power is 3/2, so divide by 3/2, which is multiplying by 2/3. The correct integral is (2/3)x^(3 / 2) + c. Eli's answer differentiates to (1/2)x^(1 / 2), not x^(1 / 2).
    57Find integral of (5x^4 - 2x + 7) dx. Use the letter c for the constant. Type your answer like x^3+2x+c.x^5-x^2+7x+c (also accept: c+x^5-x^2+7x)

    58A curve has dy/dx = 2/x^2 and passes through (2, 5). Find the equation of the curve. Type your answer like 3-4/x.6-2/x (also accept: -2/x+6, 6-2x^(-1), -2x^(-1)+6)

    59Which of these integrals cannot be done with the rule integral of x^n dx = x^(n + 1)/(n + 1) + c, even after tidying?the integral of x cubed plus 4x, all over x squared, with respect to x integral of((x^3 + 4x)/x^2) dx
    Working: (x^3 + 4x)/x^2 = x + 4/x = x + 4x^(-1). The term 4x^(-1) has n = -1, so the rule cannot integrate it. The other two options tidy to powers other than -1.
    60A curve has dy/dx = 4x^3 - 6x and passes through (1, 0). Find the value of y when x = 2.6
    Working: y = x^4 - 3x^2 + c. At (1, 0): 0 = 1 - 3 + c, so c = 2. At x = 2: y = 16 - 12 + 2 = 6.
    61Find integral of (2x + 3)(x - 1) dx. Use the letter c for the constant. Type your answer like x^3/3+x^2/2+c.2x^3/3+x^2/2-3x+c (also accept: (2/3)x^3+(1/2)x^2-3x+c, 2x^3/3+0.5x^2-3x+c, -3x+2x^3/3+x^2/2+c, c+2x^3/3+x^2/2-3x)
    Working: (2x + 3)(x - 1) = 2x^2 + x - 3. Integrate: (2x^3)/3 + x^2/2 - 3x. So the integral is (2x^3)/3 + x^2/2 - 3x + c.
    62Find integral of(3/x^4) dx. Use the letter c for the constant. Type your answer like 2/x^2+c.-1/x^3+c (also accept: -x^(-3)+c, -x^-3+c, c-1/x^3)
    Working: 3/x^4 = 3x^(-4). integral of 3x^(-4) dx = (3x^(-3))/(-3) + c = -x^(-3) + c = -1/x^3 + c.
    63Find integral of (6x^2 - 4x + 5) dx. Use the letter c for the constant. Type your answer like x^3+2x+c.2x^3-2x^2+5x+c (also accept: c+2x^3-2x^2+5x, 5x-2x^2+2x^3+c)
