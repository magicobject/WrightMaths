    Differentiation from first principles: answers

    77 questions, 6 of them marked (18 marks in all). Question numbers match the page. Use your browser's Print for a copy.

    Open the questions Back to the book
    Answers for Differentiation from first principles
    No.QuestionAnswerMarks
    1Find the gradient of the straight line through (1, 3) and (4, 12).3
    Working: Rise = 12 − 3 = 9. Run = 4 − 1 = 3. Gradient = 9 ÷ 3 = 3. The line rises 3 units for each 1 unit across.
    2Write 1/x^2 as a power of x. Type it like x^(-5).x^(-2) (also accept: x^-2)
    Working: 1/x^2 = x^(-2), because a negative power means one over the positive power.
    3Write sqrt(x) as a power of x. Type it like x^(2/3).x^(1/2) (also accept: x^0.5, x^(0.5))
    Working: sqrt(x) = x^(1 / 2).
    4Expand and simplify (x + 3)^2. Type it like x^2+8x+4. [Figure: The tangent at A on the curve y = x squared, with its gradient triangle]x^2+6x+9 (also accept: 9+6x+x^2)
    Working: (x + 3)(x + 3) = x^2 + 3x + 3x + 9 = x^2 + 6x + 9.
    5A curve passes through the origin. The tangent to the curve at P is drawn. It passes through (1, 0) and (3, 6). Find the gradient of the curve at P. [Figure: A curve with the tangent drawn at P]3
    Working: Rise = 6 − 0 = 6. Run = 3 − 1 = 2. Gradient = 6 ÷ 2 = 3. At P the curve rises 3 units for each 1 unit across.
    6Two tangents are drawn to the same curve, one at A and one at B. At which point is the gradient of the curve greater? [Figure: Two tangents drawn to the same curve]At B, because the tangent there is steeper
    Working: The tangent at B slopes up more steeply than the tangent at A, so the gradient of the curve is greater at B.
    7A straight line has equation y = 4x - 3. What is the gradient of the line at x = 5?4
    Working: The line y = 4x - 3 has gradient 4 at every point, including at x = 5.
    8At a point on a curve, the tangent slopes down as you move from left to right. What does that tell you about the gradient of the curve there? [Figure: Chords from A getting closer to the tangent at A]It is negative
    Working: The tangent goes down as x increases, so its gradient is negative. The curve is falling at that point.
    9Find the gradient of the chord of y = x^2 from the point where x = 1 to the point where x = 4.5
    Working: Rise = 16 − 1 = 15. Run = 4 − 1 = 3. Gradient = 15 ÷ 3 = 5.
    10Find the gradient of the chord of y = x^3 from x = 1 to x = 1.1. Give your answer to 2 decimal places.3.31
    Working: Rise = 1.331 − 1 = 0.331. Run = 0.1. Gradient = 0.331 ÷ 0.1 = 3.31.
    11Find the gradient of the chord of y = x^2 from x = 3 to x = 3.5.6.5
    Working: Rise = 12.25 − 9 = 3.25. Run = 0.5. Gradient = 3.25 ÷ 0.5 = 6.5.
    12The gradients of four chords of y = x^2, each starting at x = 2, are 5, 4.5, 4.1 and 4.01. Each chord ends nearer to x = 2 than the one before. What value do the gradients get close to?4
    Working: 5, 4.5, 4.1, 4.01, ... are getting close to 4. That is the gradient of the curve at x = 2.
    13The point B slides along a curve towards the point A. What happens to the chord AB? [Figure: The chord gradient 2 + h gets close to 2 as h gets close to 0]It gets closer to the tangent at A
    Working: As B gets closer to A, the chord AB turns towards the tangent at A.
    14For f(x) = x^2, the rise of the chord from x to x + h is 2xh + h^2. Divide it by the run, h, and simplify. Type the gradient of the chord like 5x+3h.2x+h (also accept: h+2x)
    Working: (2xh + h^2)/h = 2x + h. This is the gradient of the chord. Letting h tend to 0 would then give 2x.
    15Use differentiation from first principles to find f'(x) for f(x) = 3x^2. Type it like 5x.6x
    Working: 3(x + h)^2 - 3x^2 = 3x^2 + 6xh + 3h^2 - 3x^2 = 6xh + 3h^2. Divide by h: 6x + 3h. As h tends to 0, this tends to 6x. So f'(x) = 6x.
    16For f(x) = x^3, use (x + h)^3 = x^3 + 3x^2h + 3xh^2 + h^3 to simplify the gradient of the chord, (f(x + h) - f(x))/h. Type it like 4x^2+5xh+h^2.3x^2+3xh+h^2
    Working: f(x + h) - f(x) = 3x^2h + 3xh^2 + h^3. Dividing every term by h gives 3x^2 + 3xh + h^2.
    17In first principles working you see (2xh + h^2)/h = 2x + h. Why is it allowed to divide by h?h is not 0 at this stage: B is a different point from A, so there is a chord
    Working: The chord joins two different points, so h is not 0 and we may divide by it. Only after simplifying do we ask what happens as h tends to 0.
    18Use first principles to find f'(x) for f(x) = 2x^3. You may use (x + h)^3 = x^3 + 3x^2h + 3xh^2 + h^3. Type it like 5x^2.6x^2
    Working: 2(x + h)^3 - 2x^3 = 6x^2h + 6xh^2 + 2h^3. Divide by h: 6x^2 + 6xh + 2h^2. As h tends to 0 this tends to 6x^2. So f'(x) = 6x^2.
    19Write down the limit as h tends to 0 of 4x + 7h. Type it like 5x. [Figure: The power rule in two moves]4x
    Working: 7h tends to 0 as h tends to 0. 4x does not depend on h. So limit as h -> 0 of (4x + 7h) = 4x.
    20Differentiate y = x^7 with respect to x. Type dy/dx like 3x^2.7x^6
    Working: dy/dx = 7x^(7 - 1) = 7x^6.
    21Find f'(x) when f(x) = 5x^4. Type it like 6x^2.20x^3
    Working: f'(x) = 5 * 4x^3 = 20x^3.
    22Differentiate y = 3x^2 - 4x + 1 with respect to x. Type dy/dx like 5x^2-3.6x-4
    Working: dy/dx = 6x - 4 + 0 = 6x - 4. The terms gave 6x, -4 and 0.
    23Find dy/dx when y = 12.0
    Working: The graph of y = 12 is a horizontal line, so its gradient is 0 everywhere. dy/dx = 0.
    24Find dy/dx when y = 2x^3 - x^2. Type it like 5x^2-3x.6x^2-2x
    Working: 2x^3 gives 6x^2. -x^2 gives -2x. So dy/dx = 6x^2 - 2x.
    25What does dy/dx mean? [Figure: Tangents to y equals the square root of x]The derivative of y with respect to x: the gradient of the curve at each value of x
    Working: dy/dx is the derivative of y with respect to x. It is the limit of the chord gradient: the gradient of the curve.
    26Write 5/x^3 as a number times a power of x. Type it like 7x^(-2).5x^(-3) (also accept: 5x^-3)
    Working: 5/x^3 = 5 * 1/x^3 = 5x^(-3).
    27Find dy/dx when y = 1/x^2. Type it like 5x^(-4) or like 5/x^4.-2x^(-3) (also accept: -2x^-3, -2/x^3)
    Working: y = x^(-2), so dy/dx = -2x^(-3). In fraction form this is -2/x^3.
    28Find dy/dx when y = sqrt(x). Give your answer using a power of x or a fraction, like 3x^(-2/3) or 1/(4x^(2/3)).(1/2)x^(-1/2) (also accept: 1/2x^(-1/2), x^(-1/2)/2, 0.5x^(-1/2), (0.5)x^(-1/2), 0.5x^-0.5, 1/(2x^(1/2)), 1/(2sqrt(x)), 1/(2*sqrt(x)))
    Working: y = x^(1 / 2), so dy/dx = (1/2)x^(-1 / 2). In fraction form this is 1/(2sqrt(x)).
    29Find dy/dx when y = 4x^(3 / 2). Give your answer using a power of x, like 5x^(1/3), or using sqrt(x).6x^(1/2) (also accept: 6x^0.5, 6x^(0.5), 6sqrt(x), 6*sqrt(x))
    Working: 4 * (3/2)x^(3 / 2 - 1) = 6x^(1 / 2), which is 6sqrt(x).
    30Which of these is the derivative of y = 1/x?It is -1/x^2
    Working: y = x^(-1), so dy/dx = -1 * x^(-2) = -1/x^2. This agrees with the picture: the curve always falls.
    31Find the gradient of the curve y = 1/x at the point where x = 2. Give your answer as a fraction or a decimal. [Figure: Expand and split first, then differentiate term by term]-1/4
    Working: dy/dx = -x^(-2) = -1/x^2. At x = 2: -1/4. The gradient is -1/4, which matches the picture of the tangent at (2, 1/2).
    32Find dy/dx when y = x(x^2 - 4). Type it like 5x^2-3.3x^2-4
    Working: y = x^3 - 4x, so dy/dx = 3x^2 - 4.
    33Find dy/dx when y = (x + 3)^2. Type it like 5x+7.2x+6
    Working: y = x^2 + 6x + 9, so dy/dx = 2x + 6.
    34Find dy/dx when y = (x^2 + 1)/x. Type it like 5x^(-3)+2, or like 5/x^3+2.1-x^(-2) (also accept: 1-x^-2, 1-1/x^2, -x^(-2)+1, -x^-2+1, -1/x^2+1)
    Working: y = x + x^(-1), so dy/dx = 1 - x^(-2) = 1 - 1/x^2.
    35Find dy/dx when y = xsqrt(x). Give your answer using a power of x or sqrt(x), like 5x^(1/3) or 7sqrt(x).(3/2)x^(1/2) (also accept: 3/2x^(1/2), 1.5x^(1/2), 0.5*3x^(1/2), x^(1/2)*3/2, (3/2)sqrt(x), 3/2sqrt(x), 1.5sqrt(x), 3sqrt(x)/2, 1.5x^0.5, (3/2)x^0.5)
    Working: xsqrt(x) = x^(3 / 2), so dy/dx = (3/2)x^(1 / 2).
    36Which of these is dy/dx when y = (x + 5)/x? [Figure: A curve whose gradient increases: positive second derivative]It is -5/x^2
    Working: y = 1 + 5x^(-1), so dy/dx = 0 - 5x^(-2) = -5/x^2.
    37Find d^2y/(dx^2) when y = x^4 + 3x^2 - 5x. Type it like 5x^2+3.12x^2+6
    Working: dy/dx = 4x^3 + 6x - 5, so d^2y/(dx^2) = 12x^2 + 6.
    38Find f''(x) when f(x) = x^3 - 6x^2. Type it like 5x-3.6x-12
    Working: f'(x) = 3x^2 - 12x, so f''(x) = 6x - 12.
    39Find the value of d^2y/(dx^2) when x = 2, for y = x^3 - 3x.12
    Working: dy/dx = 3x^2 - 3 and d^2y/(dx^2) = 6x. At x = 2: 6 * 2 = 12. The value 12 is positive, so the gradient is increasing there.
    40At one point on a curve, d^2y/(dx^2) = -4. What does that tell you?The gradient is decreasing as x increases through that point
    Working: d^2y/(dx^2) is the rate of change of the gradient. The second derivative here is negative, so the gradient is decreasing as x increases.
    41The gradients of a curve are measured at x = 0, x = 1 and x = 2. They are -3, -1 and 1. Is the second derivative positive, negative or zero for x from 0 to 2? [Figure: The sign of the gradient along a curve]Positive
    Working: The gradients go from -3 to -1 to 1. They increase, so the second derivative is positive.
    42The graph shows y = f(x). Use it to find the two values of x where f'(x) = 0. Type them with "or" between, like 1 or 3. [Figure: The graph of a cubic function f]-2 or 2 (also accept: 2 or -2)
    Working: The tangent is horizontal at the top of the left hill and the bottom of the right valley. Reading across, those are at x = -2 and x = 2.
    43The graph shows y = f(x). For which values of x is f'(x) negative? Type your answer as an inequality, like 1<x<4. [Figure: The graph of a cubic function f]-2<x<2
    Working: The curve falls between its two flat points, so f'(x) is negative for -2
    44The graph of y = f(x) is a U-shaped parabola with its lowest point at x = 1. Which description fits the graph of y = f'(x)?A straight line that crosses the x-axis at x = 1 and slopes upwards
    Working: At the lowest point the tangent is horizontal, so f'(1) = 0. On the left f falls, so f' is negative. On the right f rises, so f' is positive. A straight line through (1, 0) sloping up does all of this.
    45The graph of y = f(x) is a cubic curve. What shape is the graph of y = f'(x)?A quadratic curve (a parabola)
    Working: x^3 differentiates to 3x^2. So the derivative of a cubic has x^2 as its highest power: it is a quadratic.
    46For the curve in the first question of this set, f(x) = x^3 - 12x. Use f'(x) = 3x^2 - 12 to find f'(0). [Figure: The rate of change is the gradient of the tangent]-12
    Working: f'(0) = 3 * 0^2 - 12 = -12. The gradient is negative, which agrees with the graph in the first question: the curve is falling, steeply, at the origin.
    47A balloon holds V cm³ of air after t seconds, where V = 2t^3 - t. Find dV/dt when t = 3. Give the number only, in cm³ per second.53
    Working: dV/dt = 6t^2 - 1. At t = 3: 6 * 9 - 1 = 53. The volume is increasing at 53 cm³ per second.
    48A car travels s km in t hours. What are the units of ds/dt?Kilometres per hour
    Working: ds/dt is the change in distance (km) per unit of time (hours), so it is in kilometres per hour.
    49The graph shows the distance s metres of a trolley after t seconds. The tangent at P is drawn. It passes through (2, 2) and (6, 14). Find the rate of change of s at the moment shown. Give the number only, in metres per second. [Figure: A distance-time graph with a tangent at P]3
    Working: Rise = 14 − 2 = 12. Run = 6 − 2 = 4. Gradient = 12 ÷ 4 = 3. At P the distance is increasing at 3 metres per second.
    50The temperature T °C of a cup of tea after t minutes is T = 90 - 2t^2 for 0 <= t <= 5. Find dT/dt when t = 3. Give the number only, in °C per minute. [Figure: The gradient of y = x cubed minus 4x squared plus 5 at the point (1, 2)]-12
    Working: dT/dt = -4t. At t = 3: -12. The tea is cooling at 12 °C per minute.
    51Find the gradient of the curve y = x^3 - 4x^2 + 5 at the point where x = 3.3
    Working: dy/dx = 3x^2 - 8x. At x = 3: 3 * 9 - 8 * 3 = 27 - 24 = 3.
    52Find f'(9) when f(x) = 4sqrt(x). Give your answer as a fraction.2/3
    Working: f'(x) = 4 * (1/2)x^(-1 / 2) = 2x^(-1 / 2). At x = 9: 2 * 1/3 = 2/3.
    53The curve y = x^3 has gradient 12 at two points. Find the x-values of both points. Type them with "or" between, like 1 or 3. [Figure: Three curves with the same derivative]-2 or 2 (also accept: 2 or -2)
    Working: dy/dx = 3x^2. Set 3x^2 = 12, so x^2 = 4, so x = 2 or x = -2. The gradient is 12 at both points: 3 * (-2)^2 = 12.
    54A curve has dy/dx = 6x and passes through (0, 5). Find its equation. Type it like 2x^2+1.3x^2+5
    Working: y = 3x^2 + c. At (0, 5): c = 5. So y = 3x^2 + 5. Check: dy/dx = 6x. ✓
    55A curve has dy/dx = 3x^2 - 4 and passes through (2, 1). Find its equation. Type it like x^2-3x+5.x^3-4x+1
    Working: y = x^3 - 4x + c. At (2, 1): 8 - 8 + c = 1, so c = 1. So y = x^3 - 4x + 1.
    56The graph shows y = f'(x). At which value of x does the graph of y = f(x) have a horizontal tangent? [Figure: The graph of the derivative of a function f]1
    Working: f'(x) = 0 where the graph of f' crosses the x-axis, which is at x = 1. So the graph of f has a horizontal tangent at x = 1.
    57f'(x) = 2x - 2. For x > 1, is f increasing or decreasing?Increasing, because f'(x) is positive there
    Working: For x > 1, 2x - 2 > 0. A positive gradient means f is increasing.
    58Both y = x^2 + 1 and y = x^2 - 3 have dy/dx = 2x. Why do they have the same derivative?A constant has a flat graph, so adding or subtracting a constant does not change the gradient
    Working: The derivative of x^2 + 1 is 2x + 0. The derivative of x^2 - 3 is 2x - 0. The constant differentiates to 0 in each case.
    59Asha says: (d/dx)(x^3) = x^2. What went wrong?She took 1 off the power but did not bring the 3 down as a multiplier
    Working: The rule gives (d/dx)(x^3) = 3x^2. She has lost the multiplier 3.
    60Ben says: y = 5, so dy/dx = 5. What went wrong?The graph of y = 5 is horizontal, so its gradient is 0
    Working: The graph of y = 5 is a horizontal line, so dy/dx = 0.
    61Chen says: y = 1/x^2, so dy/dx = 1/(2x). What went wrong?He did not rewrite 1/x^2 as x^(-2). The power rule gives -2x^(-3)
    Working: y = x^(-2), so dy/dx = -2x^(-3) = -2/x^3. Check the sign: for x > 0 the curve falls, so the gradient must be negative.
    62Dee says: for f(x) = x^2, (f(x + h) - f(x))/h = (2xh + h^2)/h. She puts h = 0, gets 0/0, and says f'(x) = 0. What went wrong?She put h = 0 into the fraction before cancelling h. The fraction has no value at h = 0. Cancel first to get 2x + h, then let h tend to 0
    Working: While h is not 0, (2xh + h^2)/h = 2x + h. As h tends to 0 this tends to 2x, so f'(x) = 2x.
    63Eli says: d^2y/(dx^2) means (dy/dx)^2. For y = x^2, dy/dx = 2x, so d^2y/(dx^2) = 4x^2. What went wrong?d^2y/(dx^2) means differentiate twice. The answer is 2
    Working: d^2y/(dx^2) means differentiate twice. dy/dx = 2x, and differentiating again gives d^2y/(dx^2) = 2.
    64Find f'(x) when f(x) = 3x^4 - 2x^2 + x - 7. Type it like 5x^3-2x+4.12x^3-4x+1
    Working: f'(x) = 12x^3 - 4x + 1 - 0 = 12x^3 - 4x + 1.
    65Find dy/dx when y = 2/x + x^2. Type it like 5x-3x^(-2), or like 5x-3/x^2.2x-2x^(-2) (also accept: 2x-2x^-2, 2x-2/x^2, -2x^(-2)+2x, -2x^-2+2x, -2/x^2+2x)
    Working: y = 2x^(-1) + x^2, so dy/dx = -2x^(-2) + 2x. In the other form, 2x - 2/x^2.
    66Find the gradient of the curve y = 3x^2 - 5x at the point where x = -1.-11
    Working: dy/dx = 6x - 5. At x = -1: 6 * (-1) - 5 = -11. The curve is falling steeply there.
    67Find the value of d^2y/(dx^2) when x = 4, for y = x^(5 / 2). Give your answer as a fraction or a decimal.15/2
    Working: dy/dx = (5/2)x^(3 / 2) and d^2y/(dx^2) = (15/4)x^(1 / 2). At x = 4: 15/4 * 2 = 15/2.
    68For f(x) = 2x^2 + 3x, the gradient of the chord from x to x + h simplifies to 4x + 2h + 3. Find f'(x). Type it like 5x+7.4x+3 (also accept: 3+4x)
    Working: As h tends to 0, 2h tends to 0. The terms 4x and 3 do not contain h. So f'(x) = 4x + 3.
    69Find dy/dx when y = (3x^2 - 1)/x. Type it like 5+x^(-3), or like 5+1/x^3.3+x^(-2) (also accept: 3+x^-2, 3+1/x^2, x^(-2)+3, x^-2+3, 1/x^2+3)
    Working: y = 3x - x^(-1), so dy/dx = 3 + x^(-2) = 3 + 1/x^2.
    70A cyclist has travelled s metres after t seconds, where s = 0.5t^2 + 3t. Find how fast the distance is changing when t = 4. Give the number only, in metres per second.7
    Working: ds/dt = t + 3. At t = 4: 7. The distance is increasing at 7 metres per second.
    71For y = x^3, find the value of d^2y/(dx^2) when x = -1. Give the number only. Then, on paper, say what the sign of your answer tells you about the gradient.-6
    Working: d^2y/(dx^2) = 6x. At x = -1 it is -6. The value -6 is negative, so the gradient is decreasing as x increases through x = -1.
    72Differentiate f(x) = 4x^2 - 3x from first principles. Type f'(x) like 5x+7.8x-3 (also accept: -3+8x)
    1. M1 for expanding f(x + h) correctly
    2. M1 for forming (f(x + h) - f(x))/h and simplifying it to 8x + 4h - 3
    3. M1 for letting h tend to 0 (the limit must be shown)
    4. A1 for f'(x) = 8x - 3
    Working: f(x + h) = 4(x^2 + 2xh + h^2) - 3x - 3h. So f(x + h) - f(x) = 8xh + 4h^2 - 3h. Divide by h: 8x + 4h - 3. As h tends to 0 this tends to 8x - 3. So f'(x) = 8x - 3.
    		4
    73(a) [3 marks] Find dy/dx. Type it like 5-3x^(-2), or like 5-3/x^2.4-9x^(-2) (also accept: 4-9x^-2, 4-9/x^2, -9x^(-2)+4, -9x^-2+4, -9/x^2+4)
    1. M1 for expanding (2x + 3)^2 = 4x^2 + 12x + 9
    2. M1 for dividing each term by x to get 4x + 12 + 9x^(-1)
    3. A1 for dy/dx = 4 - 9x^(-2)
    Working: y = (4x^2 + 12x + 9)/x = 4x + 12 + 9x^(-1). So dy/dx = 4 + 0 - 9x^(-2) = 4 - 9/x^2.
    		3
    74(b) [2 marks] Hence find the value of d^2y/(dx^2) when x = 1.18
    1. M1 for differentiating -9x^(-2) to get 18x^(-3)
    2. A1 for 18
    Working: d^2y/(dx^2) = -9 * (-2)x^(-3) = 18x^(-3). At x = 1: 18. The value 18 is positive, so the gradient is increasing there.
    		2
    75(a) [2 marks] Find dV/dt. Type it like 3-4t.-5-2t (also accept: -2t-5)
    1. M1 for differentiating at least one term correctly
    2. A1 for dV/dt = -5 - 2t
    Working: dV/dt = 0 - 5 - 2t = -5 - 2t.
    		2
    76(b) [3 marks] Find the rate of change of the volume when t = 3. Give the number only, in litres per minute. Then, on paper, say what the sign of your answer means.-11
    1. M1 for substituting t = 3 into dV/dt
    2. A1 for -11
    3. B1 for saying that the volume is decreasing (at 11 litres per minute)
    Working: dV/dt = -5 - 2 * 3 = -11. The rate is -11 litres per minute. The sign is negative, so the volume is decreasing: the tank is losing 11 litres each minute at that moment.
    		3
    77f(x) = 4sqrt(x) + 3/x, for x > 0. Find the exact value of f'(4). Give your answer as a fraction.13/16
    1. B1 for rewriting as 4x^(1 / 2) + 3x^(-1)
    2. M1 for differentiating one term correctly
    3. A1 for f'(x) = 2x^(-1 / 2) - 3x^(-2)
    4. A1 for 13/16
    Working: f(x) = 4x^(1 / 2) + 3x^(-1), so f'(x) = 2x^(-1 / 2) - 3x^(-2). At x = 4: 2 * 1/2 - 3/16 = 1 - 3/16 = 13/16.
    		4
