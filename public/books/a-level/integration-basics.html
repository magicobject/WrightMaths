    Integration · Year 1

    Integration as reverse differentiation

    Differentiating gives the gradient of a curve. Integrating goes the other way: from the gradient back to the curve. This page shows how to do it, and why every integral without limits ends in + c.

    Where you will use this: finding a curve when you know its gradient, finding an area under a curve (the next topic), and working back from a rate of change to the quantity.

    Words you need

    Tap a teal word anywhere on the page to see this again.

    integrate
    To reverse differentiation: to find a function whose derivative is the function you are given. With limits, the answer is a number, the signed area: parts of the graph above the x-axis count as positive and parts below count as negative.
    antiderivative
    A function whose derivative is a given function.
    constant of integration
    The unknown number c that you add when you integrate without limits. It is there because every constant differentiates to zero.
    integrand
    The function that is being integrated: the expression between the integral sign and the dx.
    with respect to
    The words that say which letter is the variable when you differentiate or integrate. In an integral, the letter after d is the variable.
    integral of x to the n
    The rule: add 1 to the power, then divide by the new power. It works for every n except negative 1.

    This page assumes you can differentiate a power of x, and that you can write roots and reciprocals as powers. The warm-up checks both. It does not use definite integrals or area: they come in the next topic.

    1. Going backwards: what was differentiated?

    To differentiate a function is to find its derivative. The derivative gives the gradient of the curve at every value of x.

    Now go the other way. You are given the derivative, and you want the function it came from. To integrate is to do exactly that. Integrating reverses differentiating.

    Read the two graphs together. The height of the lower graph is the gradient of the upper graph. Integrating starts from the lower graph and asks: which curve has these gradients?

    Key idea: to integrate a function f(x) is to find a function whose derivative is f(x). Any such function is an antiderivative of f(x). The result of integrating is called an integral.

    So there is one question to ask each time: what did I differentiate to get this function? Use what you know about differentiating powers. Differentiating brings the power down in front and takes 1 off the power. Integrating must undo that.

    Worked example

    Find a function whose derivative is 4x3.

    1. Differentiating takes 1 off the power. So the power in the answer is one more than 3. Try x4.
    2. Differentiate x4: the 4 comes down in front and the power drops to 3. This gives 4x3.
    3. That is the derivative we were given. So x4 is a function whose derivative is 4x3.

    Now you finish it

    Find a function whose derivative is 5x4.

    1. The power in the answer is one more than 4. So try ___.
    2. The derivative of x5 is ___.
    3. That is the derivative we were given. So a function whose derivative is 5x4 is ___.
    Check my answer

    One more than 4 is 5. Differentiating x5 gives 5x4. So x5 works. Other functions work too, such as x5+2. The next section shows why.

    2. Why every integral ends in + c

    Differentiate x2. You get 2x. Now differentiate x2+3 and x2−5. You get 2x again each time.

    Adding a number moves a curve up or down. It does not change how steep the curve is at any value of x. So many functions have the same derivative. The picture shows three of them.

    Together, these curves are a family: one curve for each value of c. Every function with derivative 2x has the form x2+c, where c is a number. We write all of them at once as x2+c.

    Key idea: the letter c is the constant of integration. It stands for an unknown number: any real number. Every integral on this page has no limits, so always write +c.

    Why can you not find c from the derivative alone? Differentiating turns every constant into 0, so the derivative shows nothing about it. Integrating cannot tell which constant was there. Section 7 shows how a point on the curve gives c.

    Worked example

    Differentiate y=x3, y=x3+9 and y=x3−4. What do you notice? What does it tell you about the integral of 3x2?

    1. y=x3 gives dydx=3x2.
    2. y=x3+9 gives 3x2+0=3x2. y=x3−4 gives 3x2−0=3x2.
    3. All three have the same derivative, 3x2.
    4. So the functions with derivative 3x2 are x3+c, for any number c.

    Now you finish it

    Differentiate y=x4+7 and y=x4−2. Write all the functions with derivative 4x3 in one expression.

    1. y=x4+7 gives dydx=___.
    2. y=x4−2 gives the same derivative, 4x3.
    3. So the functions with derivative 4x3 are x4+___.
    Check my answer

    The 7 and the −2 both become 0 when you differentiate. So every function with derivative 4x3 is x4+c.

    • One
    • Two
    • As many as there are numbers: one for each value of c
    1. Every function x2+c has derivative 2x.
    2. How many values can c take?
    3. c can be any real number.

    3. The integral sign, and the rule for powers of x

    Integrating has its own notation. ∫2xdx is read "the integral of 2x with respect to x". The sign ∫ is a stretched letter S. The integrals on this page have no numbers on the sign. Numbers there are called limits. They come in the next topic.

    The function between the sign and the dx is the integrand. The dx says which letter is the variable: this is what with respect to x means. Always write the dx.

    ∫2xdx=x2+c

    Read this as: the integral of 2x with respect to x equals x squared plus c.

    Key idea: to integrate a power of x, add 1 to the power, then divide by the new power. Then add c.

    ∫xndx=xn+1n+1+c

    Here n is the power: xn is read "x to the power n". This works for every number n except n=−1.

    Why the rule works

    Differentiate xn+1n+1. The power n+1 comes down in front, and the power drops to n. The result is (n+1)xnn+1=xn. So the rule undoes the power rule.

    Why n = −1 is excluded

    If n=−1, then n+1=0. The rule would divide by 0, which is not possible. The integrand is then x−1=1x. No power of x has 1x as its derivative. You meet the answer in Year 2.

    Every other power works, including negative powers and fractional powers. Write roots and reciprocals as powers first.

    Worked example

    Find ∫x5dx.

    1. The power is 5. Add 1: the new power is 6.
    2. Divide by the new power: x66.
    3. Add c: ∫x5dx=x66+c.
    4. Check by differentiating: x66 gives 6x56=x5. ✓

    Worked example: a power you cannot see

    Find ∫xdx.

    1. Write x as x1. The new power is 2.
    2. Divide by the new power: x22.
    3. ∫xdx=x22+c.

    Now you finish it

    Find ∫x7dx.

    1. The power is 7. The new power is ___.
    2. Divide x8 by the new power, ___. This gives x88.
    3. So ∫x7dx= ___.
    Check my answer

    7 + 1 = 8, so the answer is x88+c. Check: the derivative of x88 is 8x78=x7.

    4. Numbers, multiples and sums

    Three facts let you integrate longer expressions.

    1. A number in front stays in front. ∫6x2dx: integrate x2 to get x33, then multiply by 6. The answer is 2x3+c.
    2. A sum is integrated one term at a time. Integrate each term, then add the results.
    3. A number on its own gets an x. ∫5dx=5x+c, because the derivative of 5x is 5. This is the rule with 5=5x0.

    Write one c at the end of the whole answer, not one c for each term. Each term could have its own constant, but a sum of unknown constants is one unknown constant.

    Worked example

    Find ∫(6x2+4x−5)dx.

    1. Integrate 6x2: 6x33=2x3.
    2. Integrate 4x: 4x22=2x2.
    3. Integrate −5: −5x.
    4. Join the terms and add c: ∫(6x2+4x−5)dx=2x3+2x2−5x+c.
    5. Check by differentiating: the derivative of the answer is 6x2+4x−5. ✓

    Now you finish it

    Find ∫(8x3−3x2+2)dx.

    1. 8x3 integrates to 8x44=___.
    2. −3x2 integrates to −3x33=___.
    3. 2 integrates to ___.
    4. So the integral is 2x4−x3+2x+___.
    Check my answer

    ∫(8x3−3x2+2)dx=2x4−x3+2x+c. Check: the derivative is 8x3−3x2+2.

    5. Tidy first: brackets, fractions and roots

    The rule needs each term to be a number times a power of x. Many expressions are not in that form yet. Rewrite them first.

    Brackets: expand first

    You cannot integrate a product by integrating each factor. Expand the brackets, then integrate each term.

    Worked example

    Find ∫(x+2)2dx.

    1. Expand: (x+2)2=x2+4x+4.
    2. Integrate each term: x33+4x22+4x.
    3. Tidy and add c: ∫(x+2)2dx=x33+2x2+4x+c.
    4. Check by differentiating: the derivative of the answer is x2+4x+4, which is (x+2)2. ✓

    Section 8 gives a shortcut for brackets like this one. Expanding always works.

    Now you finish it

    Find ∫(x+3)2dx.

    1. Expand: (x+3)2=___.
    2. Integrate each term: x33+___+___.
    3. Add c: ∫(x+3)2dx=x33+3x2+9x+c.
    Check my answer

    (x+3)(x+3)=x2+6x+9. Then 6x integrates to 6x22=3x2 and 9 integrates to 9x.

    Fractions: divide each term first

    If the bottom of a fraction is a single term, divide each term on the top by it. Then use the laws of indices. This is allowed because a+bc=ac+bc. Dividing each term is not allowed when the bottom has two terms.

    Worked example

    Find ∫x3+4x2dx.

    1. Divide each term on the top by x2: x3x2+4x2=x+4x−2.
    2. Integrate x: x22. Integrate 4x−2: the new power is −1, so 4x−1−1=−4x−1.
    3. Write −4x−1 as −4x.
    4. ∫x3+4x2dx=x22−4x+c.

    Watch for a term that becomes 1x. For example, x3+4xx2=x+4x. The rule cannot integrate 4x. That is the n=−1 case, which you meet in Year 2.

    Roots and reciprocal powers

    Write a root or a reciprocal as a power of x. Then use the rule. The rule works for negative and fractional powers. To divide by a fraction, multiply by its reciprocal: dividing by 32 is multiplying by 23.

    Worked example

    Find ∫xdx.

    1. Write the root as a power: x=x1/2.
    2. The new power is 12+1=32.
    3. Divide by 32, which is multiplying by 23: 23x3/2.
    4. ∫xdx=23x3/2+c.
    5. Check: the derivative of 23x3/2 is 23×32x1/2=x1/2. ✓

    Worked example: a reciprocal power

    Find ∫1x2dx.

    1. Write the reciprocal as a power: 1x2=x−2.
    2. The new power is −2+1=−1. Divide by −1: x−1−1=−x−1.
    3. ∫1x2dx=−1x+c.
    4. Check: the derivative of −x−1 is −1×(−1)x−2=x−2. ✓

    Take care with signs. Adding 1 to −2 gives −1, not −3. Dividing by −1 changes the sign.

    Now you finish it

    Find ∫1x3dx.

    1. Write the reciprocal as a power: 1x3=x−3.
    2. The new power is ___.
    3. Divide by the new power: x−2−2=___.
    Check my answer

    −3+1=−2. Dividing by −2 gives −12x−2=−12x2. So ∫1x3dx=−12x2+c.

    7. Finding the curve through a point

    Sometimes you know the derivative of a function and one point on its graph. The point picks out one curve from the family.

    The derivative of f(x) is written f′(x), read "f prime of x". You are given f′(x) and a point, and you find f(x).

    Method:

    1. Integrate the derivative. Include +c.
    2. Put the x-value and y-value of the point into your answer.
    3. Solve for c.
    4. Write the equation of the curve with the value of c in it.

    8. When the inside is linear Extra

    This is an extra method. In the syllabus plan it belongs to Year 2, where it is called the reverse chain rule, and some courses introduce it earlier. Check your specification. If your course does not need it, skip to "Flip it".

    A linear expression has the form ax+b, where a and b are numbers, such as 2x+1. To integrate a power of (ax+b), treat the bracket like x. Then also divide by a, the number in front of x. The expression in the bracket is called the inside.

    Key idea:

    ∫(ax+b)ndx=(ax+b)n+1a(n+1)+c

    This works for every n except n=−1, and for a≠0. It works only when the expression in the bracket is linear.

    Why you divide by a

    Test the rule on (2x+1)2. Expand first: (2x+1)2=4x2+4x+1. Integrate each term: 4x33+2x2+x+c.

    Now use the rule with a=2 and n=2. It gives (2x+1)36+c. Expand the top: 8x3+12x2+6x+16=4x33+2x2+x+16. This matches the expanded method. The two answers differ only by a constant, and c can be any number, so they agree. The 6 on the bottom is a(n+1)=2×3.

    Differentiating (2x+1)36 needs the chain rule, which comes in Year 2. For now, check by expanding, as above.

    For brackets like (x+2)2, where a=1, the rule gives (x+2)33+c. The two answers differ only by a constant, so they agree.

    Find ∫(2x+3)(x−1)dx. Use the letter c for the constant. Type your answer like x^3/3+x^2/2+c.

    1. Expand the brackets first.
    2. (2x+3)(x−1)=2x2−2x+3x−3. Join the like terms.
    3. Integrate each term of 2x2+x−3. Write +c.
    • You did not divide the x term by the new power, 2. x integrates to x22.

    (2x+3)(x−1)=2x2+x−3. Integrate: 2x33+x22−3x. So the integral is 2x33+x22−3x+c.

    Find ∫3x4dx. Use the letter c for the constant. Type your answer like 2/x^2+c.

    1. Write 3x4 as 3 times a power of x.
    2. 3x4=3x−4. The new power is −3.
    3. Divide by −3. The 3 in front cancels.
    • Check the sign. You divide by the new power, −3, so the answer is negative.
    • You did not divide by the new power, −3. The 3 in front is divided by it.

    3x4=3x−4. ∫3x−4dx=3x−3−3+c=−x−3+c=−1x3+c.

    Why it works

    • Integrating undoes differentiating. The derivative of an integral is the integrand. That is the reason you can check any answer by differentiating it.
    • The rule is the power rule backwards. Differentiating brings the power down and takes 1 off. Integrating adds 1 to the power and divides by the new power, which cancels the number that came down.
    • The constant appears because differentiating loses it. A number added to a function moves its graph up or down, and does not change the gradient. So a whole family of curves has the same derivative.
    • One point fixes the constant. Only one curve in the family passes through a given point.
    • The power −1 is different. The rule would divide by 0. A different function has 1x as its derivative. You meet it in Year 2.

    Common traps

    • Forgetting +c in an integral with no limits.
    • Adding 1 to the power but not dividing by the new power.
    • Dividing by the old power instead of the new power.
    • Differentiating when you should integrate, by bringing the power down.
    • Leaving a number on its own without an x: ∫5dx is 5x+c.
    • Writing a root or a reciprocal without rewriting it as a power first.
    • Losing a sign with negative powers: ∫x−2dx is −x−1+c.
    • Dividing by 32 as if it were 23. Dividing by a fraction means multiplying by its reciprocal.
    • Squaring each term of a bracket: (x+1)2 is not x2+1.
    • Using the y-value of a point as c. Put the point into the equation and solve for c.
