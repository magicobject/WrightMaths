    Vectors

    A vector is a journey: how far across and how far up or down. You will write journeys as column vectors, add and subtract them, multiply them by numbers, find their lengths, and use them to describe shapes and prove that lines are parallel or points are in a straight line. Then you will go the other way: from a vector back to the journey.

    Where you will use this: the route of a cable or a pipe across a building plan, the straight-line length of a rafter, the movement of a character in a game, and checking that three fixings line up.

    Words you need

    Vector
    A journey with a size and a direction, such as 3 right and 2 up. It is drawn as an arrow and written as a column vector, or as a bold letter such as a.
    Column vector
    Two numbers written one above the other in brackets. The top number is the move across, and the bottom number is the move up or down.
    Magnitude
    The length of a vector. For the vector with x across and y up it is the square root of (x squared plus y squared), from Pythagoras.
    Scalar
    An ordinary number, used to multiply a vector. Multiplying a vector by a scalar makes it longer or shorter, and a negative scalar reverses its direction.

    Typing vectors

    Type a column vector as a pair with the top number first, like (3, -2). The brackets and spaces are optional.

    Vectors written with letters are in bold on the page. You type them as plain letters, like 2a + b or b - a. Any order is fine, but write the letters and the numbers the way the question shows.

    The vector from A to B is written AB here, and said “vector AB”. In your exam you write it with an arrow over the letters, or you underline it.

    1. Vectors and journeys

    A Vector describes a journey: how far across and how far up or down. It has a size and a direction. On a diagram it is an arrow. It starts at the tail and ends at the head.

    We write a vector as a column vector: the move across on top, the move up or down underneath. So a journey of 3 right and 2 up is 32.

    • Two arrows with the same length and the same direction are the same vector, wherever they are drawn. The two arrows above are both 32.
    • The vector from A to B is called AB. To find it, subtract: AB = B − A (end minus start), across and up separately.
    • The vector the other way, from B back to A, is BA. It is the opposite: BA = −AB.
    • A letter in bold, such as a, can name a vector without naming its end points.

    Key idea: a vector says how to get there, not where you start. To find where you finish, add the vector to the starting point.

    Worked example

    A is the point (1, 2) and B is the point (5, 5). Find the vector AB and the vector BA.

    1. AB = B − A: across 5 − 1 = 4, up 5 − 2 = 3. So AB = 43.
    2. BA is the opposite: BA = −4−3.
    3. Check: starting at A(1, 2) and adding AB gives (1 + 4, 2 + 3) = (5, 5), which is B. ✓

    Now you finish it

    A is the point (−2, 1) and B is the point (3, −2). Find the vector AB.

    1. Across: 3 − (−2) = ___.
    2. Up: −2 − 1 = ___.
    3. AB = (___, ___).
    Check my answer

    Across: 3 − (−2) = 5. Up: −2 − 1 = −3. AB = 5−3.

    2. Adding and subtracting vectors

    To add vectors, do one journey and then the other. Add the top numbers, and add the bottom numbers.

    ab + cd = a + cb + d

    • If you go from A to B and then from B to C, the whole journey is AB + BC = AC. This is the triangle rule.
    • To subtract, add the opposite: a − b = a + (−b). Subtract the top numbers, and subtract the bottom numbers.
    • You can work backwards along an arrow, but then you use the minus of that vector.

    Key idea: always add the tops together and the bottoms together. Never add a top to a bottom.

    Worked example

    a = 31 and b = 24. Work out a + b and a − b.

    1. a + b = 3 + 21 + 4 = 55.
    2. a − b = 3 − 21 − 4 = 1−3.

    Now you finish it

    1. Tops: −2 + 4 = ___.
    2. Bottoms: 5 + 1 = ___.
    Check my answer

    a + b = 26.

    3. Multiplying a vector by a number

    A plain number is called a Scalar. To multiply a vector by a scalar, multiply both numbers.

    3ab = 3a3b

    • 2a is the same direction as a, twice as long. 1 over 2a is half as long. (Type a half as 1/2.)
    • −a is the same length as a in the opposite direction.
    • Two vectors are Parallel if one is a scalar multiple of the other. For example, 23 and 69 are parallel, because 69 = 323. A negative scalar gives parallel vectors that point in opposite directions.

    Key idea: to test whether two vectors are parallel, divide the tops, then divide the bottoms. If you get the same number both times, they are parallel.

    Worked example

    a = 2−1 and b = 13. Work out 3a − 2b.

    1. 3a = 6−3.
    2. 2b = 26.
    3. 3a − 2b = 6 − 2−3 − 6 = 4−9.

    Now you finish it

    a = 2−1 and b = 13. Work out 2a + b.

    1. 2a = (___, ___).
    2. Add b: tops ___ + 1, bottoms ___ + 3.
    Check my answer

    2a = 4−2. 2a + b = 51.

    Check your knowledge: scalar multiples and parallel vectors

    1. Multiply the top number by 3, and the bottom number by 3.
    2. 3 × (−1) is −3.
    • Both numbers are multiplied by 3, not just the top.
    • That adds 3 to each number. Multiplying by 3 is not adding 3.

    3 × 2 = 6 and 3 × (−1) = −3. The answer is 6−3, typed (6, -3).

    4. The size of a vector

    The magnitude (length) of a vector is how long its arrow is. Write it with straight lines: |a|. The across move and the up move make the two short sides of a right-angled triangle, so use Pythagoras.

    for xy,   magnitude = √(x² + y²)

    Key idea: square both numbers first. A negative number squared is positive, so the minus signs disappear: (−5)² = 25.

    Worked example

    Find the magnitude of 5−12.

    1. Square each number: 5² = 25 and (−12)² = 144.
    2. Add: 25 + 144 = 169.
    3. Square root: √169 = 13.
    4. The magnitude is 13.

    Worked example: rounding

    Find the magnitude of 25 to 1 decimal place.

    1. 2² + 5² = 4 + 25 = 29.
    2. √29 = 5.385… ≈ 5.4.

    Now you finish it

    Find the magnitude of −86.

    1. (−8)² + 6² = ___ + ___ = ___.
    2. The square root is ___.
    Check my answer

    64 + 36 = 100, and √100 = 10.

    Check your knowledge: magnitude

    Find the magnitude of 34.

    1. Square both numbers and add.
    2. 3² + 4² = 25.
    • That adds the numbers. Square them first, then add, then take the square root.
    • That is the sum of the squares. Take the square root to get the length.

    3² + 4² = 9 + 16 = 25. √25 = 5.

    Find the magnitude of −512.

    1. Squaring removes the minus sign.
    2. (−5)² = 25 and 12² = 144.
    • That adds −5 and 12. Square each number first.
    • A length is never negative. The square root here is 13.

    (−5)² + 12² = 25 + 144 = 169. √169 = 13.

    2. Then find its magnitude with Pythagoras.

    • That is the sum of the squares. Take the square root.

    AB = (7 − 1, 10 − 2) = (6, 8). 6² + 8² = 36 + 64 = 100. √100 = 10.

    1. The journey is the vector (20, 21). Its magnitude is the straight-line distance.
    2. 20² + 21² = 400 + 441.
    • That is the distance flown, 20 + 21. The straight-line distance is shorter.

    5. Vectors in diagrams

    In a diagram, vectors are often given as letters. If O is the origin, OA = a means the arrow from O to A is called a.

    To find an unknown vector, find a route along arrows you know, from the start to the end.

    • Going along an arrow adds its vector.
    • Going against an arrow subtracts it (add its opposite).

    Key idea: write the route in letters first, such as AB = AO + OB, then replace each part with a vector, then simplify. Collect the as and the bs.

    Worked example: a triangle

    In triangle OAB, OA = a and OB = b. Find AB in terms of a and b.

    1. Route from A to B: go from A back to O, then from O to B.
    2. AB = AO + OB.
    3. AO is the opposite of OA, so AO = −a. OB = b.
    4. AB = −a + b = b − a.

    Worked example: a parallelogram

    OACB is a parallelogram. OA = a and OB = b. Find OC and AC.

    1. In a parallelogram, opposite sides are equal and parallel, so AC = OB = b and BC = OA = a.
    2. OC = OA + AC = a + b.
    3. AC is equal to OB, so AC = b.

    Now you finish it

    In the same parallelogram, find CB in terms of a and b.

    1. CB goes from C to B. Which side is parallel to it?
    2. CB is the opposite direction to OA, so CB = ___.
    Check my answer

    BC is equal to OA = a, so CB (the way back) is −a.

    Check your knowledge: vectors in diagrams

    In triangle OAB, OA = a and OB = b. Find the vector AB in terms of a and b. Type it in letters, like 2a + b.

    1. Find a route from A to B using O.
    2. AB = AO + OB. What is AO?
    • That is BA, the journey the other way. AB goes from A to B.
    • That adds them. To get from A to B you go back along OA (that is −a) and then along OB.

    AB = AO + OB = −a + b = b − a.

    6. Midpoints, ratios and straight lines

    Vectors make geometry questions short.

    • Midpoint. If M is the Midpoint of AB, then AM = 1 over 2AB. In terms of position: OM = OA + 1 over 2AB = 1 over 2(a + b).
    • Ratio. If P is on AB with AP : PB = m : n, then AP = m over (m + n) AB. For 1 : 2, P is one third of the way from A to B.
    • Straight lines. Three points are in a straight line (they are collinear) if AB and BC are parallel. Because they share the point B, the two arrows must lie along one line.

    Key idea: to show A, B and C are collinear, show that AB and BC are multiples of each other, and say that they share B.

    Worked example: a ratio

    A is (1, 2) and B is (7, 5). P is on AB with AP : PB = 1 : 2. Find the coordinates of P.

    1. AB = B − A = (6, 3).
    2. AP is 1 over 3 of AB, because 1 + 2 = 3 parts and AP is 1 part: AP = (2, 1).
    3. P = A + AP = (1 + 2, 2 + 1) = (3, 3).

    Worked example: collinear points

    A is (1, 2), B is (3, 5) and C is (7, 11). Show that A, B and C are in a straight line.

    1. AB = (3 − 1, 5 − 2) = (2, 3).
    2. BC = (7 − 3, 11 − 5) = (4, 6).
    3. BC = 2 × AB, so AB and BC are parallel.
    4. They share the point B, so A, B and C are collinear (on one straight line).

    Now you finish it

    A is (1, 1), B is (4, 3) and C is (10, 7). Are A, B and C in a straight line?

    1. AB = (___, ___) and BC = (___, ___).
    2. BC = ___ × AB, so they are parallel.
    3. They share B, so they ___ in a straight line.
    Check my answer

    AB = (3, 2) and BC = (6, 4). BC = 2AB, so the lines are parallel. They share B, so A, B and C are on one straight line.

    7. Simple vector proofs

    A proof uses vectors to show that a fact is always true. A good proof has three parts.

    1. Write the vectors you need in terms of a and b (find routes).
    2. Simplify, and show that one is a multiple of another, or that two are equal.
    3. Finish with a sentence: “so they are parallel”, “they share the point B, so A, B, C are collinear”, or “so ABCD is a parallelogram”.

    Key idea: parallel is not enough for collinear. You also need the vectors to share a point.

    Worked example

    OA = a and OB = b. M is the midpoint of OA and N is the midpoint of OB. Show that MN is parallel to AB.

    1. OM = 1 over 2a and ON = 1 over 2b.
    2. MN = MO + ON = −1 over 2a + 1 over 2b = 1 over 2(b − a).
    3. AB = b − a, so MN = 1 over 2AB.
    4. MN is a multiple of AB, so MN is parallel to AB (and half as long).

    Now you finish it

    P, Q and R are points with PQ = a + 2b and QR = 3a + 6b. Show that P, Q and R are in a straight line.

    1. QR = 3(a + 2b) = 3 × ___.
    2. So QR and PQ are ___.
    3. They share the point ___, so P, Q and R are collinear.
    Check my answer

    QR = 3(a + 2b) = 3PQ. So QR and PQ are parallel. They share the point Q, so P, Q and R are in a straight line.

    Flip it: run it backwards

    Forwards, you are given two points and write the journey as a vector. Backwards, you are given the vector and need the journey: where it starts, where it ends, or how to describe it in words.

    Forwards

    A(1, 2), B(5, 5): AB = ?

    End minus start: (4, 3).

    Backwards

    A(1, 2), AB = (4, 3): B = ?

    Start plus vector: (5, 5).

    • Find the end: end = start + vector.
    • Find the start: start = end − vector.
    • Words: ab means the top number right (or left if negative) and the bottom number up (or down if negative).
    • Find a missing number: use the information given (a magnitude, or “is parallel to”) to make an equation.

    Key idea: writing a journey as a vector and reading a journey from a vector are two directions of the same road. Check by going back.

    2. A = (6 − 2, 1 − (−3)) = (4, 4).
    3. Check: (4, 4) + (2, −3) = (6, 1). ✓

    2. k² + 16 = 25, so k² = 9.

    Why it works

    • A vector is a journey, not a place. Moving by (3, 2) from any start goes the same distance in the same direction, so equal vectors can be drawn anywhere.
    • Adding vectors is doing journeys one after another. The across moves add and the up moves add, which is why you add tops with tops and bottoms with bottoms.
    • A scalar stretches. 3a is three journeys of a in a row, so it points the same way and is three times as long. A minus sign turns it round.
    • Magnitude is Pythagoras. The across and up moves are the two short sides of a right-angled triangle. The arrow is the long side.
    • Parallel plus a shared point is a straight line. Two parallel arrows could be on different lines. If they also start at the same point, they must be on one line.
    • Proofs work for every shape. Letters stand for any vectors, so a proof with a and b works however long the sides are, and not just for one drawing.

    Common traps

    • Finding AB as start minus end. It is end minus start.
    • Adding the top number of one vector to the bottom number of another.
    • Forgetting to change both signs for the opposite vector.
    • Adding the numbers of a vector to find its length, instead of squaring first.
    • Saying two vectors are parallel because the numbers are close, not because one is a multiple of the other.
    • Proving parallel and forgetting to say they share a point when the question asks for a straight line.

    AB = (−4, 4). Half = (−2, 2). Midpoint of AB = (6 − 2, 1 + 2) = (4, 3). The midpoint of OC is half of (8, 6) = (4, 3). It is the same point, so the diagonals of a parallelogram cut each other in half. With vectors: the midpoint of AB is 1 over 2(a + b), and so is the midpoint of OC.

    Find numbers m and n so that m21 + n13 = 711. Type your answer as m, n, like (4, 1) if m = 4 and n = 1.

    1. Write one equation for the tops and one for the bottoms.
    2. 2m + n = 7 and m + 3n = 11. Solve them like simultaneous equations.
    • That swaps m and n. Check: 3(2, 1) + 2(1, 3) = (8, 9), not (7, 11).
    • Check both lines: 2(2, 1) + 2(1, 3) = (6, 8), not (7, 11).

    Tops: 2m + n = 7. Bottoms: m + 3n = 11. From the first, n = 7 − 2m. Put it in the second: m + 3(7 − 2m) = 11, so m + 21 − 6m = 11, so −5m = −10 and m = 2. Then n = 7 − 4 = 3. The answer is (2, 3). Check: 2(2, 1) + 3(1, 3) = (4 + 3, 2 + 9) = (7, 11).
