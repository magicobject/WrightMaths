Negative numbers

Numbers below zero: how to order them, add and subtract them, multiply and divide them, and the sign rules that tell you which way to go.

GCSE Maths Book / Negative numbers

Before you start: what this stands on

Maths is built like a pyramid, each topic standing on the ones below. This topic needs:

  • Add, subtract, multiply, divide Number

The "Last time" questions below are a quick check of that base. If they feel shaky, build the base first.

Words you need

Tap a teal word anywhere on the page to see this again.

Negative number
A number below zero, written with a minus sign. On a number line it is to the left of zero.
Number line
A straight line with numbers marked at equal spacing, increasing from left to right. It continues on the left of zero for negative numbers.
Integer
A whole number. It can be positive, negative or zero.
Difference
The result of subtracting the smaller number from the larger: how far apart two numbers are.

A few questions use a letter such as x for a number we do not know yet. Treat it as a blank box: x + 2x = 3x means 1 box plus 2 boxes. Algebra basics explains it fully.

The temperature is −4°C and rises by 9 degrees. What is the new temperature in °C?

  1. Picture a thermometer. Go up 4 to reach 0, then up 5 more.
  • That adds 4 and 9. The start is below zero: up 4 to 0, then 5 more.
  • It rises, so it ends higher than −4.

−4 + 9 = 5.

63 − 28 = 35.

7 × 9 = 63.

1. The number line

A negative number is below zero. On a number line the numbers keep going to the left of zero. The further left you go, the smaller the number.

… −3, −2, −1, 0, 1, 2, 3 …

Key idea: bigger numbers are further to the right. So −2 is bigger than −10, even though 10 looks bigger than 2. A debt (money you owe) of £2 is better than a debt of £10. (£ means pounds, the UK money.)

Try it: which is smaller, −3 or −8?

Worked example

Put −7, 3, −2 and 0 in order from smallest to largest.

  1. Negatives are smaller than zero. The further from zero, the smaller.
  2. So −7 is smallest, then −2.
  3. Then 0, then 3.
  4. −7, −2, 0, 3.

Check your knowledge: the number line

Which is the biggest: −7, −2 or −10?

  • −7
  • −2
  • −10
  1. Picture the number line. Which is furthest to the right?

−2 is closest to zero, so it is the biggest.

Which is the smaller number: −8 or −3?

  • −8
  • −3
  1. Which is further to the left?

−8 is further left, so it is smaller.

What number is halfway between −6 and 2?

  1. Find the distance between them, then halve it.
  2. −6 up to 0 is 6, then 2 more. That is a gap of 8. Half of 8 is 4. Start at −6 and go up 4.
  • That is −6 + 2. You added. Find the middle: halve the gap.
  • 4 is half the gap, not the position. Start at −6 and go up 4.

−6 + 4 = −2.

How far is −3 from 4 on the number line?

  1. Count from −3 up to 0, then on to 4.
  • That is 4 − 3. −3 is on the other side of zero: add the distances.

3 to reach zero, then 4 more: 7.

What is 3 more than −5?

  1. Start at −5 and go up 3.
  • That goes down. “More” means up the number line.
  • That is 5 − 3. Start at −5 and go up 3. You do not reach zero.

−5 + 3 = −2.

2. Adding and subtracting positive numbers

Think of the number line (or a thermometer). Adding a positive number moves you right (up). Subtracting a positive number moves you left (down).

Key idea: start at the first number, then move. −3 + 5: start at −3, go up 5, land on 2. −4 − 3: start at −4, go down 3, land on −7.

Try it: work out −2 + 5.

Worked example

Work out −6 + 10.

  1. Start at −6.
  2. Go up 10: up 6 reaches 0, then 4 more.
  3. −6 + 10 = 4.

Check your knowledge: adding and subtracting

Work out −3 + 5.

  1. Start at −3 and move 5 up.
  • Adding moves you up the line.
  • You ignored the minus sign. The 3 is below zero.

−3 + 5 = 2.

Work out −4 − 3.

  1. Start at −4 and move 3 down.
  • Subtracting moves you down, away from zero.
  • You began at −4 and went down, so it is negative.

−4 − 3 = −7.

Work out 2 − 7.

  1. Start at 2, go down 7: 2 reaches zero, then 5 more below.
  • You did 7 − 2. Going down 7 from 2 passes zero.

2 − 7 = −5.

Work out −6 + 10.

  1. Up 6 gets to 0, then 4 more.
  • Going up 10 from −6 passes zero.
  • The start is −6, not 6.

−6 + 10 = 4.

The temperature is 3°C and falls by 8 degrees. What is the new temperature in °C?

  1. 3 − 8.
  • It falls below zero, so it is negative.

3 − 8 = −5°C.

3. Subtracting a negative

This step feels odd at first. Subtracting a negative adds. It is the same as adding the positive number.

5 − (−3) = 5 + 3 = 8

Key idea: subtracting a debt makes you richer. If someone takes away a £3 debt of yours, you are £3 better off. So 5 − (−3) is 5 + 3.

Counters and zero pairs

A + counter and a − counter cancel (a zero pair), so you can slip in zero pairs, take the − counters away and see what is left.

5 − (−3) = 8

Try it: work out 4 − (−1).

Worked example

Work out −2 − (−6).

  1. Change “− (−6)” to “+ 6”.
  2. −2 + 6 = 4.

And adding a negative is the same as subtracting the positive: 3 + (−5) = 3 − 5 = −2.

Check your knowledge: subtracting negatives

Work out 5 − (−3).

  1. Subtracting a negative adds.
  • That is 5 − 3. Subtracting a negative adds.
  • That is −5 − 3. The 5 stays positive, and subtracting −3 adds 3.

5 − (−3) = 5 + 3 = 8.

Work out −2 − (−6).

  1. Change to −2 + 6.
  • That is −2 − 6. Subtracting a negative adds.

−2 + 6 = 4.

A player has 3 points. A trap adds −5 points. What is the score now?

  1. Adding a negative is the same as subtracting.
  • Adding a negative makes the answer smaller.
  • That is 5 − 3. Adding −5 takes you down 5, past zero.

3 + (−5) = 3 − 5 = −2.

Work out −4 − (−4).

  1. Subtracting a negative adds: −4 + 4.
  • That takes away a positive 4. Here the 4 is negative.
  • That is 4 + 4. The first number is −4, so go up from −4.

−4 + 4 = 0.

Work out 7 − (−2) + (−3).

  1. Do it left to right: first 7 − (−2).
  2. Then add (−3), which is the same as subtracting 3.
  • That adds the 3. Adding −3 takes 3 away.
  • Check step one: 7 − (−2) is 7 + 2 = 9, not 5.

7 + 2 = 9, then 9 − 3 = 6.

4. Multiplying and dividing

For multiplying and dividing, work out the size as usual. Then decide the sign with one rule:

same signs → positive
different signs → negative

This is for non-zero numbers. If either number is 0, the answer is 0 (0 × (−3) = 0), with no sign at all.

Why? First a picture of why it is believable. In this pattern the second number stays at −2.

  • 3 × (−2) = −6
  • 2 × (−2) = −4
  • 1 × (−2) = −2
  • 0 × (−2) = 0

The answers go up by 2 each time, so the pattern suggests the next answer is 2: (−1) × (−2) = 2. A pattern is a picture, not a proof. Here is the reason.

We want (−1) × (−2) to keep the usual rules, including brackets: (−1) × (2 + (−2)) = (−1) × 0 = 0. Multiplying out the brackets, (−1) × 2 + (−1) × (−2) = 0, which is −2 + (−1) × (−2) = 0. The only number that makes −2 add up to 0 is 2, so (−1) × (−2) must be 2.

Key idea: (−5) × (−6): same signs, so positive: 30. 3 × (−4): different signs, so negative: −12. Division undoes multiplication, so it follows the same rule (for non-zero numbers; you cannot divide by 0).

Try it: work out 2 × (−5).

Worked example

Work out −20 ÷ (−4).

  1. Size: 20 ÷ 4 = 5.
  2. Signs: both negative, so the same signs: positive.
  3. −20 ÷ (−4) = 5.

Check your knowledge: multiply and divide

A quiz game takes away 4 points for each wrong answer. Zara gets 3 answers wrong. What is the change in her score?

  1. 3 wrong answers, each worth −4: 3 × (−4).
  • Points are taken away, so the score goes down. It is negative.
  • You added 3 and −4. It is 3 lots of −4: multiply.

3 × 4 = 12, with different signs the answer is negative: −12.

Work out (−5) × (−6).

  1. Same signs.
  • Two negatives multiplied give a positive.

5 × 6 = 30, with the same signs it is positive: 30.

Work out −24 ÷ 6.

  1. Different signs.
  • The signs are different, so the answer is negative.

24 ÷ 6 = 4, with different signs: −4.

Work out −20 ÷ (−4).

  1. Same signs.
  • Dividing a negative by a negative gives a positive.

20 ÷ 4 = 5, same signs: 5.

Work out (−2) × 5 × (−3).

  1. Do it in steps: (−2) × 5 first.
  2. Then multiply by (−3).
  • (−2) × 5 = −10. Then × (−3) makes it positive.

(−2) × 5 = −10, then −10 × (−3) = 30. Two negatives make a positive.

Work out (−3) × (−3).

  1. Same signs.
  • Same signs give a positive answer.

3 × 3 = 9, and the answer is positive: 9. (This is also (−3)².)

Flip it: run it backwards

So far you have gone one way. Now run it backwards. Same idea, other direction.

Forwards

−7 + 10 = 3

Add and find where you land.

Backwards

−7 + ? = 3

Find what must be added.

Key idea: to find a missing number, undo what was done to it. Adding undoes subtracting. Multiplying undoes dividing. The signs look strange, but the method is the same.

Forwards

5 − (−3) = 8

Subtracting a negative adds.

Backwards

8 + (−3) = 5

Adding a negative takes away.

Check your knowledge: flip it

−7 + ? = 3. Find the missing number.

  1. From −7, how far up to get to 3?
  • That is −7 + 3. Find how far up from −7 to 3.
  • That is 7 − 3. Go up from −7: 7 to reach zero, then 3 more.
  • It must be positive: you add to move up.

−7 to 0 is 7, then 3 more: 10. Check: −7 + 10 = 3.

? − (−4) = 9. Find the missing number.

  1. Subtracting −4 is the same as adding 4. So ? + 4 = 9.
  • That is 9 + 4. ? + 4 = 9 means take 4 from 9.

? + 4 = 9, so ? = 5. Check: 5 − (−4) = 9.

(−3) × ? = 18. Find the missing number.

  1. Undo with division: 18 ÷ (−3).
  • −3 × 6 = −18, not 18. The missing number is negative.

18 ÷ (−3) = −6. Check: (−3) × (−6) = 18.

The temperature rises from −5°C to 8°C. By how many degrees did it rise?

  1. Count up to zero (5), then on to 8.
  • That is 8 − 5. The start is below zero: add the distances.

5 + 8 = 13 degrees. Check: −5 + 13 = 8.

? ÷ (−2) = 6. Find the missing number.

  1. Undo ÷ (−2) with × (−2).
  • 12 ÷ (−2) = −6, not 6.
  • That is 6 ÷ (−2). Undo a division by multiplying.

6 × (−2) = −12. Check: −12 ÷ (−2) = 6.

5. Negative numbers in real life

Negatives appear in temperatures, bank balances, floors below ground and heights below sea level. “How far apart?” is top minus bottom.

Key idea: the difference between two values is the higher one minus the lower one. From −30 m to 150 m is 150 − (−30) = 180 m.

Try it: the temperature goes from −2°C to 6°C. How many degrees is that?

Check your knowledge: in context

  • A bank account is £45 overdrawn (you owe the bank). That is −45.
  • A payment of £120 goes in.

What is the balance in pounds?

  1. −45 + 120.
  • That adds 45 and 120. The account starts below zero.
  • The payment is bigger than the debt, so it is positive.

−45 + 120 = 75. The balance is £75.

A shipwreck is 30 m below sea level (−30 m). A cliff is 150 m above sea level. How many metres higher is the cliff than the wreck?

  1. Top minus bottom: 150 − (−30).
  • That is 150 − 30. The wreck is below zero: add.

150 + 30 = 180 m.

Find the next number in the sequence −8, −5, −2, …

  1. What is added each time?
  • That is the second number. The sequence goes up by 3 each time.
  • That adds 1. The sequence goes up by 3 each time, so −2 + 3.

It goes up by 3 each time: −2 + 3 = 1.

A lift (elevator) goes from floor −2 (a basement, below the ground) to floor 5. How many floors does it travel?

  1. 2 floors to reach floor 0, then 5 more.
  • That is 5 − 2. The basement is below ground: add.

2 + 5 = 7 floors.

The temperatures one day were −3, 4, −8 and 0 degrees. What is the range (highest minus lowest)?

  1. Highest is 4, lowest is −8.
  2. 4 − (−8).
  • That is 4 − 0. The lowest is −8, not 0.
  • That is lowest minus highest. Use highest minus lowest.

4 − (−8) = 12 degrees.

Spot the mistake

Ben says: “−3 − 4 = 1.” What went wrong?

  • He did 4 − 3. He ignored the start at −3.
  • Nothing is wrong: 1 is the right answer.
  • Subtracting a negative adds, so it is 7.
  1. Picture the number line: you start at −3 and move 4 to the left.

Start at −3 and go down 4. The answer is −7.

Cara says: “(−2) × (−5) = −10.” What went wrong?

  • Negative times negative is positive.
  • Nothing is wrong: multiplying by a negative always gives a negative answer.
  • She should have added, which gives −7.
  1. Same signs give a positive.

Negative times negative is positive: (−2) × (−5) = 10.

Dan says: “5 − (−2) = 3.” What went wrong?

  • He did 5 − 2, not 5 + 2.
  • Nothing is wrong: 5 − 2 = 3 is the right answer here.
  • It should be −3, because subtracting always takes you down.
  1. Subtracting a debt makes you better off.

5 − (−2) = 5 + 2 = 7. He did 5 − 2, not 5 + 2: subtracting a negative adds.

Check your knowledge: mixed review

A football team has a goal difference of −8. After a win, it goes up by 3. What is the goal difference now?

  1. Start at −8, up 3.
  • That is 8 − 3. The start is −8, and 3 is not enough to reach zero.
  • Adding moves up the line.

−8 + 3 = −5.

Work out 6 − (−6).

  1. Change to 6 + 6.
  • Subtracting a negative adds: 6 + 6, not 6 − 6.
  • That is −6 − 6. The first 6 is positive.

12.

Work out (−2) × (−2) × (−2).

  1. (−2) × (−2) = 4. Then 4 × (−2).
  • Three negatives is an odd number, so it is negative.

4 × (−2) = −8. Three negatives make a negative.

Which is the biggest: −0.5, −0.05 or −5?

  • −0.5
  • −0.05
  • −5
  1. Which is closest to zero?

−0.05 is closest to zero, so it is the biggest.

Work out −12 ÷ (−3) × (−2).

  1. Left to right: −12 ÷ (−3) first.
  • 4 × (−2) is negative.
  • Do the division first, then multiply.

−12 ÷ (−3) = 4, then 4 × (−2) = −8.

Exam style

  • Monday was −3°C.
  • Tuesday was 4°C.
  • The lowest temperatures over five nights were −6, −2, 3, 1 and −4 degrees.

Write your working on paper, then type the answer.

(a) [1 mark] By how many degrees did the temperature rise from Monday to Tuesday?

  1. 4 − (−3).
  • That is 4 − 3. Monday was below zero: add the distances.

4 − (−3) = 4 + 3 = 7 degrees.

(b) [2 marks] Work out the range of the five minimum temperatures.

  1. Highest is 3, lowest is −6.
  2. Range = highest − lowest.
  • That is lowest minus highest. Use highest minus lowest: 3 − (−6).
  • The lowest is −6, not 0.

3 − (−6) = 9 degrees.

  • M1 for picking the highest (3) and lowest (−6) temperatures
  • A1 for 3 − (−6) = 9

(c) [2 marks] A submarine at −120 m rises 45 m. What is its new depth, as a number in metres (use a minus sign)?

  1. −120 + 45.
  • It is still below sea level, so it is negative.
  • It rises, so go up: add 45.

−120 + 45 = −75 m.

  • M1 for −120 + 45 (rising means adding)
  • A1 for −75

Going further

Work out (−2)3.

  1. (−2) × (−2) × (−2).
  • Three negatives gives a negative.
  • The power means multiply, not add.

4 × (−2) = −8.

Two numbers multiply to give −12 and add to give 1. What is the larger of the two?

  1. Pairs that multiply to −12: 3 and −4, −3 and 4, 2 and −6 …
  2. Which pair adds to 1?
  • That is the smaller one. The larger is positive.

−3 and 4: −3 × 4 = −12 and −3 + 4 = 1. The larger is 4. (This is the idea behind factorising quadratics.)

In this magic square every row, every column and both long diagonals add up to the same total (you are not told it). Find the number x in the bottom-left corner.

  1. Is there a line of three where you can see every number?
  2. That line tells you the magic total. Which other line through x has just one number missing?
  3. The line from the top-right corner through the middle to x: 1 + 0 + x equals the total.
  • That is the top-right number. You need the number that makes 1 + 0 + x equal the total, so it must cancel the 1.
  • 0 is the magic total, not x. Now use 1 + 0 + x = 0.
  • That is already in the top-left corner. Use the line 1 + 0 + x.

The diagonal −3 + 0 + 3 = 0 shows the magic total is 0. The other diagonal is 1 + 0 + x = 0, so x = −1. Check the bottom row: −1 + (−2) + 3 = 0.

Take any 5 whole numbers, positive or negative. Two of them must have a difference that is a multiple of 4. (For example, −3 and 5 have difference 8.) Which is the key idea in the proof?

  • There are only 4 possible remainders on dividing by 4, so two of the 5 numbers share one.
  • There are 10 pairs of numbers, and so many differences that one of them must be a multiple of 4.
  • Subtracting a negative number is the same as adding, so the difference is always a multiple of 4.
  1. What are the possible remainders when a whole number is divided by 4?
  2. If you have more numbers than remainders, what must happen?
  3. If two numbers both leave remainder r, write them as 4p + r and 4q + r. What is their difference?

There are only 4 possible remainders on dividing by 4, so two of the 5 numbers share one. Write them as 4p + r and 4q + r. Their difference is 4p − 4q = 4(p − q), a multiple of 4. Negative numbers have remainders too: −3 = 4 × (−1) + 1, so −3 and 5 = 4 × 1 + 1 both have remainder 1, and 5 − (−3) = 8.

A student says: “−x is always negative. Check x = 3: −x = −3. Check x = 5: −x = −5. Both negative, so it is always true.” Which sentence names the flaw?

  • x could be negative: if x = −2 then −x = 2.
  • −x is always positive, so the claim is the wrong way round.
  • She should have tried at least ten positive numbers before being sure it was true.
  1. The student only tried 3 and 5. What kind of number did she leave out?
  2. Try different kinds of number for x, not just positive ones.

x could be negative: if x = −2 then −x = −(−2) = 2, which is positive. So the claim is false, and two examples that happen to work do not prove it. A letter can stand for a negative number as well as a positive one.

Why it works

  • The number line goes both ways. Adding moves right, subtracting moves left, and the signs just tell you the direction.
  • Subtracting a negative adds because taking away a debt leaves you better off.
  • The sign rules: same signs, positive; different signs, negative. The pattern 3 × (−2), 2 × (−2), 1 × (−2) … makes it believable, and (−1) × (2 + (−2)) = 0 proves it. Division undoes multiplication, so it follows the same rule.

Common traps

  • Thinking −10 is bigger than −2.
  • Treating −3 − 4 as 4 − 3.
  • Forgetting that subtracting a negative adds.
  • Ignoring the signs when multiplying. For non-zero numbers, an odd number of negatives gives a negative and an even number gives a positive. If any factor is 0, the answer is 0.
  • Losing a sign in the last step of a long calculation.
