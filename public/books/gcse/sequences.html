    Sequences

    A sequence is a list of numbers that follows a rule. Learn to carry a pattern on, to find any term from its position, and to write the rule for a pattern you are given.

    Where you will use this: the risers of a staircase, rows of tiles, a fixing cost that grows by the same amount each time, and a savings plan.

    Sequence
    A list of numbers that follow a rule. Each number is a term of the sequence.
    nth term
    A formula that gives any term of a sequence from its position n.
    Term-to-term rule
    A rule that tells you how to get from one term of a sequence to the next.
    Common difference
    The amount a linear sequence goes up or down by each time. It is also the number in front of n in the nth term.

    Letters and positions

    n stands for the position of a term. n = 1 is the 1st term, n = 2 is the 2nd term, and so on.

    3n means 3 × n. In 3n + 2, work out the 3n first, then add 2.

    “The 10th term” means the term where n = 10.

    1. Term-to-term rules

    A Sequence is a list of numbers in order. Each number is a Term. The sequence 3, 7, 11, 15 … has the 1st term 3, the 2nd term 7, and so on.

    A Term-to-term rule tells you how to get from one term to the next. To find it, look at the gaps between the terms.

    Each gap here is 4, so the rule is add 4. When the gap is always the same, it is called the Common difference. If the terms go down, the gap is negative: 20, 17, 14 … has a common difference of −3, so the rule is subtract 3.

    Key idea: to carry a sequence on, find the gap, then apply it again and again to the last term you have.

    Try it: carry on 2, 5, 8, 11 … for two more terms. (What is the gap?)

    Worked example

    Write the next two terms of 50, 44, 38, 32 …

    1. 44 − 50 = −6, and 38 − 44 = −6. The rule is subtract 6.
    2. 32 − 6 = 26.
    3. 26 − 6 = 20. The next two terms are 26 and 20.

    Now you finish it

    Write the next two terms of 7, 12, 17, 22 …

    1. 12 − 7 = ___, so the rule is add ___.
    2. 22 + ___ = ___.
    3. ___ + ___ = ___. The next two terms are ___ and ___.
    Check my answer

    The gap is 5. 22 + 5 = 27 and 27 + 5 = 32. The next two terms are 27 and 32.

    2. Finding any term from its position

    The term-to-term rule is slow if you want the 50th term, because you would have to write all the terms before it. A faster way is a formula that uses the position, n. It is called the nth term, or the Position-to-term rule.

    For 3, 7, 11, 15 … the nth term is 4n − 1. To check, Substitute n = 1, 2, 3, 4 into it:

    The terms of 4n − 1
    n1234
    4n − 1371115

    To find the 20th term, put n = 20 into the formula: 4 × 20 − 1 = 79. You do not need the 19 terms before it.

    Key idea: n is the position. Replace n with the position you want, then follow the BIDMAS order: multiply first, then add or subtract.

    Try it: the nth term is 5n + 2. What is the 4th term? (Put n = 4.)

    Worked example

    The nth term of a sequence is 5n + 2. Find the 1st term, the 2nd term and the 10th term.

    1. n = 1: 5 × 1 + 2 = 7.
    2. n = 2: 5 × 2 + 2 = 12.
    3. n = 10: 5 × 10 + 2 = 52.

    Now you finish it

    The nth term is 3n − 4. Find the 8th term.

    1. Put n = 8: 3 × ___ − 4.
    2. 3 × 8 = ___.
    3. ___ − 4 = ___.
    Check my answer

    3 × 8 = 24 and 24 − 4 = 20.

    • That looks like 3 and 10 side by side (310). 3n means 3 times n.

    3 × 10 = 30, then 30 − 2 = 28.

    The nth term of a sequence is 4n − 10. What is the 1st term?

    1. Put n = 1 into the rule.
    2. Work out 4 × 1 first, then subtract 10. Will you go below zero?
    • That looks like 10 − 4. The rule is 4 − 10, so you go below zero.
    • That looks like taking 4 away as well. The 4n part is added, as 4 × 1 = 4.

    Each riser of a staircase is 18 cm high. The top of step n is 18n cm above the floor. How high above the floor is the top of step 14? Answer in cm.

    2. Put n = 14 into 18n.

    • That looks like step 13. Step 14 means n = 14.

    • 32
    • 35 (the 7n part only)
    • 9 (7 + 5 − 3)
    1. Put n = 5 into the rule.
    2. Work out 7 × 5, then subtract 3.

    7 × 5 = 35, then 35 − 3 = 32.

    3. Finding the nth term of a linear sequence

    A Linear sequence goes up (or down) by the same amount every time. Its nth term always looks like an + b, where a is the common difference.

    1. Find the common difference. Call it a.
    2. Write the terms of an: the 1st is a, the 2nd is 2a, and so on.
    3. Compare with the sequence. What must you add or take away to match it? That is b.

    Here is a pattern made of matchsticks. Pattern n is a row of n squares.

    Pattern 1 uses 4 matchsticks, pattern 2 uses 7 and pattern 3 uses 10. The gap is 3, because each new square needs 3 more matchsticks. 3n gives 3, 6, 9, so you need to add 1 each time. The nth term is 3n + 1. The extra 1 is there because the first square needs 4 matchsticks, but the others only need 3, as they share a side.

    Key idea: the gap goes in front of n. Then check n = 1 and fix the start. A good check is to put n = 1, 2, 3 into your answer and see the sequence again.

    Try it: use 3n + 1 to find how many matchsticks make a row of 20 squares. (Put n = 20.)

    Worked example

    Find the nth term of 5, 8, 11, 14 …

    1. The gap is 3, so start with 3n: 3, 6, 9, 12.
    2. The sequence is 2 more each time, so add 2.
    3. The nth term is 3n + 2.
    4. Check n = 4: 3 × 4 + 2 = 14. ✓

    Worked example: a sequence that goes down

    Find the nth term of 20, 17, 14, 11 …

    1. The gap is −3, so start with −3n: −3, −6, −9, −12.
    2. To get from −3, −6, −9, −12 to 20, 17, 14, 11, you add 23 to each term.
    3. The nth term is −3n + 23, which you can also write as 23 − 3n.
    4. Check n = 1: −3 + 23 = 20. ✓

    Now you finish it

    Find the nth term of 6, 10, 14, 18 …

    1. The gap is ___, so start with ___n: ___, ___, ___, ___.
    2. To reach 6, 10, 14, 18 you add ___ to each term.
    3. The nth term is ___n + ___.
    Check my answer

    The gap is 4, so 4n gives 4, 8, 12, 16. Add 2 to reach 6, 10, 14, 18. The nth term is 4n + 2.

    Check your knowledge: the nth term

    Find the nth term of the sequence 4, 7, 10, 13 …

    1. Find the gap between neighbouring terms.
    2. Write the gap times n. Then see what you must add or take away to match the sequence.
    • That looks like the gap times n only. 3n gives 3, 6, 9, 12 but the sequence starts at 4, so something must be added.
    • That looks like the gap added to n. The gap goes in front of n, as 3n.

    The gap is 3, so start with 3n: 3, 6, 9, 12. The sequence is 1 more each time: 4, 7, 10, 13. The nth term is 3n + 1.

    Find the nth term of the sequence 2, 8, 14, 20 …

    1. What is the gap each time?
    2. Write that gap times n, then compare with the sequence.
    • That looks like the gap times n only. 6n gives 6, 12, 18, 24, which is 4 too big.
    • That looks like adding the difference the wrong way round. The sequence is smaller than 6n, so you take something away.

    The gap is 6, so start with 6n: 6, 12, 18, 24. The sequence is 4 less each time: 2, 8, 14, 20. The nth term is 6n − 4.

    Find the nth term of the sequence 9, 7, 5, 3 …

    1. The terms are going down. What is the gap, with its sign?
    2. Write the gap times n, then compare with the sequence.
    • That looks like using +2n. The sequence goes down, so the number in front of n is negative.
    • That looks like using the first term as the number to add. Check n = 1: −2 + 9 = 7, not 9.

    The gap is −2, so start with −2n: −2, −4, −6, −8. To reach 9, 7, 5, 3 you add 11 to each term. The nth term is −2n + 11 (or 11 − 2n).

    2. That gap goes in front of n. Then compare with the sequence 8, 12, 16 and fix the start.
    • That looks like the gap times n only. 4n gives 4 for one section, but 8 slabs are needed.
    • That looks like using the first term as the number in front of n. The count goes up by 4 for each section, so the number in front of n is 4.

    4. Is this number in the sequence?

    To test whether a number is a term, set the nth term equal to the number and Solve for n. A position is a whole number: 1st, 2nd, 3rd. So:

    • If n comes out as a whole number (1 or more), the number is in the sequence, and n tells you which term it is.
    • If n comes out as a decimal or a fraction, the number is not in the sequence.

    Key idea: undo the sum in the opposite order. For 4n − 1 = 99, add 1 first (4n = 100), then divide by 4 (n = 25).

    Try it: is 30 in the sequence 4n − 1? (Solve 4n − 1 = 30. Is n whole?)

    Worked example

    The nth term is 4n − 1. Is 99 a term? Is 100 a term?

    1. 4n − 1 = 99, so 4n = 100 and n = 25. A whole number, so 99 is the 25th term.
    2. 4n − 1 = 100, so 4n = 101 and n = 25.25. Not a whole number, so 100 is not in the sequence.

    Now you finish it

    The nth term is 5n + 2. Is 62 a term?

    1. 5n + 2 = 62, so 5n = ___.
    2. n = ___ ÷ 5 = ___.
    3. Is n whole? So 62 ___ in the sequence.
    Check my answer

    5n = 60, so n = 12. That is a whole number, so 62 is the 12th term.

    3. Work out the terms for those two positions and pick the first one over 100.

    5. Other kinds of sequence

    Not every sequence has a common difference. Two more kinds turn up a lot, and for these you usually only need to carry them on.

    Multiplying each time

    A Geometric sequence multiplies by the same number each time. 2, 6, 18, 54 … multiplies by 3. You can also multiply by a fraction, which makes the terms smaller: 80, 40, 20, 10 … multiplies by 1 over 2, which is the same as dividing by 2.

    Adding the last two terms

    In a Fibonacci-type sequence, each term is the sum of the two terms before it. The famous one starts 1, 1, 2, 3, 5, 8, 13 … But it can start with any two numbers: 3, 4, 7, 11, 18 …

    Key idea: test the gaps first. If they are not equal, divide each term by the one before it. If those answers are all the same, the sequence multiplies by that number. If each term is the sum of the last two, it is Fibonacci-type.

    Try it: carry on 1, 3, 9, 27 … for one more term. (What do you multiply by?)

    Worked example: multiplying

    Write the next two terms of 5, 10, 20, 40 …

    1. 10 ÷ 5 = 2 and 20 ÷ 10 = 2, so multiply by 2.
    2. 40 × 2 = 80 and 80 × 2 = 160.

    Now you finish it

    Write the next two terms of 1, 3, 4, 7 … where each term is the sum of the two before.

    1. 3 + 4 = 7, so the rule works.
    2. The next term is 4 + 7 = ___.
    3. The one after is 7 + ___ = ___.
    Check my answer

    4 + 7 = 11 and 7 + 11 = 18. The next two terms are 11 and 18.

    Check your knowledge: multiplying and Fibonacci-type sequences

    2. 6 is 3 × 2 and 12 is 6 × 2. Multiply by the same number each time.
    • That looks like only the first of the two terms. Give both, with a comma between them.
    • That looks like adding 6 each time. The gaps are not the same, so the rule is not adding.

    2. 81 ÷ 27 = 3. Each term is the last one divided by the same number.
    • That looks like taking 3 away. The gaps are 54, 18, 6, so they are not equal: the rule is divide by 3.
    • That looks like carrying on taking away. The rule is divide by 3.

    81 ÷ 3 = 27, 27 ÷ 3 = 9 and 9 ÷ 3 = 3. The rule is divide by 3, so the next term is 3 ÷ 3 = 1.

    2. You want the same answer every time.

    2. Each length is half of the last one. Keep going until you reach the 6th.

    6. Quadratic sequences Higher

    In a Quadratic sequence, the gaps themselves change by the same amount each time, so the nth term has an n² in it. Look at 3, 8, 15, 24 …: the first differences are 5, 7, 9, and the second differences are 2, 2.

    The nth term has the form an² + bn + c, and a is half the second difference.

    1. Find the first differences, then the second differences.
    2. Half the second difference is a. Write the terms of an².
    3. Subtract these terms from the terms of the sequence. What is left is linear: find its nth term as in section 3.

    Worked example

    Find the nth term of 4, 9, 18, 31 …

    1. First differences: 5, 9, 13. Second differences: 4, 4.
    2. Half of 4 is 2, so start with 2n²: 2, 8, 18, 32.
    3. Sequence minus 2n²: 4 − 2 = 2, 9 − 8 = 1, 18 − 18 = 0, 31 − 32 = −1. That is 2, 1, 0, −1, with nth term −n + 3.
    4. The nth term is 2n² − n + 3. Check n = 4: 32 − 4 + 3 = 31. ✓

    Now you finish it

    Find the nth term of 2, 7, 14, 23 …

    1. First differences: 5, 7, 9. Second differences: ___, ___. Half of that is ___.
    2. n² gives 1, 4, 9, 16. Sequence minus n² is 1, 3, 5, 7.
    3. 1, 3, 5, 7 has nth term ___n − ___. So the nth term is n² + ___n − ___.
    Check my answer

    The second differences are 2, 2, half is 1. 1, 3, 5, 7 goes up by 2, so it is 2n − 1. The nth term is n² + 2n − 1. Check n = 4: 16 + 8 − 1 = 23. ✓

    Check your knowledge: quadratic sequences Higher

    Find the nth term of the quadratic sequence 2, 6, 12, 20 … Type it like n^2 + 3n.

    1. Work out the first differences, then the second differences.
    2. Half the second difference is the number in front of n². Take that many n² from the terms.
    3. Look at what is left over. Is it a simple linear sequence?
    • That looks like only the n² part. n² gives 1, 4, 9, 16, so there is something left over.
    • That looks like the second difference used as the number in front of n. Half of it goes in front of n².

    First differences: 4, 6, 8. Second differences: 2, 2. Half of 2 is 1, so start with n²: 1, 4, 9, 16. Take these from the sequence: 1, 2, 3, 4, which is n. The nth term is n² + n.

    Find the nth term of the quadratic sequence 5, 11, 21, 35 … Type it like 3n^2 + n.

    1. Work out the first and second differences.
    2. Half the second difference goes in front of n².
    3. Take that part from each term and see what is left.
    • That looks like only the 2n² part. 2n² gives 2, 8, 18, 32, which is not quite the sequence.
    • That looks like using the whole second difference. Half of it goes in front of n².

    First differences: 6, 10, 14. Second differences: 4, 4. Half of 4 is 2, so start with 2n²: 2, 8, 18, 32. Take these from the sequence: 3, 3, 3, 3. The nth term is 2n² + 3.

    Pattern n is a square of n rows of n dark dots, plus 2 pink dots. Write the nth term for the total number of dots. Type it like n^2 + 3n.

    1. How many dark dots are in pattern n? Think rows times dots in each row.
    2. How many pink dots are there in every pattern?
    • That looks like only the square. Add the pink dots as well.
    • That looks like a single row of dark dots. The dark dots fill n rows.

    The square has n × n = n² dark dots and there are always 2 pink dots. The nth term is n² + 2. (Check: 3, 6, 11 for patterns 1, 2, 3.)

    Flip it: from the rule to the pattern, and back

    You can go from the rule to the terms, or from the terms back to the rule.

    Continuing the pattern

    nth term 4n + 3 → 7, 11, 15, 19 …

    Put n = 1, 2, 3 into the rule. Write the terms out.

    Writing the rule

    7, 11, 15, 19 … → nth term ?

    Find the gap, put it in front of n, then fix the start.

    Key idea: use the term-to-term rule to carry a pattern on a few steps. Use the nth term to jump to a far-off term, or to test a number.

    You can also write the rule when you only know two terms of a linear sequence. The terms between them rise by equal amounts, so divide the total rise by the number of steps.

    Worked example: from two terms

    The 3rd term of a linear sequence is 11 and the 7th term is 27. Find the nth term.

    1. From the 3rd to the 7th term is 4 steps. The terms rise by 27 − 11 = 16.
    2. Each step is 16 ÷ 4 = 4, so the nth term starts 4n.
    3. When n = 3, 4n = 12, but the term is 11, so take away 1.
    4. The nth term is 4n − 1. Check n = 7: 28 − 1 = 27. ✓

    Now you finish it

    The 2nd term is 13 and the 6th term is 29. Find the nth term.

    1. From the 2nd to the 6th is ___ steps and the terms rise by ___.
    2. Each step is ___, so the nth term starts ___n.
    3. When n = 2, ___n = ___, but the term is 13, so add ___.
    Check my answer

    4 steps and a rise of 16, so each step is 4. 4n gives 8 when n = 2, so add 5. The nth term is 4n + 5. Check n = 6: 24 + 5 = 29. ✓

    Check your knowledge: flip it

    Write the first three terms of the sequence with nth term 4n + 3. Type them with commas, like 2, 4, 6.

    1. For the 1st term put n = 1. For the 2nd put n = 2, and so on.
    2. Work out 4 × n first, then add 3.
    • That looks like only the first term. Give all three, with commas.
    • That looks like 4n only. Add the 3 as well.

    n = 1: 4 + 3 = 7. n = 2: 8 + 3 = 11. n = 3: 12 + 3 = 15. The terms are 7, 11, 15.

    A sequence starts 2, 6, 10, 14 … Write the nth term of this sequence.

    1. What is the gap each time?
    2. Write the gap times n and compare with the sequence.
    • That looks like adding instead of taking away. 4n + 2 gives 6 for the 1st term, not 2.
    • That looks like the gap times n only. 4n gives 4, 8, 12, 16, which is 2 too big.

    The gap is 4, so start with 4n: 4, 8, 12, 16. The sequence is 2 smaller each time: 2, 6, 10, 14. The nth term is 4n − 2.

    The 2nd term of a linear sequence is 9 and the 5th term is 18. Write the nth term.

    1. How many steps are there from the 2nd term to the 5th? How much do the terms go up in total?
    2. Share the total rise evenly over the steps to find the gap. That gap goes in front of n.
    3. Then use the 2nd term to find what to add.
    • That looks like the gap times n only. 3n gives 6 for the 2nd term, but it should be 9.
    • That looks like the 2nd term in front of n. The number in front of n is the gap between terms.

    From the 2nd term to the 5th is 3 steps and the terms rise by 18 − 9 = 9, so each step is 9 ÷ 3 = 3. The nth term starts 3n. When n = 2, 3n = 6 but the term is 9, so add 3. The nth term is 3n + 3. Check: the 5th term is 3 × 5 + 3 = 18.

    A linear sequence starts at 5 and goes up by 6 each time. Write the nth term.

    1. The gap goes in front of n.
    2. Check what 6n gives for n = 1, then fix it so the first term is 5.
    • That looks like adding the first term on. 6n + 5 gives 11 for the 1st term.
    • That looks like adding instead of taking away. 6n + 1 gives 7 for the 1st term.

    The gap is 6, so start with 6n. When n = 1, 6n = 6 but the first term is 5, so take away 1. The nth term is 6n − 1.

    The nth term of a sequence is 5n − 4. What is its term-to-term rule?

    • Add 5
    • Add 4 each time
    • Multiply by 5 and subtract 4
    1. Work out the first three terms.
    2. What do you do to get from one term to the next?

    The first three terms are 1, 6, 11. Each is 5 more than the one before, so the rule is add 5.

    Spot the mistake

    Finding an error in someone else’s working helps you learn. For each one, decide what went wrong.

    Lee says: the nth term of 5, 8, 11, 14 … is n + 3, because the sequence goes up by 3. What went wrong?

    • He should have used 3n and fixed the start.
    • Nothing is wrong. The gap is added to n.
    • He should have used the first term, 5n, instead.
    1. Test his rule. Put n = 1, 2, 3 into n + 3. Do you get 5, 8, 11?
    2. The gap tells you how fast the terms grow, so it multiplies n.

    n + 3 gives 4, 5, 6, which goes up by 1. The gap of 3 must multiply n: 3n gives 3, 6, 9, 12, and the sequence is 2 more each time. The nth term is 3n + 2.

    Zoe says: the 10th term of 5, 7, 9, 11 … is 5 + 10 × 2 = 25. What went wrong?

    • There are only 9 steps up to the 10th term.
    • She should have worked out 10 × 5 + 2 instead.
    • Nothing is wrong: 25 is the 10th term.
    1. Test her method on the 2nd term: is it 5 + 2 × 2?
    2. To get from the 1st term to the 10th term, how many steps of 2 do you take?

    The 10th term is the 1st term plus 9 steps of 2: 5 + 9 × 2 = 23. Check with the nth term 2n + 3: 2 × 10 + 3 = 23.

    Check your knowledge: mixed review

    Mixed up on purpose, like a real paper. Work out which method fits.

    Work out the 8th term of the sequence with nth term 9n − 20.

    1. Put n = 8 into the rule.
    2. Work out 9 × 8 first.
    • That looks like 9n only. Take away the 20 as well.

    9 × 8 = 72, then 72 − 20 = 52.

    Find the nth term of the sequence 12, 9, 6, 3 …

    1. The terms are going down by the same amount each time.
    2. The number in front of n is negative. Compare it with the sequence to fix the start.
    • That looks like ignoring that the sequence goes down. The number in front of n is negative.
    • That looks like using the first term as the number to add. Check n = 1: −3 + 12 = 9, not 12.

    The terms go down by 3, so start with −3n: −3, −6, −9, −12. To reach 12, 9, 6, 3 add 15. The nth term is −3n + 15.

    Which is the term-to-term rule for 2, 6, 18, 54 …?

    • Multiply by 3
    • Add 4 each time
    • Add 3 each time
    1. Are the gaps equal?
    2. Try dividing each term by the one before.

    6 ÷ 2 = 3, 18 ÷ 6 = 3 and 54 ÷ 18 = 3. Each term is 3 times the one before.

    Which term of the sequence with nth term 6n − 5 is equal to 91?

    1. Set 6n − 5 equal to 91.
    2. Undo the − 5, then undo the × 6.
    • That looks like 6n. Divide by 6 to find n.
    • That looks like subtracting 5 instead of adding it. To undo − 5, add 5.

    6n − 5 = 91, so 6n = 96 and n = 16. So 91 is the 16th term.

    Each term of this sequence is the sum of the two before it: 1, 1, 2, 3, 5, 8 … What are the next two terms? Type them with a comma, like 8, 6.

    1. Add the last two terms to get the next one.
    2. Then use your new term with the one before it for the one after.
    • That looks like only the first of the two terms. Give both, with a comma between them.

    5 + 8 = 13 and 8 + 13 = 21. The next two terms are 13, 21.

    Exam style

    Use these like a real paper. The marks tell you how much to write. A calculator is fine here.

    Not sure what a question word means? Question words explained.

    Write your working on paper, then type the answer.

    • A sequence starts 11, 17, 23, 29 …

    (a) [2 marks] Write an expression for the nth term.

    1. Find the gap.
    2. Write the gap times n, then compare with the sequence.
    • That looks like the gap times n only. 6n gives 6, 12, 18, 24, which is 5 too small.
    • That looks like the gap added to n. The gap goes in front of n.

    The terms go up by 6, so start with 6n: 6, 12, 18, 24. The sequence is 5 more each time. The nth term is 6n + 5.

    • M1 for 6n (a difference of 6)
    • A1 for 6n + 5
    • The nth term of the sequence is 6n + 5.

    (b) [3 marks] Is 200 a term of this sequence? Type yes or no, then show your working on paper.

    1. Set the nth term equal to 200.
    2. Solve for n. What do you need n to be?
    • That looks like 200 being close to a term. Solve 6n + 5 = 200 and check whether n is a whole number.

    6n + 5 = 200, so 6n = 195 and n = 32.5. A position must be a whole number, so 200 is not a term. The answer is no.

    • M1 for setting 6n + 5 = 200
    • M1 for solving to get n = 32.5
    • C1 for concluding that n is not a whole number, so 200 is not a term

    [3 marks] Pattern n of a row of matchstick squares uses 3n + 1 matchsticks. Mia has 100 matchsticks. She wants to make the biggest pattern she can. What is the biggest value of n she can make?

    1. The pattern needs at most 100 matchsticks. Write that using 3n + 1.
    2. Solve 3n + 1 = 100 and decide what n must be.
    • That looks like rounding up. Pattern 34 needs 3 × 34 + 1 = 103 matchsticks, which is more than 100.
    • That looks like 3n. Divide by 3 to find n.

    3n + 1 = 100, so 3n = 99 and n = 33. Pattern 33 uses 3 × 33 + 1 = 100 matchsticks, so Mia can make pattern 33.

    • M1 for 3n + 1 = 100 (or at most 100)
    • M1 for 3n = 99
    • A1 for 33

    [3 marks] Show that 96 is a term of the sequence 6, 11, 16, 21 …

    1. Find the nth term first.
    2. Set it equal to 96 and solve. What must be true about n?

    The gap is 5, so the nth term starts 5n: 5, 10, 15, 20. The sequence is 1 more, so the nth term is 5n + 1. Then 5n + 1 = 96 gives 5n = 95 and n = 19. That is a whole number, so 96 is the 19th term.

    • M1 for the nth term 5n + 1
    • M1 for solving 5n + 1 = 96 to get n = 19
    • C1 for concluding that n is a whole number, so 96 is a term
    • Tom saves £30 in week 1, £42 in week 2, £54 in week 3, and so on.
    • Ava saves £5 in week 1, £25 in week 2, £45 in week 3, and so on.

    [4 marks] In which week does Ava first save more in that week than Tom does? Give the week number.

    1. Find the nth term for each of them.
    2. Compare: when is Ava’s nth term bigger than Tom’s?
    3. Solve it, then pick the first whole number of weeks that works.
    • That looks like rounding 4.125 down. Check week 4: Tom saves 66 and Ava saves 65, so Ava is not ahead yet.
    • That looks like how much Ava saves in week 5. The question asks for the week number.

    Tom: the terms go up by 12, so the nth term is 12n + 18. Ava: they go up by 20, so the nth term is 20n − 15. Ava is ahead when 20n − 15 > 12n + 18, so 8n > 33 and n > 4.125. The first whole week is 5. Check: Tom saves 78 and Ava saves 85 in week 5.

    • M1 for Tom: 12n + 18
    • M1 for Ava: 20n − 15
    • M1 for comparing them, giving n > 4.125
    • A1 for week 5

    Why it works

    • The gap goes in front of n. Each time n goes up by 1, the nth term goes up by the number in front of n. So that number must be the common difference.
    • The number on the end fixes the start. an gives a, 2a, 3a … The sequence usually starts somewhere else, so b is how far you must shift all the terms.
    • Testing a number is solving an equation. If the number is in the sequence, there is some whole position n that gives it. If solving gives a decimal, no whole position does.
    • Quadratic sequences have constant second differences. n² goes 1, 4, 9, 16 with gaps 3, 5, 7, which grow by 2. For an² the second difference is 2a, so a is half of it.

    Common traps

    • Writing the term-to-term rule (“add 3”) when the question asks for the nth term (3n + 2).
    • Forgetting to fix the start: the gap times n is only the first half of the answer.
    • Reading 4n as 4 and n side by side (46 when n = 6). 4n means 4 times n.
    • Adding the common difference as many times as the position: the 10th term has only 9 steps from the 1st term.
    • Saying a number is in the sequence when n is a decimal.

    Going further

    [3 marks] Show that the sum of any two consecutive terms of the sequence with nth term 4n − 1 is never a multiple of 4.

    1. Write the term after 4n − 1 by putting n + 1 in place of n.
    2. Add the two terms and collect like terms.
    3. Can you write your answer as 4 times something, plus a remainder?

    Two consecutive terms are 4n − 1 and 4(n + 1) − 1 = 4n + 3. Their sum is 8n + 2. And 8n + 2 = 4(2n) + 2, which is always 2 more than a multiple of 4. A number that is 2 more than a multiple of 4 is never a multiple of 4.

    • M1 for the next term 4(n + 1) − 1 = 4n + 3
    • M1 for adding the terms to get 8n + 2
    • C1 for 4(2n) + 2, so always 2 more than a multiple of 4

    In a sequence of whole numbers, each term from the 3rd onwards is the sum of the two terms before it. The 3rd term is 10 and the 5th term is 26. What are the 1st and 2nd terms? Type them with a comma, like 8, 6.

    1. Call the first two terms a and b. Write the first five terms using a and b.
    2. The 3rd term is a + b and the 4th is a + 2b. Make an equation from the 3rd term and another from the 5th.
    3. Subtract to get rid of one letter.
    • That looks like the 3rd term itself. The 1st and 2nd terms add up to it.
    • That adds to 10, but check the 5th term: 5, 5, 10, 15, 25. It should be 26.

    Let the first two terms be a and b. The 3rd term is a + b = 10. The 4th is a + 2b. The 5th is (a + b) + (a + 2b) = 2a + 3b = 26. Double the first equation: 2a + 2b = 20. Subtract: b = 6, so a = 4. The sequence is 4, 6, 10, 16, 26.

    Sequence A has nth term 4n + 3. Sequence B has nth term 54 − 4n. Is there a number that is in both sequences? Type yes or no.

    1. Write out the first few terms of each.
    2. Divide the terms of A by 4. What remainder do they leave?
    3. Now do the same for B. Write 54 − 4n as 4 times something, plus a remainder.
    • That looks like spotting two numbers that are close. Compare the remainders when each sequence is divided by 4.

    Every term of A is 3 more than a multiple of 4, so it leaves remainder 3 when divided by 4. And 54 − 4n = 4(13 − n) + 2, so every term of B leaves remainder 2. A number cannot leave remainder 3 and remainder 2 together, so no number is in both sequences. The answer is no.

    Check your knowledge: on the job

    Real jobs from the building trades: carpentry, electrics and plumbing. Prices are typical, so check them with your own supplier.

    The risers of a staircase are 19 cm high, so the top of step n is 19n cm above the floor. The top of the staircase must be 2.66 m above the floor. How many steps does it need?

    1. The rule is in centimetres. Change 2.66 m to centimetres first.
    2. Set 19n equal to that height.
    3. Solve for n.
    • That looks like the height in cm. The question asks for the number of steps.
    • That looks like dividing 2.66 m by 19 cm. Change the metres to centimetres first.

    2.66 m = 266 cm. 19n = 266, so n = 266 ÷ 19 = 14. The staircase needs 14 steps.

    A tiler lays wall tiles in rows that get longer towards a corner. Row 1 has 12 tiles, row 2 has 14, row 3 has 16, and so on. How many tiles are in row 9?

    1. How many more tiles does each row have than the one before?
    2. Find the nth term for the number of tiles.
    3. Put n = 9 into it.
    • That looks like 12 + 9 × 2. From row 1 to row 9 there are only 8 jumps of 2.
    • That looks like row 8. Row 9 is one more row on.

    The rows go up by 2, so the nth term starts 2n: 2, 4, 6. Add 10 to get 12, 14, 16, so the nth term is 2n + 10. For n = 9: 2 × 9 + 10 = 28 tiles. Check: 12 + 8 × 2 = 28.

    An electrician fixes cable clips along a wall. The 1st clip is 25 cm from the corner and the clips are 40 cm apart, so the distances are 25, 65, 105, 145 … cm. How far from the corner is the 12th clip? Answer in cm.

    1. By how much does the distance go up from clip to clip?
    2. Find the nth term. The number in front of n is that gap.
    3. Then put n = 12 into it.
    • That looks like 40n only. The nth term is 40n − 15, so take the 15 away.
    • That looks like 25 + 12 × 40. From the 1st clip to the 12th there are only 11 gaps.

    The gap is 40, so start with 40n: 40, 80, 120. The terms are 15 smaller, so the nth term is 40n − 15. For n = 12: 40 × 12 − 15 = 480 − 15 = 465 cm.

    [3 marks] A plumber charges a £60 call-out fee plus £18 for each metre of pipe fitted. The costs of fitting 1, 2, 3 … metres are £78, £96, £114 … Write the nth term, then work out the cost of fitting 11 metres. Answer in pounds.

    1. By how much does the cost go up for each extra metre?
    2. That gap goes in front of n. Then fix the start so n = 1 gives £78.
    3. Put n = 11 into your nth term.
    • That looks like 18 × 11 only. The £60 call-out fee is charged as well.
    • That looks like 18 + 11. 18n means 18 times n.

    The costs go up by 18, so the nth term starts 18n: 18, 36, 54. Add 60 to reach 78, 96, 114. The nth term is 18n + 60. For 11 metres: 18 × 11 + 60 = 198 + 60 = 258. The cost is £258.

    • M1 for the nth term 18n + 60 (a difference of 18)
    • M1 for putting n = 11 into it
    • A1 for 258

    A carpenter fits joists. The 1st joist is 40 cm from the wall and the joists are 45 cm apart, so the distances are 40, 85, 130 … cm. Could there be a joist exactly 400 cm from the wall? Type yes or no.

    1. Find the nth term first.
    2. Set it equal to 400 and solve for n.
    3. Is n a whole number?
    • That looks like testing 400 ÷ 45 instead of using the nth term. Solve 45n − 5 = 400.

    The gap is 45, so the nth term starts 45n: 45, 90, 135. That is 5 too big, so the nth term is 45n − 5. Then 45n − 5 = 400 gives 45n = 405 and n = 9. That is a whole number, so yes: it is the 9th joist.

    A plumber stacks pipes in rows. The bottom row has 12 pipes and each row above has one pipe fewer: 12, 11, 10 … The nth term is 13 − n. Which row has 5 pipes? Give the row number.

    1. Set 13 − n equal to 5.
    2. What number n makes that true?
    • That looks like adding 13 and 5. The rule takes n away from 13.
    • That looks like the number of pipes. The question asks which row.

    13 − n = 5, so n = 13 − 5 = 8. Row 8 has 5 pipes. Check: the rows go 12, 11, 10, 9, 8, 7, 6, 5, so 5 is the 8th number.
