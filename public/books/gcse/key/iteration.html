    1Work out 2x − 3 when x = 6.9
    Working: 2 × 6 = 12. 12 − 3 = 9.
    2Solve 2x + 7 = 15.4
    Working: 2x + 7 = 15, so 2x = 15 − 7 = 8, and x = 8 ÷ 2 = 4.
    3Work out the cube root of 27, which is the number that multiplies by itself three times to give 27.3
    Working: 3 × 3 × 3 = 27, so the cube root of 27 is 3.
    4Work out x³ + x − 3 when x = 2.7
    Working: 2³ = 8. Then 8 + 2 − 3 = 7.
    5Round 1.21347 to 2 decimal places.1.21
    Working: 1.21347 has 1, 2 and then 3 after the point. The 3 is less than 5, so round down: 1.21.
    6x 0 = 4 and x n+1 = 2x n − 1. Find x 1 .7
    Working: x 1 = 2 × 4 − 1 = 7.
    7x 0 = 4 and x n+1 = 2x n − 1. Find x 3 .25
    Working: x 1 = 7. x 2 = 2 × 7 − 1 = 13. x 3 = 2 × 13 − 1 = 25.
    8x 0 = 2 and x n+1 = x n ² − 3. Find x 3 .1
    Working: x 1 = 2² − 3 = 1. x 2 = 1² − 3 = −2. x 3 = (−2)² − 3 = 4 − 3 = 1.
    9In the formula x n+1 = 5x n − 4, what does x n stand for?The term you have now
    Working: x n is the current term. To get the next term, x n+1 , multiply x n by 5 and take away 4.
    10x 0 = 10 and x n+1 = (x n + 6) ÷ 2. Find x 2 .7
    Working: x 1 = (10 + 6) ÷ 2 = 8. x 2 = (8 + 6) ÷ 2 = 7.
    11x 0 = 1 and x n+1 = √(x n + 2). Find x 2 , to 3 decimal places.1.932
    Working: x 1 = √(1 + 2) = 1.7320…. x 2 = √(1.7320… + 2) = 1.9318… ≈ 1.932.
    12x 0 = 1 and x n+1 = (x n + 10) ÷ 3. Find x 3 , to 2 decimal places.4.85
    Working: x 1 = 3.6666…, x 2 = 4.5555…, x 3 = 4.8518… ≈ 4.85.
    13Same rule, x 0 = 1 and x n+1 = (x n + 10) ÷ 3. Find x 5 , to 4 decimal places. What number do the terms seem to be heading for?4.9835
    Working: The terms are 3.6666…, 4.5555…, 4.8518…, 4.9506…, 4.9835…. x 5 = 4.9835… ≈ 4.9835. They are getting closer to 5.
    14The terms of x n+1 = (x n + 10) ÷ 3 settle at a number L. Then L = (L + 10) ÷ 3. Solve this to find L.5
    Working: 3L = L + 10, so 2L = 10 and L = 5. This matches the terms 4.98… getting close to 5.
    15The terms of x n+1 = 2x n + 1 with x 0 = 3 are 3, 7, 15, 31, 63. What do they do? [Figure: Graph of y = x cubed plus x minus 3]They keep growing, so they do not settle on a number.
    Working: Each term is more than double the last, so the steps get bigger. The terms diverge: they do not settle at a number.
    16f(x) = x³ + x − 3. Work out f(1.4), to 3 decimal places.1.144
    Working: 1.4³ = 2.744. Then 2.744 + 1.4 − 3 = 1.144.
    17For f(x) = x³ + x − 3, f(1.2) = −0.072 and f(1.3) = 0.497. What do these tell you?f(x) = 0 has a solution between 1.2 and 1.3.
    Working: f(1.2) is negative and f(1.3) is positive. The sign changes, and the graph is continuous (no gaps or jumps), so it crosses the axis between 1.2 and 1.3.
    18f(x) = x³ − 5x + 1. Work out f(1). (This is part of showing that f has a solution between 0 and 1.)-3
    Working: f(1) = 1³ − 5 × 1 + 1 = 1 − 5 + 1 = −3. With f(0) = 1, the sign changes from positive to negative between 0 and 1.
    19Show that x³ + 2x − 7 = 0 has a solution between 1 and 2.Written answer: see the mark scheme
    1. M1 for f(1) = −4 and f(2) = 5 (both correct)
    2. C1 for a change of sign, so a solution between 1 and 2
    Working: Let f(x) = x³ + 2x − 7. f(1) = 1 + 2 − 7 = −4. f(2) = 8 + 4 − 7 = 5. f(1) is negative and f(2) is positive. The sign changes, and f is continuous (no gaps or jumps), so there is a solution between 1 and 2.
    		2
    20f(x) = x³ + x − 3 has f(1.21) = −0.018 and f(1.22) = 0.036 (to 3 decimal places). The solution lies in an interval of width 0.01. What is the lower end of this interval? Type it like 1.35.1.21
    Working: f(1.21) is negative and f(1.22) is positive. The sign changes, so the solution is between 1.21 and 1.22. The lower end is 1.21.
    21f(x) = x³ + x − 3. Work out f(1.25), to 3 decimal places. Is the solution above or below 1.25? [Figure: The first terms of an iteration on a number line]0.203
    Working: 1.25³ = 1.953125. f(1.25) = 1.953125 + 1.25 − 3 = 0.203125, which is 0.203 to 3 decimal places. It is positive and f(1.2) is negative, so the solution is between 1.2 and 1.25: below 1.25.
    22Which rearranges x³ + x − 3 = 0 into a formula of the form x = ...?x = ∛(3 − x)
    Working: x³ + x − 3 = 0 gives x³ = 3 − x (take x from both sides and add 3). Then x = ∛(3 − x).
    23Show that x³ + 2x − 7 = 0 can be rearranged to x = ∛(7 − 2x).Written answer: see the mark scheme
    1. M1 for x³ = 7 − 2x (take 2x from both sides and add 7)
    2. C1 for taking the cube root to get x = ∛(7 − 2x)
    Working: x³ + 2x − 7 = 0. Take 2x from both sides and add 7: x³ = 7 − 2x. Take the cube root of both sides: x = ∛(7 − 2x), as required.
    		2

    Working: x 1 = ∛(3 − 1) = 1.2599…. x 2 = ∛(3 − 1.2599…) ≈ 1.2028.
    25x 0 = 0 and x n+1 = (x n ³ + 1) ÷ 5. This is a rearrangement of x³ − 5x + 1 = 0. Find x 2 , to 4 decimal places.0.2016

    26Show that x² − 6x − 2 = 0 can be rearranged to x = 6 + 2/x.Written answer: see the mark scheme
    1. M1 for x² = 6x + 2 (add 6x and 2 to both sides)
    2. C1 for dividing every term by x to get x = 6 + 2/x
    Working: x² − 6x − 2 = 0. Add 6x and 2 to both sides: x² = 6x + 2. Divide every term by x: x = 6 + 2/x, as required.
    		2

    28x 0 = 1 and x n+1 = ∛(3 − x n ). Find x 5 , to 2 decimal places.1.21

    Working: The terms are 1.5874…, 1.5639…, 1.5703…, 1.5686…. x 3 and x 4 both round to 1.57. The solution is 1.57 to 2 decimal places.
    30f(x) = x³ + x − 3. Work out f(1.205), to 3 decimal places. (This is one of the two checks for the solution 1.21 to 2 decimal places.)-0.045

    32x 0 = 0 and x n+1 = (x n ³ + 1) ÷ 5. Use iteration to find the solution of x³ − 5x + 1 = 0, to 3 decimal places.0.202

    36Same loan: B 0 = 3000 and B n+1 = 1.01 B n − 250. After how many months is the balance first below £1000?9
    Working: The balances are 1877.78, 1646.56, 1413.02, 1177.15, 938.92 for months 5 to 9. After 8 months the balance is £1177.15, still above £1000. After 9 months it is £938.92, so the answer is 9 months.
    37A savings account adds 3% each year, and then £100 is paid in. S n+1 = 1.03 S n + 100, with S 0 = 500. Find S 3 , to the nearest penny. Type it like 1234.50.855.45

    Working: Multiplying by 1.01 adds 1% interest to the balance. Subtracting 250 takes off the payment. Each month does both, in that order.
    40x n+1 = 3x n − 2 and x 2 = 25. Work backwards to find x 1 .9
    Working: The rule: multiply by 3, take 2 away. Backwards: add 2, then divide by 3. (25 + 2) ÷ 3 = 9. Check: 3 × 9 − 2 = 25.
    41The terms of x n+1 = (x n + 12) ÷ 4 settle at a number L. Solve L = (L + 12) ÷ 4 to find L.4
    Working: 4L = L + 12, so 3L = 12 and L = 4. Check: (4 + 12) ÷ 4 = 4.
    42The terms of x n+1 = √(x n + 6) (starting at x 0 = 1) settle at a number L, so L = √(L + 6). Square both sides, solve the quadratic, and give the positive value of L.3
    Working: L² = L + 6, so L² − L − 6 = 0, which factorises as (L − 3)(L + 2) = 0. So L = 3 or L = −2. A square root is not negative, so L = 3. (The terms are 2.645…, 2.940…, 2.990…, 2.998…, heading for 3.)
    43The formula x n+1 = ∛(7 − 2x n ) is used to solve an equation. Which equation is it?x³ + 2x − 7 = 0
    Working: Put x for both terms: x = ∛(7 − 2x). Cube both sides: x³ = 7 − 2x. Add 2x and take 7 from both sides: x³ + 2x − 7 = 0.
    44x 0 = 3 and x n+1 = 2x n − 3. Find x 5 . (Work out the first few terms and look at what happens.)3
    Working: x 1 = 2 × 3 − 3 = 3. The term did not change, so every term is 3, including x 5 = 3. A number that fits L = 2L − 3 (here L = 3) stays put if you start there. (Start anywhere else and the terms run away from 3.)
    45Priya says: for f(x) = 1/x, f(−1) = −1 and f(1) = 1. The sign changes, so f(x) = 0 has a solution between −1 and 1. What is wrong?The graph of 1/x has a gap at x = 0, so it never crosses the axis.
    Working: The rule needs the graph to be one unbroken curve. 1/x cannot be worked out at x = 0, so the graph breaks there. It jumps from far below the axis to far above it without crossing it. 1 ÷ x is never 0, so there is no solution at all.
    46Sam says: I tried x n+1 = 3 − x n ³ with x 0 = 1.2 for x³ + x − 3 = 0. The terms were 1.27, 0.94, 2.16, -7.14. They run away, so the equation has no solution. What is wrong?The equation has a solution. This formula fails to home in.
    Working: The terms running away only says this formula is no good. The equation x³ + x − 3 = 0 has a solution between 1.2 and 1.3 (a sign change), and the rearrangement x = ∛(3 − x) homes in on it.
    47Lee says: I want the solution of x³ + x − 3 = 0 to 2 decimal places. I used x n+1 = ∛(3 − x n ) and rounded each answer to 1 decimal place before using it again. I got 1.3, 1.2, 1.2, 1.2, so the answer is 1.20. What went wrong?Rounding every term early loses accuracy. Keep all the digits with Ans.
    Working: Rounding to 1 decimal place each time throws away the digits you need. The true terms keep changing in the second decimal place (1.26, 1.20, 1.22, 1.21, 1.21), and the solution is 1.21 to 2 decimal places. Keep every digit with the Ans button and round only the answer.

    54A joiner takes a £4,800 loan for tools. Each month 1.5% interest is added to the balance, and then £300 is paid. B n+1 = 1.015 B n − 300, with B 0 = 4800. Find B 3 , the balance after 3 months, to the nearest penny. Type it like 1234.50.4105.69
    Working: B 1 = 1.015 × 4800 − 300 = 4572.00. B 2 = 4340.58. B 3 = 1.015 × 4340.58 − 300 = 4105.6887 ≈ £4105.69.
    55Same loan: B 0 = 4800 and B n+1 = 1.015 B n − 300. After how many months is the balance first below £3,000?8

    56An electrician tests a cable under load. A simple model for its temperature T (in °C) after each 10 minutes is T n+1 = 0.9 T n + 8, with T 0 = 20. Find T 3 , to 1 decimal place.36.3
    Working: T 1 = 0.9 × 20 + 8 = 26. T 2 = 0.9 × 26 + 8 = 31.4. T 3 = 0.9 × 31.4 + 8 = 36.26 ≈ 36.3°C.
    57In the same cable model, T n+1 = 0.9 T n + 8. The temperature settles at a value L. Put L in place of both T n and T n+1 and solve to find L, in °C.80
    Working: L = 0.9L + 8, so 0.1L = 8 and L = 8 ÷ 0.1 = 80. The model says the cable settles at 80°C.
    58A plumber is checking a hot water cylinder that is being switched off. A simple model for its temperature T (in °C) after each hour is T n+1 = 0.88 T n + 2.4, with T 0 = 60. Find T 3 , to 1 decimal place.47.3
    Working: T 1 = 0.88 × 60 + 2.4 = 55.2. T 2 = 50.976. T 3 = 0.88 × 50.976 + 2.4 = 47.2588… ≈ 47.3°C.
    59In the cylinder model, T n+1 = 0.88 T n + 2.4. The temperature settles at a value L. Solve L = 0.88L + 2.4 to find L, in °C. Is the answer sensible for a room?20
    Working: L = 0.88L + 2.4, so 0.12L = 2.4 and L = 2.4 ÷ 0.12 = 20. The cylinder cools towards 20°C, which is about room temperature, so that is sensible.

    63The iteration x n+1 = √(x n + 2) settles at a number L. Show that L = 2.Written answer: see the mark scheme
    1. M1 for L = √(L + 2)
    2. M1 for L² = L + 2, so L² − L − 2 = 0
    3. C1 for (L − 2)(L + 1) = 0, and L = 2 because L is positive
    Working: Put L in place of x n and x n+1 : L = √(L + 2). Square both sides: L² = L + 2, so L² − L − 2 = 0. Factorise: (L − 2)(L + 1) = 0, so L = 2 or L = −1. L is a square root, so it is not negative. So L = 2.
    		3
    64f(x) = x³ + x − 3. Show that the solution of f(x) = 0 is 1.21 to 2 decimal places.Written answer: see the mark scheme
    1. M1 for f(1.205) = −0.045 (or negative, with evidence)
    2. M1 for f(1.215) = 0.009 (or positive, with evidence)
    3. C1 for a change of sign, so the solution is between 1.205 and 1.215, so it is 1.21 to 2 decimal places
    Working: f(1.205) = 1.205³ + 1.205 − 3 = -0.045 (negative). f(1.215) = 1.215³ + 1.215 − 3 = 0.009 (positive). The sign changes, so the solution lies between 1.205 and 1.215, which means it is 1.21 to 2 decimal places.
    		3
    65x n+1 = (1/1 + x n ) with x 0 = 1 gives the terms 0.5, 0.667, 0.6, 0.625, 0.615, 0.619…. They settle at a number L. Write L = 1/(1 + L), rearrange it to a quadratic equal to 0, and use the quadratic formula to find L, to 3 decimal places.0.618
    Working: L = 1/(1 + L), so L(1 + L) = 1 and L² + L − 1 = 0. The quadratic formula gives L = (−1 ± √5)/2. The terms are positive, so L = (−1 + √5)/2 = 0.6180… ≈ 0.618.
    66f(x) = x³ − 3x + 1. Work out f(−2), f(−1), f(0), f(1) and f(2). Use them to show that f(x) = 0 has three solutions, and give an interval of width 1 for each. [Figure: A curve with five marked points]Written answer: see the mark scheme
    1. M1 for f(−2) = −1, f(−1) = 3, f(0) = 1, f(1) = −1, f(2) = 3
    2. M1 for identifying the three changes of sign
    3. C1 for a conclusion: three solutions, between −2 and −1, 0 and 1, and 1 and 2
    Working: f(−2) = −8 + 6 + 1 = −1. f(−1) = −1 + 3 + 1 = 3. f(0) = 1. f(1) = 1 − 3 + 1 = −1. f(2) = 8 − 6 + 1 = 3. The sign changes from − to + between −2 and −1, from + to − between 0 and 1, and from − to + between 1 and 2. The graph is continuous, so there is a solution in each interval: three solutions.
    		3
    67f(x) = 1/x has f(−1) = −1 and f(1) = 1. Does f(x) = 0 have a solution between −1 and 1? Type yes or no.no (also accept: No)
    Working: No. 1 ÷ x is never 0, because 1 divided by any number is not 0. The sign changes only because the graph jumps across the break at x = 0. The change-of-sign test needs the graph to join up.
    68x n+1 = (x n + (7/x n )) ÷ 2 with x 0 = 3 settles at a number L. Find x 3 , to 5 decimal places. Then show that L = √7: put L in place of x n and x n+1 and solve.2.64575
    Working: x 1 = 2.666666…, x 2 = 2.645833…, x 3 = 2.645751… ≈ 2.64575. For the limit: L = (L + 7/L) ÷ 2, so 2L = L + 7/L, so L = 7/L, so L² = 7 and L = √7 = 2.64575…. The terms reach √7 very quickly.
