    3. C1 for 2/8 simplified to 1/4, stated as the answer
    Working: Total cut = 5 × 5/8 = 25/8 m. Pipe = 3 3/8 = 27/8 m. Left over = 27/8 − 25/8 = 2/8 = 1/4 m. So the piece left over is 1/4 m long, as required.

    2Non-calculator Grade 9 Prove that the sum of the squares of any two consecutive odd numbers is always 2 more than a multiple of 8. Uses: Algebra basics Uses: Squares and rootsWritten answer: see the mark scheme
    1. B1 for two consecutive odd numbers written as 2n + 1 and 2n + 3 (or similar, such as 2n − 1 and 2n + 1)
    2. M1 for expanding both brackets correctly
    3. A1 for 8n² + 16n + 10
    4. C1 for 8(n² + 2n + 1) + 2 with a conclusion that n² + 2n + 1 is a whole number, so this is 2 more than a multiple of 8
    Working: Let the two odd numbers be 2n + 1 and 2n + 3, where n is a whole number. (2n + 1)² + (2n + 3)² = 4n² + 4n + 1 + 4n² + 12n + 9 = 8n² + 16n + 10. 8n² + 16n + 10 = 8(n² + 2n + 1) + 2. n² + 2n + 1 is a whole number, so 8(n² + 2n + 1) is a multiple of 8. The sum is therefore always 2 more than a multiple of 8.

    3Non-calculator Grade 8 The highest common factor of two numbers is 6. Their lowest common multiple is 180. One of the numbers is 36. Find the other number. Uses: Factors and multiples30
    1. M1 for prime factors of 36 and 180, or for 6 × 180 = 1080
    2. M1 for a clear method: the missing factors are 5 and only one each of 2 and 3, or 1080 ÷ 36
    3. A1 for 30
    Working: 36 = 2 × 2 × 3 × 3 and 180 = 2 × 2 × 3 × 3 × 5. The LCM has a 5, which 36 does not, so the other number has a 5. The HCF is 6 = 2 × 3, so the other number has only one 2 and one 3. It is 2 × 3 × 5 = 30. Check: HCF(36, 30) = 6 and LCM(36, 30) = 180. The other number is 30. (Another route: HCF × LCM = product of the two numbers, so 6 × 180 = 1080 and 1080 ÷ 36 = 30.)

    4Non-calculator Grade 9 n is a positive whole number. Prove that (n + 1)/(n + 2) is always greater than n/(n + 1). Uses: Fractions Uses: Algebra basicsWritten answer: see the mark scheme
    1. M1 for subtracting (or cross-multiplying) with common denominator (n + 1)(n + 2)
    2. M1 for a correct numerator, (n + 1)² − n(n + 2), expanded
    3. A1 for a difference of 1/((n + 1)(n + 2))
    4. C1 for stating that this is positive because n is positive, so the first fraction is greater
    Working: (n + 1)/(n + 2) − n/(n + 1) = ((n + 1)(n + 1) − n(n + 2))/((n + 2)(n + 1)) = (n² + 2n + 1 − n² − 2n)/((n + 1)(n + 2)) = 1/((n + 1)(n + 2)). n is positive, so (n + 1)(n + 2) is positive and the difference is positive. So (n + 1)/(n + 2) is always greater than n/(n + 1).

    8Non-calculator Grade 9 The price of a games console is increased by 20%. A week later the new price is reduced by x% so that the console costs its original price again. Find the exact value of x. Give your answer as a mixed number. Uses: Percentage change Uses: FractionsWritten answer: see the mark scheme
    1. M1 for an increase multiplier 1.2 and a decrease multiplier (1 − x/100) multiplied to give 1
    2. M1 for 1 − x/100 = 5/6 (or 1/1.2)
    3. M1 for x/100 = 1/6, so x = 100/6
    4. A1 for 16 2/3
    Working: Let the original price be P. After the increase: 1.2P. After the decrease: 1.2P × (1 − x/100). 1.2P × (1 − x/100) = P, so 1 − x/100 = 1/1.2 = 5/6. x/100 = 1 − 5/6 = 1/6, so x = 100/6 = 16 2/3. The reduction is 16 2/3%.     3. M1 for solving to find k = 12
    4. A1 for 96
    Working: Sam starts with 3k sweets and Tia with 5k. After the gift Sam has 3k − 12 and Tia has 5k + 12. The ratio is 1 : 3, so 3(3k − 12) = 5k + 12. 9k − 36 = 5k + 12, so 4k = 48 and k = 12. Total = 8k = 96 sweets. (Check: Sam 36 → 24, Tia 60 → 72, and 24 : 72 = 1 : 3.)

Uses: RatioWritten answer: see the mark scheme

    15Non-calculator Grade 7 Prove that the difference between the squares of any two consecutive integers is always an odd number. Uses: Algebra basicsWritten answer: see the mark scheme
    1. M1 for n and n + 1 (or equivalent) with the difference of squares set up
    2. A1 for correct expansion and simplification to 2n + 1
    3. C1 for a conclusion: 2n is even, so 2n + 1 is odd
    Working: Let the two consecutive integers be n and n + 1. (n + 1)² − n² = n² + 2n + 1 − n² = 2n + 1 2n is a multiple of 2, so it is even. Adding 1 to an even number always gives an odd number, so the difference is always odd.

    16Non-calculator Grade 8 Prove that the sum of any four consecutive integers is never a multiple of 4. Uses: Algebra basicsWritten answer: see the mark scheme
    1. M1 for four consecutive integers written algebraically, such as n, n + 1, n + 2, n + 3
    2. M1 for adding them
    3. A1 for 4n + 6, or 4(n + 1) + 2, or equivalent
    4. C1 for a conclusion: a multiple of 4 plus 2 is never a multiple of 4
    Working: Let the four consecutive integers be n, n + 1, n + 2 and n + 3. Sum = n + (n + 1) + (n + 2) + (n + 3) = 4n + 6 4n + 6 = 4n + 4 + 2 = 4(n + 1) + 2 4(n + 1) is a multiple of 4, so the sum is always 2 more than a multiple of 4. A remainder of 2 means it is never a multiple of 4.
    		4

    1. M1 for AB = b − a (oe)

    3. A1 for OP = 1/3 a + 2/3 b (oe)
    4. M1 for factorising to 1/3( a + 2 b )
