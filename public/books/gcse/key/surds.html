79Higher Prove that √2 is irrational. (Start by supposing √2 = a/b, where a and b are whole numbers with no common factor.)Written answer: see the mark scheme
  1. M1 for supposing √2 = a/b in lowest terms and squaring to get a² = 2b²
  2. A1 for a² even, so a is even (a = 2c)
  3. M1 for 4c² = 2b², so b² = 2c² and b is even
  4. C1 for a and b both even, which contradicts no common factor, so √2 is irrational
Working: Suppose √2 = a/b with a and b whole numbers that have no common factor. Squaring gives 2 = a²/b², so a² = 2b². So a² is even, which means a is even (the square of an odd number is odd). Write a = 2c. Then 4c² = 2b², so b² = 2c², so b² is even and b is even. Now a and b are both even, so they share the factor 2. That contradicts the choice of a and b with no common factor. So √2 cannot be written as a fraction: it is irrational.
