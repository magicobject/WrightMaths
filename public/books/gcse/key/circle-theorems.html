67AB is a diameter of a circle with centre O, and C is a point on the circle. Prove that angle ACB = 90°.Written answer: see the mark scheme
  1. B1 OA = OB = OC (radii), so triangles OAC and OBC are isosceles
  2. M1 angle OCA = a and angle OCB = b (base angles of isosceles triangles)
  3. M1 a + b + (a + b) = 180 (angles in triangle ABC)
  4. C1 so a + b = 90, angle ACB = 90°

68ABCD is a cyclic quadrilateral with centre O. Let angle BAD = x. Prove that angle BCD = 180° − x. (Use the theorem that the angle at the ...Written answer: see the mark scheme
  1. B1 angle BOD = 2x (centre is twice circumference)
  2. B1 reflex angle BOD = 360 − 2x (angles at a point)
  3. M1 angle BCD = (360 − 2x) ÷ 2 = 180 − x
  4. C1 so angle BAD + angle BCD = 180°

69TA and TB are tangents to a circle with centre O. Prove that TA = TB. (Use Pythagoras.)Written answer: see the mark scheme
  1. B1 angles OAT and OBT are 90° (tangent perpendicular to radius)
  2. M1 TA² = OT² − OA² and TB² = OT² − OB²
  3. C1 OA = OB (radii), so TA = TB
