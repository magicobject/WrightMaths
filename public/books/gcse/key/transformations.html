1Write the coordinates of the point 4 units to the right of the origin and 3 units down. Type it like (2, 5).4,-3 (also accept: (4, -3))
Working: Right 4 gives x = 4. Down 3 gives y = −3. The point is (4, −3).
2Work out −3 + 7.4
Working: −3 + 7 = 4.
3Work out 2 − 6.-4
Working: 2 − 6 = −4.
4What is the y-coordinate of the point (5, −2)? [Figure: A triangle and its image after a slide]-2
Working: In (5, −2), x = 5 and y = −2. The y-coordinate is −2.
5Which transformation changes the size of a shape?Enlargement
Working: An enlargement changes the size. Translation, reflection and rotation keep the size the same.
6A rectangle is 5 cm by 2 cm. It is reflected in a mirror line. What is the perimeter of the image? Answer in cm.14
Working: The image is congruent, so it is also 5 cm by 2 cm. Perimeter = 5 + 2 + 5 + 2 = 14 cm.
7A shape is enlarged by scale factor 2. Which statement is true?Lengths double, angles do not change
Working: Every length is multiplied by 2. The angles stay exactly the same.
8This triangle is called ABC. Write the coordinates of B. Type them like (2, 5). [Figure: Triangle ABC on a grid]4,1 (also accept: (4, 1))
Working: B is 4 along and 1 up, so B is (4, 1).
9A point is at (2, 3). It is translated by 4 1 . Write the new coordinates. Type them like (2, 5).6,4 (also accept: (6, 4))
Working: x: 2 + 4 = 6. y: 3 + 1 = 4. The new point is (6, 4).
10A point is at (−3, 2). It is translated by 5 −6 . Write the new coordinates, like (2, 5).2,-4 (also accept: (2, -4))
Working: x: −3 + 5 = 2. y: 2 + (−6) = −4. The new point is (2, −4).
11Triangle ABC is translated by −3 −2 . Write the coordinates of B&prime;. Type them like (2, 5). [Figure: Triangle ABC before a translation]2,-1 (also accept: (2, -1))
Working: B is (5, 1). Add −3 −2 : x = 5 − 3 = 2, y = 1 − 2 = −1. B&prime; is (2, −1).
12A shape is translated by −2 5 . Which describes the move?2 left and 5 up
Working: The top number −2 means 2 to the left. The bottom number 5 means 5 up.
13A border pattern on a wall has a motif with its bottom-left corner at (2, 1) on a plan, measured in cm. The motif is repeated using a translation of 6 0 each time. What is the position of the bottom-left corner of the 4th motif? Type it like (2, 5).20,1 (also accept: (20, 1))
Working: The 1st motif is at (2, 1). The 4th is 3 translations on: x = 2 + 3 × 6 = 20. The point is (20, 1).
14A game character at (1, 6) walks to (4, 3). Write the translation as a vector, top number first. Type it like (3, -2).(3, -3) (also accept: 3,-3)
Working: Across: 4 − 1 = 3. Up: 3 − 6 = −3. The vector is 3 −3 , typed (3, -3).
15A triangle has a perimeter of 9 cm. It is translated by 7 2 . What is the perimeter of the image? Answer in cm. [Figure: A triangle reflected in the line x = 4]9
Working: A translation does not change the size. The perimeter is still 9 cm.
16The point (2, 5) is reflected in the y-axis. Write the image. Type it like (2, 5).-2,5 (also accept: (-2, 5))
Working: The point is 2 right of the y-axis, so the image is 2 left: x = −2. y stays 5. The image is (−2, 5).
17Triangle ABC is reflected in the line x = 4. Write the coordinates of C&prime;. Type them like (2, 5). [Figure: A triangle and a mirror line]6,4 (also accept: (6, 4))
Working: C is (2, 4), which is 2 squares left of the line x = 4. The image is 2 squares right of the line: x = 6. C&prime; is (6, 4).
18Triangle ABC is reflected in the x-axis. Write the coordinates of B&prime;. Type them like (2, 5). [Figure: A triangle above the x-axis]3,-2 (also accept: (3, -2))
Working: B is (3, 2), which is 2 above the x-axis. The image is 2 below: y = −2. B&prime; is (3, −2).
19A point is 3 units to the left of a vertical mirror line. Where is its image?3 units to the right of the line
Working: Object and image are equal distances from the mirror line, on opposite sides. So the image is 3 units to the right of it.
20The point (1, 4) is reflected in the line y = 2. Write the image. Type it like (2, 5).1,0 (also accept: (1, 0))
Working: 4 is 2 above the line y = 2. The image is 2 below it: y = 0. The image is (1, 0).
21A rectangle has an area of 12 cm². It is reflected in a line. What is the area of the image? Answer in cm².12
Working: A reflection does not change the size, so the area is still 12 cm².
22A point lies on the mirror line. Where is its image? [Figure: A triangle reflected in the line y = x]In the same place
Working: A point on the line is 0 units from it, so its image is also 0 units from it: the same point.
23Higher The point (3, 5) is reflected in the line y = x. Write the image. Type it like (2, 5).5,3 (also accept: (5, 3))
Working: Swap the coordinates: (3, 5) becomes (5, 3).
24Higher The point (−2, 3) is reflected in the line y = x. Write the image, like (2, 5).3,-2 (also accept: (3, -2))
Working: Swap them, keeping the signs: (−2, 3) becomes (3, −2).
25Higher The point (2, 5) is reflected in the line y = −x. Write the image, like (2, 5).-5,-2 (also accept: (-5, -2))
Working: Swap: (5, 2). Change both signs: (−5, −2).
26Higher Which point stays where it is when reflected in the line y = x? [Figure: A triangle rotated 90 degrees clockwise about the origin](4, 4)
Working: A point on the mirror line stays put. On y = x the two coordinates are equal, so (4, 4) is on the line, and swapping gives (4, 4) again.
27The point (4, 2) is rotated 180° about the origin. Write the image. Type it like (2, 5).-4,-2 (also accept: (-4, -2))
Working: A half turn changes both signs: (4, 2) becomes (−4, −2).
28Triangle ABC is rotated 90° clockwise about the origin. Write the coordinates of A&prime;. Type them like (2, 5). [Figure: A triangle to be rotated about the origin]2,-1 (also accept: (2, -1))
Working: A is (1, 2). Using (x, y) → (y, −x): A&prime; is (2, −1).
29Which turn is the same as 90° clockwise?270° anticlockwise
Working: 360° − 90° = 270°. A quarter turn clockwise ends in the same place as three quarter turns anticlockwise.
30The point (3, 1) is rotated 90° anticlockwise about the origin. Write the image, like (2, 5).-1,3 (also accept: (-1, 3))
Working: (x, y) → (−y, x) gives (−1, 3). The image is (−1, 3).
31The point (5, 1) is rotated 180° about the centre (2, 1). Write the image. Type it like (2, 5).-1,1 (also accept: (-1, 1))
Working: The arm from (2, 1) to (5, 1) is (3, 0). Half a turn makes it (−3, 0). Add to the centre: (2 − 3, 1 + 0) = (−1, 1).
32The point Q is rotated 90° clockwise about the centre. Write the coordinates of Q&prime;. Type them like (2, 5). [Figure: A point and a centre of rotation]1,-2 (also accept: (1, -2))
Working: The arm from the centre (1, 1) to Q(4, 1) is (3, 0). A clockwise quarter turn gives (0, −3). Add to the centre: (1, −2).
33A tiler turns a patterned tile 90° clockwise and then another 90° clockwise. What single turn is that? Answer in degrees. [Figure: A triangle enlarged by scale factor 2 from the origin]180
Working: 90° + 90° = 180°. It is a half turn.
34The point (2, 3) is enlarged by scale factor 3, centre (0, 0). Write the image. Type it like (2, 5).6,9 (also accept: (6, 9))
Working: 3 × 2 = 6 and 3 × 3 = 9. The image is (6, 9).
35Triangle ABC is enlarged by scale factor 2 about the centre. Write the coordinates of C&prime;. Type them like (2, 5). [Figure: A triangle and a centre of enlargement]5,3 (also accept: (5, 3))
Working: C is (3, 2). The arm from the centre (1, 1) is (2, 1). Doubled: (4, 2). Add to the centre: (1 + 4, 1 + 2) = (5, 3).
36A side of a shape is 4 cm long. The shape is enlarged by scale factor 2.5. How long is that side in the image? Answer in cm.10
Working: 4 × 2.5 = 10, so the side is 10 cm.
37The point (6, 8) is enlarged by scale factor 1/2, centre (0, 0). Write the image. Type it like (2, 5).3,4 (also accept: (3, 4))
Working: Half of 6 is 3 and half of 8 is 4. The image is (3, 4).
38A triangle has sides of 3 cm, 4 cm and 5 cm. It is enlarged by scale factor 2. What is the perimeter of the image? Answer in cm.24
Working: New sides: 6, 8 and 10. Perimeter = 6 + 8 + 10 = 24 cm. (Or: 12 × 2 = 24.)
39A shape is enlarged by scale factor 1/3. What happens to it?It gets smaller
Working: 1/3 is less than 1, so every length is multiplied by a number less than 1 and the shape gets smaller (to one third of its length).
40A logo is 6 cm wide on a business card. It is enlarged by scale factor 4 for the side of a van. How wide is the logo on the van? Answer in cm. [Figure: A triangle enlarged by scale factor minus 2 from the origin]24
Working: 6 × 4 = 24, so the logo is 24 cm wide on the van.
41Higher The point (2, 1) is enlarged by scale factor −2, centre (0, 0). Write the image. Type it like (2, 5).-4,-2 (also accept: (-4, -2))
Working: −2 × 2 = −4 and −2 × 1 = −2. The image is (−4, −2).
42Higher The point (3, 2) is enlarged by scale factor −1, centre (1, 1). Write the image, like (2, 5).-1,0 (also accept: (-1, 0))
Working: The arm is (2, 1). Times −1: (−2, −1). Add to the centre: (1 − 2, 1 − 1) = (−1, 0).
43Higher A rectangle is 3 cm by 2 cm. It is enlarged by scale factor 3. What is the area of the image? Answer in cm².54
Working: New rectangle: 9 cm by 6 cm. Area = 9 × 6 = 54 cm². (Check: 6 × 3² = 54.)
44Higher Which single transformation is the same as an enlargement with scale factor −1 and centre (0, 0)? [Figure: Triangle P and its image Q]A half turn about (0, 0)
Working: Scale factor −1 about the origin sends (x, y) to (−x, −y). That is exactly a rotation of 180° about the origin.
45Which is a full description of the single transformation that maps triangle P onto triangle Q? [Figure: Triangles P and Q]A translation, 5 left and 2 up
Working: P and Q are the same size and face the same way, so it is a translation. The corner (5, 1) goes to (0, 3): 5 left and 2 up.
46Which describes the single transformation that maps P onto Q? [Figure: Triangles P and Q]Reflection in the line y = 3
Working: The corner (1, 4) goes to (1, 2). Halfway between y = 4 and y = 2 is y = 3. The mirror line is y = 3.
47Triangle Q is an enlargement of triangle P. What is the scale factor? [Figure: Triangles P and Q]3
Working: The bottom side of P is 1 unit and of Q is 3 units. 3 ÷ 1 = 3. The scale factor is 3.
48Triangle P is rotated anticlockwise about the origin to give Q. What is the angle of the rotation? Answer in degrees. [Figure: Triangles P and Q]90
Working: The corner (5, 1) goes to (−1, 5). The rule (x, y) → (−y, x) fits, which is 90° anticlockwise about the origin. The angle is 90.
49Which of these is NOT a full description of a transformation?Rotation, 90° clockwise
Working: A rotation needs the angle, the direction and the centre. “Rotation, 90° clockwise” is missing the centre.
50Triangle Q is an enlargement of triangle P. Write the coordinates of the centre of enlargement. Type them like (2, 5). [Figure: A small and a large triangle]0,1 (also accept: (0, 1))
Working: The line through (2, 3) and (1, 2) goes back to (0, 1). The line through (4, 3) and (2, 2) also goes back to (0, 1). The centre is (0, 1).
51Higher The point (3, 1) is reflected in the x-axis, and then the image is reflected in the y-axis. Write the final image. Type it like (2, 5).-3,-1 (also accept: (-3, -1))
Working: x-axis: (3, 1) goes to (3, −1). y-axis: (3, −1) goes to (−3, −1).
52Higher The point (4, 1) is translated by −2 3 , then enlarged by scale factor 2 about the origin. Write the final image, like (2, 5).4,8 (also accept: (4, 8))
Working: Translate: (4 − 2, 1 + 3) = (2, 4). Enlarge by 2: (4, 8).
53Higher A shape is reflected in the line y = 2 and then reflected in the line y = 5. Which single transformation does the same?A translation 6 up
Working: (0, 0) goes to (0, 4) in y = 2, then to (0, 6) in y = 5. That is 6 up. Two reflections in parallel lines make a translation of twice the distance between the lines.
54Higher The point (2, 1) is translated by 3 0 and then rotated 90° clockwise about the origin. Write the final image, like (2, 5). (The order matters: translate first.)1,-5 (also accept: (1, -5))
Working: Translate: (2 + 3, 1) = (5, 1). Rotate 90° clockwise: (x, y) → (y, −x) gives (1, −5).
55How many lines of symmetry does a regular pentagon have?5
Working: A regular pentagon has 5 sides, so it has 5 lines of symmetry.
56What is the order of rotational symmetry of a regular hexagon?6
Working: A regular hexagon has 6 sides, so it fits onto itself 6 ways in a full turn: order 6.
57Which shape has rotational symmetry of order 2 but no line of symmetry?Parallelogram
Working: A parallelogram fits onto itself after a half turn (order 2). Its diagonals are not lines of symmetry, so it has no line of symmetry.
58A regular octagon is turned about its centre until it fits onto itself. What is the smallest turn? Answer in degrees.45
Working: 360 ÷ 8 = 45, so the smallest turn is 45°.
59How many lines of symmetry does this kite have? [Figure: A kite shape on a grid]1
Working: Fold along the vertical line through (2, 0) and (2, 5): the two halves match. No other line works, so there is 1 line of symmetry.
60A decorator rolls a border pattern along a wall 3 m long. The motif repeats every 15 cm, by a translation along the wall. How many motifs fit along the wall? (1 m = 100 cm.) [Figure: A triangle and its image after a translation]20
Working: 3 m = 300 cm. 300 ÷ 15 = 20 motifs.
61Triangle ABC is mapped to A&prime;B&prime;C&prime; by a translation. Write the translation vector, top number first. Type it like (3, -2). [Figure: A triangle and its image]-5,3 (also accept: (-5, 3))
Working: A is (6, 1) and A&prime; is (1, 4). Across: 1 − 6 = −5. Up: 4 − 1 = 3. The vector is −5 3 , typed (-5, 3).
62The point A(2, 3) is reflected in a vertical mirror line to give A&prime;(8, 3). The mirror line is x = a. What is a?5
Working: (2 + 8) ÷ 2 = 5, so the mirror line is x = 5. Check: A is 3 left of it and A&prime; is 3 right of it.
63Triangle Q is an enlargement of triangle P. What is the scale factor? Type a fraction like 1/2, or a decimal. [Figure: A large triangle and a small one]1/2 (also accept: 0.5)
Working: The bottom side of P is 4 and of Q is 2. 2 ÷ 4 = 1/2. The scale factor is 1/2, a reduction.
64Which describes the single transformation that maps P onto Q? [Figure: A triangle and its image]Rotation, 90° clockwise, centre (0, 0)
Working: (4, 1) goes to (1, −4), which fits (x, y) → (y, −x): 90° clockwise about the origin.
65Triangle Q is an enlargement of triangle P. Write the coordinates of the centre of enlargement. Type them like (2, 5). [Figure: A triangle and its larger image]2,0 (also accept: (2, 0))
Working: The line through (4, 2) and (3, 1) reaches (2, 0). The line through (6, 2) and (4, 1) reaches (2, 0). The centre is (2, 0).
66The point P(2, 5) is mapped to (−2, 5) by a transformation. Which of these could be the transformation?Reflection in the y-axis
Working: Reflection in the y-axis sends (x, y) to (−x, y), so (2, 5) goes to (−2, 5). (A translation of (−4, 0) also does it for this one point. That is why we use a whole shape to describe a transformation.)
67Dan says: the point (1, 2) is reflected in the line x = 3, so the image is (4, 2). What went wrong?He added 3 to x instead of reflecting
Working: The point is 2 left of x = 3, so the image is 2 right of it: x = 5. The image is (5, 2).
68Eve says: rotating (2, 1) by 90° clockwise about the origin gives (−1, 2). What went wrong?She turned anticlockwise, not clockwise
Working: Clockwise: (x, y) → (y, −x), so (2, 1) goes to (1, −2). Eve’s (−1, 2) is what you get turning anticlockwise.
69Ida says: the point (3, 2) is enlarged by scale factor 2 about the centre (1, 1), so the image is (6, 4). What went wrong?She doubled from the origin, but the centre is (1, 1)
Working: The arm is (2, 1). Doubled: (4, 2). Add to the centre: (1 + 4, 1 + 2) = (5, 3).
70Fay says: a shape moves 2 squares left and 3 squares down, so the translation vector is 2 3 . What went wrong?Both numbers need minus signs
Working: Left 2 is −2 across. Down 3 is −3 up. The vector is −2 −3 .
71The point (−3, 4) is reflected in the x-axis. Write the image. Type it like (2, 5).-3,-4 (also accept: (-3, -4))
Working: The reflection changes the sign of y: (−3, −4).
72The point (2, −3) is rotated 90° anticlockwise about the origin. Write the image, like (2, 5).3,2 (also accept: (3, 2))
Working: (x, y) → (−y, x): (2, −3) goes to (3, 2). The image is (3, 2).
73The point (−2, 3) is enlarged by scale factor 2, centre (0, 0). Write the image, like (2, 5).-4,6 (also accept: (-4, 6))
Working: 2 × (−2) = −4 and 2 × 3 = 6. The image is (−4, 6).
74The point (3, 2) is translated by −1 −4 . Write the image, like (2, 5).2,-2 (also accept: (2, -2))
Working: x: 3 − 1 = 2. y: 2 − 4 = −2. The image is (2, −2).
75How many lines of symmetry does a square have?4
Working: A square has 2 lines through the middles of opposite sides and 2 diagonals: 4 lines of symmetry.
76The point (2, 3) is reflected in the line y = −1. Write the image. Type it like (2, 5).2,-5 (also accept: (2, -5))
Working: 3 is 4 above −1. The image is 4 below −1, which is −5. The image is (2, −5).
77A drone starts at (0, 0). It is translated by 6 −2 and then translated by 6 −2 again. Where does it finish? Type it like (2, 5).12,-4 (also accept: (12, -4))
Working: After one move: (6, −2). After two: (12, −4). The drone finishes at (12, −4).
78An electrician marks sockets on a wall plan, in cm. The first socket is at (30, 25). Each next socket is a translation of 45 0 from the one before. What is the position of the 4th socket? Type it like (2, 5).165,25 (also accept: (165, 25))
Working: x = 30 + 3 × 45 = 165. y stays 25. The 4th socket is at (165, 25).
79A plumber is fitting the bathrooms of two flats. On a plan in metres, the basin in flat A is at (1, 2). Flat B is the mirror image of flat A in the party wall, which is the line x = 5. Where is the basin in flat B? Type it like (2, 5).9,2 (also accept: (9, 2))
Working: The basin is 4 left of x = 5, so the image is 4 right: x = 9. The height stays 2. Flat B’s basin is at (9, 2).
80A carpenter draws a roof truss with an enlargement of scale factor 1/20. The drawing is 15 cm wide. How wide is the real truss? Answer in m.3
Working: 15 × 20 = 300 cm. In metres: 300 ÷ 100 = 3 m.
81A tiler lays a square tile with an arrow on it. Each time, she turns the tile 90° clockwise. How many turns does it take before the arrow points the same way as at the start?4
Working: 360 ÷ 90 = 4. After 4 quarter turns the arrow points the same way again.
82An electrician has a plan in metres. A light is at L(2, 3) in the first room. The same layout is used in the next room, by rotating the plan 180° about the point (4, 3). Where is the light in the next room? Type it like (2, 5).6,3 (also accept: (6, 3))
  1. M1 for the arm (−2, 0) from the centre
  2. M1 for reversing it to (2, 0) and adding to (4, 3)
  3. A1 for (6, 3)
Working: The arm from (4, 3) to (2, 3) is (−2, 0). A half turn reverses it to (2, 0). Add to the centre: (4 + 2, 3 + 0) = (6, 3).

83A paving pattern on a patio repeats by a translation of 0.6 m along the wall each time, one slab per repeat. The wall is 4.8 m long. Each slab costs £18.50. How much do the slabs cost? Give your answer in pounds to 2 decimal places, like 12.50.148.00 (also accept: 148)
  1. M1 for 4.8 ÷ 0.6
  2. M1 for 8 × 18.50
  3. A1 for 148.00
Working: 4.8 ÷ 0.6 = 8 slabs. Cost = 8 × 18.50 = £148.00.

84Triangle T is translated by −4 3 . Write the coordinates of C&prime;, the image of C. Type them like (2, 5). [Figure: Triangle T on a grid]1,6 (also accept: (1, 6))
  1. M1 for reading C as (5, 3) and adding the vector
  2. A1 for (1, 6)
Working: C is (5, 3). x: 5 − 4 = 1. y: 3 + 3 = 6. C&prime; is (1, 6).

85Describe fully the single transformation that maps triangle P onto triangle Q. [Figure: Triangles P and Q]Written answer: see the mark scheme
  1. B1 for rotation
  2. B1 for 180° (half turn)
  3. B1 for the centre (2, 2)
Working: It is a rotation of 180° about the centre (2, 2). The corner (1, 1) goes to (3, 3), and the midpoint of those is (2, 2). A half turn is the same clockwise or anticlockwise.

86Describe fully the single transformation that maps triangle P onto triangle Q. [Figure: Triangles P and Q]Written answer: see the mark scheme
  1. B1 for enlargement
  2. B1 for scale factor 2
  3. B1 for centre (1, 0)
Working: It is an enlargement with scale factor 2 and centre (1, 0). The base of P is 1 and the base of Q is 2. The line through (3, 2) and (2, 1) goes back to (1, 0), and so does the line through (5, 2) and (3, 1).

87Triangle T is rotated 90° anticlockwise about the origin. Write the coordinates of the image of the corner (4, 3). Type them like (2, 5). [Figure: Triangle T on a grid]-3,4 (also accept: (-3, 4))
  1. M1 for an anticlockwise quarter turn about the origin
  2. M1 for using (−y, x) with x = 4, y = 3
  3. A1 for (−3, 4)
Working: Use (x, y) → (−y, x). (4, 3) becomes (−3, 4), so the image is (−3, 4).
3
88A room is 4 m by 3 m. A plan of the room is an enlargement of the room with scale factor 1/50. What is the area of the room on the plan? Give your answer in cm².48
  1. M1 for changing to 400 cm and 300 cm (or 4 m and 3 m to cm)
  2. M1 for dividing a length by 50
  3. M1 for 8 × 6
  4. A1 for 48
Working: 4 m = 400 cm and 3 m = 300 cm. On the plan: 400 ÷ 50 = 8 cm and 300 ÷ 50 = 6 cm. Area = 8 × 6 = 48 cm².
4
89Higher [3 marks] The point P(2, 3) is reflected in the x-axis. The image is then rotated 90° clockwise about the origin. Write the coordinates of the final image. Type them like (2, 5).-3,-2 (also accept: (-3, -2))
  1. M1 for (2, −3) from the reflection
  2. M1 for using (y, −x) on it
  3. A1 for (−3, −2)
Working: Reflect in the x-axis: (2, 3) goes to (2, −3). Rotate 90° clockwise with (x, y) → (y, −x): (2, −3) goes to (−3, −2).
3
90Higher The point P(1, 4) is reflected in the line x = 2. The image is then reflected in the line x = 5. These two reflections have the same effect as one translation. Write the vector of that translation, top number first, like (3, -2). Try a second point to check your answer.6,0 (also accept: (6, 0))
Working: x = 2: (1, 4) goes to (3, 4). x = 5: (3, 4) goes to (7, 4). From (1, 4) to (7, 4) is 6 across and 0 up: the vector is 6 0 , typed (6, 0). Try (0, 0): it goes to (4, 0), then (6, 0). The mirror lines are 3 apart, and the shape moves twice that, 6.
91Higher The point (3, 5) is reflected in the line y = x. The image is reflected in the x-axis. That image is reflected in the line y = x again. Write the final point, like (2, 5). Think about which single reflection does the same job. The solution explains it.-3,5 (also accept: (-3, 5))
Working: y = x: (3, 5) goes to (5, 3). x-axis: (5, 3) goes to (5, −3). y = x: (5, −3) goes to (−3, 5). The final point is (−3, 5), the same as reflecting (3, 5) in the y-axis. Three reflections in these lines make a single reflection in the y-axis.
92Higher The point P(1, 1) is enlarged by scale factor 2 with centre (0, 0). The image is then enlarged by scale factor 1/2 with centre (4, 0). Write the final point, like (2, 5). Then think about which single transformation moves P to the final point. The solution explains it.3,1 (also accept: (3, 1))
Working: First: (1, 1) goes to (2, 2). Second: the arm from (4, 0) to (2, 2) is (−2, 2). Halved: (−1, 1). Add to the centre: (4 − 1, 0 + 1) = (3, 1). P moved from (1, 1) to (3, 1): 2 to the right. Try (0, 0): it goes to (0, 0), then the arm from (4, 0) is (−4, 0), halved (−2, 0), so (2, 0): also 2 to the right. The two enlargements together make a translation of 2 0 .
