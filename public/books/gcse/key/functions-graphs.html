    Answers for Functions and graphs
    No.QuestionAnswerMarks
    1Work out 3x² − 5 when x = −2.7
    Working: (−2)² = 4, so 3 × 4 = 12 and 12 − 5 = 7.
    2Solve x² − 5x + 6 = 0. Type your answer like 1 or 4.2 or 3 (also accept: 3 or 2)
    Working: (x − 2)(x − 3) = 0, so x = 2 or x = 3. Check: 2² − 10 + 6 = 0. ✓
    3The line y = 2x − 3 crosses the y-axis. What is the y-coordinate where it crosses?-3
    Working: On the y-axis x = 0, so y = 2 × 0 − 3 = −3.
    4Solve x² = 49. Give both answers, like 2 or −2.7 or -7 (also accept: -7 or 7)
    Working: 7 × 7 = 49 and (−7) × (−7) = 49, so x = 7 or x = −7.
    5f(x) = 5x − 3. Work out f(4).17
    Working: f(4) = 5 × 4 − 3 = 20 − 3 = 17.
    6f(x) = x² + 2. Work out f(−3).11
    Working: f(−3) = (−3)² + 2 = 9 + 2 = 11.
    7f(x) = 2x + 7. Find the value of x for which f(x) = 15.4
    Working: 2x + 7 = 15, so 2x = 8 and x = 4. Check: f(4) = 2 × 4 + 7 = 15. ✓
    8f(x) = 4x. What does f(3) mean?Put 3 in for x, so f(3) = 4 × 3 = 12
    Working: f(3) means “put 3 into the rule”: f(3) = 4 × 3 = 12.
    9g(x) = x² − 4. Find the values of x for which g(x) = 45. Type your answer like 2 or −2.7 or -7 (also accept: -7 or 7)
    Working: x² − 4 = 45, so x² = 49 and x = 7 or x = −7. Check: 49 − 4 = 45. ✓
    10A plumber charges C(h) = 55h + 30 pounds for a job of h hours. Work out C(3), in pounds.195
    Working: C(3) = 55 × 3 + 30 = 165 + 30 = 195. The job costs £195.
    11f(x) = x + 4 and g(x) = 3x. Work out fg(2).10
    Working: g(2) = 3 × 2 = 6. Then f(6) = 6 + 4 = 10. So fg(2) = 10.
    12f(x) = x + 4 and g(x) = 3x. Work out gf(2).18
    Working: f(2) = 2 + 4 = 6. Then g(6) = 3 × 6 = 18. So gf(2) = 18.
    13f(x) = 2x − 1 and g(x) = x². Write fg(x) in its simplest form. Type it like 3x^2 + 1.2x^2-1 (also accept: 2x²-1, fg(x)=2x^2-1)
    Working: g(x) = x². Put it into f: f(x²) = 2 × x² − 1 = 2x² − 1.
    14f(x) = 5x + 2. Work out f^−1(17).3
    Working: 5x + 2 = 17, so 5x = 15 and x = 3. Check: f(3) = 5 × 3 + 2 = 17. ✓
    15f(x) = 3x + 4. Find f^−1(x). Type it like (x + 2)/5.(x-4)/3 (also accept: (x-4)÷3, x/3-4/3, -4/3+x/3, f-1(x)=(x-4)/3, f^-1(x)=(x-4)/3, (-4+x)/3)
    Working: Let y = 3x + 4. Then y − 4 = 3x, so x = (y − 4) ÷ 3. The inverse is f^−1(x) = (x − 4)/3. Check: f(f^−1(x)) = 3 × (x − 4)/3 + 4 = x. ✓
    16f(x) = x + 1 and g(x) = 2x. Which statement is correct? [Figure: The graph of y = x squared minus 4x plus 3]fg(x) = 2x + 1 and gf(x) = 2x + 2
    Working: fg(x) = f(2x) = 2x + 1. gf(x) = g(x + 1) = 2(x + 1) = 2x + 2. They are different, so the order matters.
    17A table of values is made for y = x² − 4x + 3. Work out y when x = −1.8
    Working: y = (−1)² − 4 × (−1) + 3 = 1 + 4 + 3 = 8.
    18The graph shows y = x² − 6x + 5. Read off the roots (where it crosses the x-axis). Type them like 2 or 7. [Figure: A U-shaped curve]1 or 5 (also accept: 5 or 1)
    Working: The curve crosses the x-axis at x = 1 and x = 5. Check: 1 − 6 + 5 = 0 and 25 − 30 + 5 = 0. ✓
    19The same graph shows y = x² − 6x + 5. What is the equation of its line of symmetry? Type the number, like x = 4. [Figure: A U-shaped curve]3
    Working: Halfway between 1 and 5 is (1 + 5) ÷ 2 = 3, so the line of symmetry is x = 3.
    20Find the turning point of y = x² − 8x + 12. Type it like (2, 5).4,-4 (also accept: (4, -4))
    Working: x² − 8x + 12 = (x − 2)(x − 6), so the roots are 2 and 6. Halfway is x = 4. y = 16 − 32 + 12 = −4. The turning point is (4, −4).
    21Which equation matches this graph? [Figure: An upside-down U-shaped curve]y = 9 − x²
    Working: The curve is upside down, so x² is negative. It crosses the y-axis at 9 and the x-axis at ±3. For y = 9 − x²: x = 0 gives 9 and x = 3 gives 0. ✓
    22A ball is thrown up. Its height after t seconds is h = 20t − 5t² metres. It lands when h = 0, at t = 4. Use the symmetry of the curve to find the greatest height, in metres. [Figure: The graph of y = x cubed]20
    Working: Halfway between t = 0 and t = 4 is t = 2. h = 20 × 2 − 5 × 4 = 40 − 20 = 20. The greatest height is 20 m.
    23Which equation could give this curve? [Figure: A smooth S-shaped curve]y = x³
    Working: The curve goes down on the left and up on the right, through the origin: it is a cubic, y = x³. Check (2, 8): 2³ = 8. ✓
    24Which equation could give this curve? [Figure: A curve in two separate pieces]y = 1/x
    Working: Two pieces that get close to both axes without touching them: this is the reciprocal graph y = 1/x. You cannot divide by 0, so there is no point on the y-axis.
    25Which equation could give this curve? [Figure: A curve that climbs faster and faster]y = 2^x
    Working: The curve stays above the x-axis, crosses the y-axis at 1 and climbs faster and faster: this is an exponential graph, y = 2^x. Check: 2^0 = 1. ✓
    26Find y when x = −3 on the graph of y = x³.-27
    Working: (−3) × (−3) × (−3) = 9 × (−3) = −27.
    27Find y when x = 0.25 on the graph of y = 1/x.4
    Working: 1 ÷ 0.25 = 4. (There are 4 quarters in 1.)
    28Find y when x = −2 on the graph of y = 2^x. Give your answer as a fraction or a decimal.1/4 (also accept: 0.25)
    Working: 2^−2 = 1 ÷ 2² = 1/4 = 0.25. This matches the graph: just above the x-axis on the left.
    29Find y when x = 5 on the graph of y = 2^x. [Figure: Solving by drawing a line across]32
    Working: 2^5 = 2 × 2 × 2 × 2 × 2 = 32.
    30The graph shows y = x² − 4x + 3. Use it to solve x² − 4x + 3 = 0. Type your answer like 2 or 5. [Figure: A U-shaped curve with y from minus 2 to 8]1 or 3 (also accept: 3 or 1)
    Working: At y = 0 the curve crosses the x-axis at x = 1 and x = 3. Check: 1 − 4 + 3 = 0 and 9 − 12 + 3 = 0. ✓
    31Use the same graph to solve x² − 4x + 3 = 3. Type your answer like 2 or 5. [Figure: A U-shaped curve with y from minus 2 to 8]0 or 4 (also accept: 4 or 0)
    Working: The line y = 3 meets the curve at x = 0 and x = 4. Check: 0 − 0 + 3 = 3 and 16 − 16 + 3 = 3. ✓
    32Use the same graph to solve x² − 4x + 3 = −1. [Figure: A U-shaped curve with y from minus 2 to 8]2
    Working: The line y = −1 just touches the lowest point of the curve, at x = 2. There is one solution. Check: 4 − 8 + 3 = −1. ✓
    33Use the same graph. How many solutions does x² − 4x + 3 = −2 have? [Figure: A U-shaped curve with y from minus 2 to 8]0
    Working: The lowest point of the curve is at y = −1, which is above y = −2. The line y = −2 never meets the curve, so there are 0 solutions.
    34Use the same graph to solve x² − 4x + 3 = 8. Type your answer like 2 or 5. [Figure: A U-shaped curve with y from minus 2 to 8]-1 or 5 (also accept: 5 or -1)
    Working: The line y = 8 meets the curve at x = −1 and x = 5. Check: 1 + 4 + 3 = 8 and 25 − 20 + 3 = 8. ✓
    35The graph shows y = x² − 4x + 3 and the straight line y = x − 1. The two meet at two points. Write the x-coordinates of the points, like 2 or 5. [Figure: A curve and a straight line that cross twice]1 or 4 (also accept: 4 or 1)
    Working: They meet at (1, 0) and (4, 3), so the x-coordinates are 1 and 4. Check: the line gives 1 − 1 = 0 and 4 − 1 = 3, and the curve gives 1 − 4 + 3 = 0 and 16 − 16 + 3 = 3. ✓
    36The graph of y = f(x) has its lowest point at (2, −1). Write the lowest point of y = f(x) + 5. Type it like (3, 1).2,4 (also accept: (2, 4))
    Working: + 5 outside the brackets moves every point up by 5. The x-coordinate stays 2 and y becomes −1 + 5 = 4: (2, 4).
    37The graph of y = f(x) has its lowest point at (2, −1). Write the lowest point of y = f(x − 3). Type it like (3, 1).5,-1 (also accept: (5, -1))
    Working: f(x − 3) moves the graph 3 to the right. The y-coordinate stays −1 and x becomes 2 + 3 = 5: (5, −1).
    38The graph of y = f(x) has its lowest point at (2, −1). Write the lowest point of y = f(−x). Type it like (3, 1).-2,-1 (also accept: (-2, -1))
    Working: f(−x) is the reflection of y = f(x) in the y-axis. x changes sign and y stays the same: (−2, −1).
    39The graph of y = f(x) has its lowest point at (2, −1). Write the turning point of y = −f(x). Type it like (3, 1).2,1 (also accept: (2, 1))
    Working: −f(x) reflects the graph in the x-axis. y changes sign and x stays the same: (2, 1). It is now the highest point, because the curve is upside down.
    40Which describes how y = f(x + 2) compares with y = f(x)?2 units to the left
    Working: To get the same input as before, x + 2 must equal the old x, so x is 2 smaller. The graph moves 2 units to the left.
    41f(x) = x² − 4x + 3 has roots 1 and 3. Find the roots of y = f(x + 1). Type them like 2 or 5.0 or 2 (also accept: 2 or 0)
    Working: f(x + 1) = 0 when x + 1 = 1 or x + 1 = 3, so x = 0 or x = 2. The graph has moved 1 to the left. Check: f(0 + 1) = f(1) = 0 and f(2 + 1) = f(3) = 0. ✓
    42The dashed curve is y = f(x). The solid curve is a copy moved 1 square sideways. Which is the equation of the solid curve? [Figure: A graph and a moved copy]y = f(x + 1)
    Working: The solid curve is the dashed curve moved 1 to the left. Moving left by 1 is y = f(x + 1).
    43A parabola y = x² + bx + c crosses the x-axis at 2 and 5. Write its equation as y = x² + bx + c. Type it like y = x^2 + 3x − 4.x^2-7x+10 (also accept: x²-7x+10)
    Working: y = (x − 2)(x − 5) = x² − 5x − 2x + 10 = x² − 7x + 10. Check: at x = 0, y = 10, and 2 × 5 = 10. ✓
    44The graph is y = x² + bx + c. The marked points are on the x-axis and y-axis. Write its equation. Type it like y = x^2 + 3x − 4. [Figure: A U-shaped curve with three marked points]x^2-2x-3 (also accept: x²-2x-3)
    Working: The roots are −1 and 3, so y = (x + 1)(x − 3) = x² − 3x + x − 3 = x² − 2x − 3. Check the y-intercept: x = 0 gives −3, which matches the graph. ✓
    45A parabola y = x² + bx + c has its lowest point at (3, −4) and passes through (0, 5). It can be written y = (x − 3)² − 4. Multiply out to write it as y = x² + bx + c. Type it like y = x^2 + 3x − 4.x^2-6x+5 (also accept: x²-6x+5)
    Working: (x − 3)² = x² − 6x + 9. Take away 4: x² − 6x + 5. Check (0, 5): y = 5. ✓
    46The graph of y = k^x passes through the point (3, 8). Find the value of k.2
    Working: k^3 = 8, so k = 2 (since 2 × 2 × 2 = 8). The graph is y = 2^x.
    47A reciprocal graph has the equation y = a/x and passes through (4, 3). Find a.12
    Working: 3 = a ÷ 4, so a = 3 × 4 = 12. Check: 12 ÷ 4 = 3. ✓
    48Which equation has a graph that crosses the x-axis at 1 and −4?y = (x − 1)(x + 4)
    Working: x = 1 makes (x − 1) = 0 and x = −4 makes (x + 4) = 0. So y = (x − 1)(x + 4).
    49Which of these points is on the graph of y = x² − 4x + 3?(5, 8)
    Working: At x = 5: 25 − 20 + 3 = 8, so (5, 8) is on the graph. The others fail: x = 4 gives 3, x = 3 gives 0 and x = −1 gives 8.
    50Sam says: f(x) = x² − 1, so f(−2) = −4 − 1 = −5. What went wrong?(−2)² = 4, not −4, so the answer is 3
    Working: (−2)² = (−2) × (−2) = 4, so f(−2) = 4 − 1 = 3.
    51Mia says: the graph of y = f(x + 3) is the graph of y = f(x) moved 3 units to the right. What went wrong?f(x + 3) moves the graph 3 to the LEFT
    Working: f(x + 3) uses the old function at a value 3 bigger, so each point on the old graph is reached 3 sooner. The graph moves 3 units to the left.
    52Jo says: the graph of y = 1/x crosses the y-axis at (0, 1). What went wrong?You cannot divide by 0, so the graph never meets the y-axis
    Working: 1 ÷ 0 has no value, so there is no point on the graph with x = 0. The curve gets closer and closer to the y-axis but never touches it.
    53Kit says: f(x) = x + 1 and g(x) = 2x, so fg(3) = f(3) then g, which is g(4) = 8. What went wrong?fg(x) means do g first, then f
    Working: fg(3) = f(g(3)). g(3) = 6, then f(6) = 7. Kit did f first, which gives gf(3) = 8.
    54f(x) = 3x² − x. Work out f(2).10
    Working: f(2) = 3 × 2² − 2 = 3 × 4 − 2 = 12 − 2 = 10.
    55Find the turning point of y = x² − 10x + 16. Type it like (2, 5).5,-9 (also accept: (5, -9))
    Working: x² − 10x + 16 = (x − 2)(x − 8), so the roots are 2 and 8 and the axis of symmetry is x = 5. y = 25 − 50 + 16 = −9. The turning point is (5, −9).
    56f(x) = 2x − 5. Find x when f(x) = −9.-2
    Working: 2x − 5 = −9, so 2x = −4 and x = −2. Check: f(−2) = −4 − 5 = −9. ✓
    57Find y when x = 4 on the graph of y = 3^x.81
    Working: 3^4 = 3 × 3 × 3 × 3 = 81.
    58f(x) = x − 2 and g(x) = x². Work out fg(5).23
    Working: g(5) = 25. Then f(25) = 25 − 2 = 23.
    59f(x) = x² − 4x + 3. Use the idea that y = f(x) − 5 is the graph moved down 5. What is the y-intercept of y = f(x) − 5?-2
    Working: f(0) = 3, so the original graph crosses the y-axis at 3. Moving down 5 gives 3 − 5 = −2.
    60Solve x² + 2x − 8 = 0. Type your answer like 1 or 4.-4 or 2 (also accept: 2 or -4, 2,-4, -4,2)
    Working: (x + 4)(x − 2) = 0, so x = −4 or x = 2. Check: 16 − 8 − 8 = 0 and 4 + 4 − 8 = 0. ✓
    61The power lost as heat in a cable is P = 2.5I² watts, where I is the current in amps. Work out P when I = 4.40
    Working: P = 2.5 × 4² = 2.5 × 16 = 40. The cable loses 40 watts.
    62The same cable loses P = 2.5I² watts. It loses 250 watts. Find the current, in amps. (The current is positive.)10
    1. M1 for 2.5I² = 250 or I² = 100
    2. A1 for 10
    Working: 2.5I² = 250, so I² = 100 and I = 10 amps (positive).
    		2
    63A tank is filled by n identical pumps. The time in minutes is t = 120/n. Work out the time when n = 5.24
    Working: t = 120 ÷ 5 = 24 minutes.
    64The same tank is filled by n pumps in t = 120/n minutes. How many pumps are needed to fill it in 10 minutes?12
    Working: 10 = 120 ÷ n, so 10n = 120 and n = 12. Check: 120 ÷ 12 = 10 minutes. ✓
    65A carpenter has 40 m of fencing for a rectangular plot. If the width is x metres, the length is 20 − x and the area is A = x(20 − x) square metres. The area is 0 at x = 0 and x = 20. Use the symmetry of the curve to find the greatest area, in square metres.100
    1. M1 for roots of x(20 − x) = 0 at x = 0 and x = 20 (or the symmetry idea)
    2. M1 for x = 10
    3. A1 for 100
    Working: Halfway between 0 and 20 is x = 10. A = 10 × (20 − 10) = 10 × 10 = 100. The greatest area is 100 m², a 10 m by 10 m square.
    		3
    66A new van is worth £18,000 and loses value so that after t years it is worth V = 18000 × 0.8^t pounds. Work out its value after 2 years. Type it like 4200.11520
    1. M1 for 18000 × 0.8²
    2. A1 for 11520
    Working: 0.8² = 0.64, so V = 18000 × 0.64 = 11520. The van is worth £11,520.
    		2
    67Solve gf(x) = 13. Type your answers like 3 or −1.5.1.5 or -2.5 (also accept: -2.5 or 1.5, 3/2 or -5/2, -5/2 or 3/2)
    1. M1 for gf(x) = (2x + 1)² − 3
    2. M1 for (2x + 1)² = 16
    3. M1 for 2x + 1 = 4 or 2x + 1 = −4
    4. A1 for 1.5 and −2.5
    Working: gf(x) = g(2x + 1) = (2x + 1)² − 3. Set it equal to 13: (2x + 1)² = 16. So 2x + 1 = 4 or 2x + 1 = −4, giving x = 1.5 or x = −2.5. Check x = 1.5: f = 4, g(4) = 16 − 3 = 13. ✓
    		4
    68Find the value of x for which f^−1(x) = g(x).-3
    1. M1 for f^−1(x) = (x + 5)/2
    2. M1 for (x + 5)/2 = x + 4
    3. A1 for −3
    Working: f^−1(x) = (x + 5)/2. Set (x + 5)/2 = x + 4. Then x + 5 = 2x + 8, so x = −3. Check: f^−1(−3) = 2/2 = 1 and g(−3) = 1. ✓
    		3
    69The curve y = x² − 6x + 8 has a lowest point. Work out the y-coordinate of the lowest point.-1
    1. M1 for roots x = 2 and x = 4
    2. M1 for x = 3 (halfway)
    3. A1 for −1
    Working: x² − 6x + 8 = (x − 2)(x − 4), so the roots are 2 and 4. The lowest point is at x = 3. y = 9 − 18 + 8 = −1.
    		3
    70The graph of y = f(x) has its lowest point at (3, −5). Write the coordinates of the lowest point of y = f(x − 4) + 3. Type them like (2, 5).7,-2 (also accept: (7, -2))
    1. M1 for x-coordinate 3 + 4 = 7
    2. M1 for y-coordinate −5 + 3 = −2
    3. A1 for (7, −2)
    Working: f(x − 4) moves the graph 4 to the right, so the x-coordinate is 3 + 4 = 7. The + 3 moves it up, so the y-coordinate is −5 + 3 = −2. The lowest point is (7, −2).
    		3
    71Show that the graphs of y = x² − 4x + 3 and y = x − 1 meet at the points where x = 1 and x = 4.Written answer: see the mark scheme
    1. M1 for x² − 4x + 3 = x − 1 rearranged to x² − 5x + 4 = 0
    2. M1 for factorising to (x − 1)(x − 4) = 0
    3. C1 for x = 1 and x = 4, and stating the graphs meet there
    Working: The graphs meet where x² − 4x + 3 = x − 1. Rearrange: x² − 5x + 4 = 0. Factorise: (x − 1)(x − 4) = 0. So x = 1 or x = 4, as required. (The points are (1, 0) and (4, 3).)
    		3
    72f(x) = ax + 3, where a is a positive number. Given that f(f(x)) = 4x + 9, find a.2
    Working: f(f(x)) = a(ax + 3) + 3 = a²x + 3a + 3. Match 4x + 9: a² = 4 so a = 2 (positive). Check the numbers on their own: 3 × 2 + 3 = 9. ✓
    73A parabola y = x² + bx + c passes through (0, 5) and (6, 5). Use symmetry to find b.-6
    Working: Both points have y = 5, so the line of symmetry is halfway: x = 3. For y = x² + bx + c, the line of symmetry is x = −b ÷ 2. So −b ÷ 2 = 3 and b = −6. Check (6, 5): 36 − 36 + 5 = 5. ✓
    74Higher The graph of y = x² − 6x + 5 is reflected in the y-axis. Write the equation of the new graph as y = x² + bx + c. Type it like y = x^2 + 3x − 4.x^2+6x+5 (also accept: x²+6x+5)
    Working: Replace x with −x: (−x)² − 6(−x) + 5 = x² + 6x + 5. Check: the original roots 1 and 5 become −1 and −5, and (x + 1)(x + 5) = x² + 6x + 5. ✓
