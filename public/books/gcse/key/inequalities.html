    No.QuestionAnswerMarks
    1Which is bigger, −3 or −7? Type the bigger number.-3
    Working: −3 is to the right of −7 on the number line, so −3 is bigger.
    2Solve 3x − 5 = 10.5
    Working: 3x − 5 = 10. Add 5 to both sides: 3x = 15. Divide by 3: x = 5.
    3Solve 2x + 7 = 1.-3
    Working: 2x + 7 = 1. Subtract 7: 2x = −6. Divide by 2: x = −3.
    4Work out −12 ÷ −3.4
    Working: Two negatives make a positive: 12 ÷ 3 = 4, so −12 ÷ −3 = 4.
    5Which inequality means “x is at least 6”?x ≥ 6
    Working: At least 6 means 6 or more, so x ≥ 6.
    6A van’s maximum load is 1200 kg. Write an inequality for the load, w kg. Type it like w<=500.w<=1200 (also accept: w≤1200, 1200>=w, 1200≥w)
    Working: “Maximum” means up to and including 1200 kg: w ≤ 1200.
    7To go on a ride you must be at least 120 cm tall. Write an inequality for the height, h cm. Type it like h>=100.h>=120 (also accept: h≥120, 120<=h, 120≤h)
    Working: At least 120 cm means 120 or more, so h ≥ 120.
    8x < 4. Which number can x NOT be?4
    Working: x < 4 means x is smaller than 4. The number 4 is not smaller than 4, so x cannot be 4.
    9How many of the numbers 3, 5, 7, 5.5 and 4.9 make x ≥ 5 true? [Figure: The inequality x greater than 2 on a number line]3
    Working: 5 (allowed, because of the line under the sign), 7 and 5.5 are all 5 or more. 3 and 4.9 are less than 5. So 3 of the numbers work.
    10Write the inequality shown on the number line. Type it like x>3. [Figure: A number line to read]x>1 (also accept: 1<x)
    Working: Open circle at 1, so 1 is not allowed. The arrow points right, so x is bigger than 1: x > 1.
    11Write the inequality shown on the number line. Type it like x<=5. [Figure: A number line to read]x<=-2 (also accept: x≤-2, -2>=x, -2≥x)
    Working: Filled circle at −2, so −2 is allowed. The arrow points left, so x is −2 or smaller: x ≤ −2.
    12Write the inequality shown on the number line. Type it like x<5. [Figure: A number line to read]x<4 (also accept: 4>x)
    Working: Open circle at 4, so 4 is not allowed. The arrow points left: x < 4.
    13Mia shows x > 5 with a filled circle on 5. What is wrong?The circle should be open
    Working: x > 5 does not allow 5, so the circle must be open. A filled circle would mean x ≥ 5.
    14The number line shows the allowed values of x. Is 2 an allowed value? Type yes or no. [Figure: A number line to read]no
    Working: The circle on 2 is open, so 2 is not one of the allowed values. The answer is no.
    15x is an integer and 2 ≤ x < 7. List the values of x. Put commas between them, like 1,2,3.2,3,4,5,6 (also accept: 2, 3, 4, 5, 6)
    Working: 2 ≤ x allows 2. x < 7 leaves out 7. The values are 2, 3, 4, 5, 6.
    16x is an integer and −3 < x ≤ 2. List the values of x. Put commas between them.-2,-1,0,1,2 (also accept: -2, -1, 0, 1, 2)
    Working: −3 is not allowed and 2 is allowed. The values are −2, −1, 0, 1, 2.
    17x is an integer and x < 9. What is the largest possible value of x?8
    Working: 9 is not allowed, so the largest whole number is 8.
    18x is an integer and x > −4.5. What is the smallest possible value of x?-4
    Working: −4.5 is between −5 and −4. x must be bigger than −4.5, so the smallest whole number is −4.
    19How many integers x make −2 ≤ x ≤ 2 true?5
    Working: The values are −2, −1, 0, 1, 2. That is 5 whole numbers.
    20Solve x + 5 > 12. Type it like x>3.x>7 (also accept: 7<x)
    Working: Subtract 5 from both sides: x > 12 − 5, so x > 7.
    21Solve 3x ≤ 18. Type it like x<=4.x<=6 (also accept: x≤6, 6>=x, 6≥x)
    Working: Divide both sides by 3: x ≤ 18 ÷ 3, so x ≤ 6.
    22Solve 2x − 7 < 5.x<6 (also accept: 6>x)
    Working: Add 7 to both sides: 2x < 12. Divide by 2: x < 6. Check x = 5: 2 × 5 − 7 = 3, and 3 < 5.
    23Solve 5x + 4 ≥ 29.x>=5 (also accept: x≥5, 5<=x, 5≤x)
    Working: Subtract 4: 5x ≥ 25. Divide by 5: x ≥ 5.
    24Solve x/3 + 2 > 6.x>12 (also accept: 12<x)
    Working: Subtract 2: x/3 > 4. Multiply by 3: x > 12.
    25Solve 7x − 3 < 4x + 9. [Figure: The numbers 2 and 5, and their negatives, on a number line]x<4 (also accept: 4>x)
    Working: Subtract 4x: 3x − 3 < 9. Add 3: 3x < 12. Divide by 3: x < 4.
    26Solve −2x < 8.x>-4 (also accept: -4<x)
    Working: Divide both sides by −2 and reverse the sign: x > −4. Check x = 0: −2 × 0 = 0, and 0 < 8. It works.
    27Solve −5x ≥ 20.x<=-4 (also accept: x≤-4, -4>=x, -4≥x)
    Working: Divide both sides by −5 and reverse the sign: x ≤ −4. Check x = −5: (−5) × (−5) = 25, and 25 ≥ 20.
    28Solve 10 − x > 6.x<4 (also accept: 4>x)
    Working: Subtract 10: −x > −4. Multiply by −1 and reverse the sign: x < 4. Check x = 3: 10 − 3 = 7, and 7 > 6.
    29Which of these is NOT a solution of 4 − 2x ≥ 10?−1
    Working: −2x ≥ 6, so x ≤ −3. The number −1 is bigger than −3, so it is not a solution. Check: 4 − 2 × (−1) = 6, and 6 is not at least 10.
    30A water tank holds 500 litres. It then loses 15 litres every minute, so after t minutes it holds 500 − 15t litres. What is the largest whole number of minutes, t, for which the tank still holds at least 200 litres? [Figure: The numbers greater than 1 and at most 4]20
    Working: 500 − 15t ≥ 200. Subtract 500: −15t ≥ −300. Divide by −15 and reverse the sign: t ≤ 20. So the largest whole number of minutes is 20. Check: 500 − 15 × 20 = 200, which is at least 200.
    31Write the double inequality shown on the number line. Type it like 2<=x<5. [Figure: A number line to read]-1<=x<4 (also accept: -1≤x<4)
    Working: Left: filled circle on −1, so ≤. Right: open circle on 4, so <. The numbers between are −1 ≤ x < 4.
    32Solve 6 < 2x < 14.3<x<7
    Working: Divide all three parts by 2: 3 < x < 7.
    33Solve 5 ≤ 3x − 1 < 11.2<=x<4 (also accept: 2≤x<4)
    Working: Add 1: 6 ≤ 3x < 12. Divide by 3: 2 ≤ x < 4.
    34Solve −3 < 2x + 5 ≤ 9.-4<x<=2 (also accept: -4<x≤2)
    Working: Subtract 5: −8 < 2x ≤ 4. Divide by 2: −4 < x ≤ 2.
    35A carpenter cuts a 600 mm batten. The length, x mm, is allowed to be up to 2 mm too short or 2 mm too long. Write the allowed lengths as a double inequality. Type it like 5<=x<=9. [Figure: Forwards: an inequality to a solution on a number line]598<=x<=602 (also accept: 598≤x≤602)
    Working: Shortest: 600 − 2 = 598. Longest: 600 + 2 = 602. Both are allowed: 598 ≤ x ≤ 602.
    36The solution of 2x + 1 < k is x < 5. Find k.11
    Working: The boundary is x = 5. Put it in: 2 × 5 + 1 = 11, so k = 11. Check: 2x + 1 < 11 gives 2x < 10, so x < 5.
    37The solution of 4x − 3 ≥ k is x ≥ 2. Find k.5
    Working: The boundary is x = 2. Put it in: 4 × 2 − 3 = 5, so k = 5. Check: 4x − 3 ≥ 5 gives 4x ≥ 8, so x ≥ 2.
    38The inequality 3x + a < 10 has the solution x < 2. Find the number a.4
    Working: At the boundary x = 2: 3 × 2 + a = 10, so 6 + a = 10 and a = 4. Check: 3x + 4 < 10 gives 3x < 6, so x < 2.
    39Which inequality has the solution x ≥ 3?3x ≥ 9
    Working: 3x ≥ 9 gives x ≥ 3. The second gives x ≥ 2, and the third gives x ≤ 3.
    40Is x = 3 a solution of 4x − 5 > 7? Type yes or no. [Figure: The graph of y = x squared minus x minus 6]no
    Working: 4 × 3 − 5 = 7. Is 7 > 7? No, they are equal. So x = 3 is not a solution (it is the boundary, which > leaves out).
    41Higher Solve x² − 9 < 0. Type it like 1<x<5.-3<x<3
    Working: x² − 9 = (x − 3)(x + 3), so the critical values are −3 and 3. The U-shape is below the axis between them: −3 < x < 3.
    42Higher Solve x² − 3x − 4 > 0. Type it like x<2 or x>5.x<-1 or x>4 (also accept: x>4 or x<-1, x<-1,x>4)
    Working: x² − 3x − 4 = (x − 4)(x + 1). The critical values are 4 and −1. The U-shape is above the axis outside them: x < −1 or x > 4.
    43Higher The sketch shows y = x² − 4x − 5, which crosses the x-axis at the two points marked. Solve x² − 4x − 5 < 0. [Figure: A sketch of a U-shaped quadratic]-1<x<5
    Working: The curve crosses the x-axis at −1 and 5. It is below the axis between them, so −1 < x < 5.
    44Higher x is an integer and x² − x − 6 < 0. List the possible values of x.-1,0,1,2 (also accept: -1, 0, 1, 2)
    Working: (x − 3)(x + 2) < 0 gives −2 < x < 3. The whole numbers strictly between are −1, 0, 1, 2.
    45Higher Solve x² + 2x − 8 ≥ 0. Type it like x<=1 or x>=6.x<=-4 or x>=2 (also accept: x≤-4 or x≥2, x>=2 or x<=-4, x≥2 or x≤-4, x<=-4,x>=2, x≤-4,x≥2)
    Working: x² + 2x − 8 = (x + 4)(x − 2). The critical values are −4 and 2. On or above the axis is outside them, including the ends: x ≤ −4 or x ≥ 2.
    46Dan says: −2x > 6, so dividing by −2 gives x > −3. What went wrong?He did not reverse the sign when dividing by a negative
    Working: Dividing by −2 turns the sign round: x < −3. Check x = −5: (−2) × (−5) = 10, which is bigger than 6.
    47Eve says: x ≥ 4 is shown on a number line with an open circle on 4 and an arrow to the right. What went wrong?The circle should be filled, because 4 is allowed
    Working: x ≥ 4 allows 4 itself, so the circle should be filled.
    48Frank says: the integers with −2 ≤ x < 3 are −1, 0, 1, 2, 3. What went wrong?He left out −2 and included 3
    Working: −2 ≤ x allows −2. x < 3 leaves out 3. The correct list is −2, −1, 0, 1, 2.
    49Solve 4x − 9 ≤ 15.x<=6 (also accept: x≤6, 6>=x, 6≥x)
    Working: Add 9: 4x ≤ 24. Divide by 4: x ≤ 6.
    50Solve 12 − 3x < 0.x>4 (also accept: 4<x)
    Working: Subtract 12: −3x < −12. Divide by −3 and reverse the sign: x > 4. Check x = 5: 12 − 15 = −3, which is less than 0.
    51x is an integer and −1 < x ≤ 3. List the values of x. Put commas between them.0,1,2,3 (also accept: 0, 1, 2, 3)
    Working: −1 is left out and 3 is allowed: 0, 1, 2, 3.
    52The line y = 2x + 1 is a straight line graph. For what values of x is y > 9? Type it like x>1.x>4 (also accept: 4<x)
    Working: 2x + 1 > 9. Subtract 1: 2x > 8. Divide by 2: x > 4. Check x = 5: y = 11, which is bigger than 9.
    53Write “n is at most −2” as an inequality. Type it like n<=5.n<=-2 (also accept: n≤-2, -2>=n, -2≥n)
    Working: At most −2 means −2 or smaller: n ≤ −2.
    54A taxi costs £3 plus £2 for each mile. Zoe has £25. What is the greatest whole number of miles she can travel?11
    Working: 3 + 2m ≤ 25. Subtract 3: 2m ≤ 22. Divide by 2: m ≤ 11. So the greatest whole number is 11. Check: 3 + 2 × 11 = 25, which is allowed.
    55Solve 7 − 3x > 22. Type it like x<2.x<-5 (also accept: -5>x)
    1. M1 for −3x > 15 (subtracting 7 from both sides)
    2. M1 for dividing both sides by −3
    3. A1 for x < −5 (sign reversed)
    Working: Subtract 7: −3x > 15. Divide by −3 and reverse the sign: x < −5. Check x = −6: 7 − 3 × (−6) = 25, and 25 > 22.
    		3
    56n is an integer and −3 < 2n + 1 ≤ 9. List all the possible values of n. Put commas between them.-1,0,1,2,3,4 (also accept: -1, 0, 1, 2, 3, 4)
    1. M1 for subtracting 1 from all three parts: −4 < 2n ≤ 8
    2. M1 for dividing by 2: −2 < n ≤ 4
    3. A1 for −1, 0, 1, 2, 3, 4
    Working: Subtract 1: −4 < 2n ≤ 8. Divide by 2: −2 < n ≤ 4. The whole numbers are −1, 0, 1, 2, 3, 4.
    		3
    57A van can carry at most 1200 kg. The driver weighs 85 kg. Each box weighs 38 kg. What is the greatest number of boxes the van can carry with the driver?29
    1. M1 for 85 + 38n ≤ 1200
    2. M1 for 38n ≤ 1115
    3. M1 for n ≤ 29.3…
    4. A1 for 29
    Working: 85 + 38n ≤ 1200. Subtract 85: 38n ≤ 1115. Divide by 38: n ≤ 29.34…. The number of boxes must be a whole number, so the greatest is 29. Check: 85 + 38 × 29 = 1187, which is under 1200.
    		4
    58Solve 6x − 5 ≥ 2x + 11.x>=4 (also accept: x≥4, 4<=x, 4≤x)
    1. M1 for collecting the x terms: 6x − 2x ≥ 11 + 5 (or equivalent)
    2. M1 for 4x ≥ 16
    3. A1 for x ≥ 4
    Working: Subtract 2x: 4x − 5 ≥ 11. Add 5: 4x ≥ 16. Divide by 4: x ≥ 4. Check x = 4: both sides equal 19.
    		3
    59Higher Solve x² − x − 12 > 0. Type it like x<2 or x>5.x<-3 or x>4 (also accept: x>4 or x<-3, x<-3,x>4)
    1. M1 for factorising: (x − 4)(x + 3)
    2. M1 for critical values −3 and 4
    3. M1 for a U-shaped sketch, or “above the axis”, to pick the outside regions
    4. A1 for x < −3 or x > 4
    Working: x² − x − 12 = (x − 4)(x + 3), so the critical values are 4 and −3. The U-shape is above the axis outside them: x < −3 or x > 4.
    		4
    60Show that 3(2x − 1) > 4x + 7 has the solution x > 5.Written answer: see the mark scheme
    1. M1 for expanding: 6x − 3 > 4x + 7
    2. M1 for collecting terms: 2x > 10
    3. C1 for dividing by 2 and stating x > 5
    Working: 3(2x − 1) = 6x − 3, so 6x − 3 > 4x + 7. Subtract 4x: 2x − 3 > 7. Add 3: 2x > 10. Divide by 2: x > 5, as required.
    		3
    61Tom says: “If x > y, then x² > y².” Show that Tom is wrong.Written answer: see the mark scheme
    Working: Take x = 2 and y = −5. Then x > y, because 2 > −5. But x² = 4 and y² = 25, and 4 < 25. So the claim is false. (It works for positive numbers, but squaring a negative number makes it positive, so the order can change.)
    62A whole number n makes both 2n + 5 > 30 and 3n − 4 < 40 true. How many whole numbers n are possible?2
    Working: 2n + 5 > 30 gives 2n > 25, so n > 12.5. 3n − 4 < 40 gives 3n < 44, so n < 14.67…. The whole numbers in both are 13 and 14. That is 2 numbers.
    63Higher Find all the values of x for which x² > 3x. Type it like x<1 or x>2. (Careful: do not divide both sides by x.)x<0 or x>3 (also accept: x>3 or x<0, x<0,x>3)
    Working: x² − 3x > 0 gives x(x − 3) > 0. The critical values are 0 and 3. The U-shape is above the axis outside them: x < 0 or x > 3. (Dividing by x would lose the negative solutions and could flip the sign.)
    64An electrician buys cable clips for £0.12 each, plus a £4.50 delivery charge. Her total budget, including delivery, is £20. What is the greatest number of clips she can buy?129
    Working: 4.50 + 0.12n ≤ 20. Subtract 4.50: 0.12n ≤ 15.50. Divide by 0.12: n ≤ 129.16…. The greatest whole number is 129. Check: 0.12 × 129 + 4.50 = 19.98, under £20.
    65A plumber buys 22 mm copper pipe at £6.40 per metre, and fittings costing £12 in total. Her total budget is £100. What is the greatest whole number of metres of pipe she can buy?13
    Working: 6.40m + 12 ≤ 100. Subtract 12: 6.40m ≤ 88. Divide by 6.40: m ≤ 13.75. The greatest whole number is 13. Check: 6.40 × 13 + 12 = 95.20, under £100.
    66A pipe has to be 2.50 m long, with a tolerance of 5 mm either way. Write the allowed lengths, L mm, as a double inequality. Type it like 5<=L<=9.2495<=L<=2505 (also accept: 2495≤L≤2505)
    Working: 2.50 m = 2500 mm. Shortest: 2500 − 5 = 2495. Longest: 2500 + 5 = 2505. So 2495 ≤ L ≤ 2505.
    67A shelf bracket can support at most 40 kg. The shelf itself weighs 6.5 kg and each box of tiles weighs 4.2 kg. What is the greatest number of boxes of tiles that can be put on the shelf?7
    Working: 6.5 + 4.2n ≤ 40. Subtract 6.5: 4.2n ≤ 33.5. Divide by 4.2: n ≤ 7.97…. The greatest whole number is 7. Check: 6.5 + 4.2 × 7 = 35.9 kg, under 40 kg.
    68A circuit is protected by a 32 A breaker, so the total current must be at most 32 A. A kettle draws 13 A. Each other appliance draws 4.5 A. What is the greatest number of other appliances that can be on at the same time as the kettle?4
    1. M1 for 13 + 4.5n ≤ 32
    2. M1 for 4.5n ≤ 19, or n ≤ 4.2…
    3. A1 for 4
    Working: 13 + 4.5n ≤ 32. Subtract 13: 4.5n ≤ 19. Divide by 4.5: n ≤ 4.22…. The greatest whole number is 4. Check: 13 + 4.5 × 4 = 31 A, under 32 A.
    		3
    69A carpenter charges a £35 call-out fee plus £28 per hour. A customer’s budget is £150. What is the greatest whole number of hours the carpenter can work?4
    1. M1 for 35 + 28h ≤ 150
    2. M1 for 28h ≤ 115, or h ≤ 4.1…
    3. A1 for 4
    Working: 35 + 28h ≤ 150. Subtract 35: 28h ≤ 115. Divide by 28: h ≤ 4.107…. The greatest whole number of hours is 4. Check: 35 + 28 × 4 = £147, under £150.
    		3
