    Iteration

    Some equations cannot be solved with a neat rearrangement. Iteration is a different way: repeat a rule again and again, and each answer gets closer to the solution. Then you show that the solution really is where you say it is.

    Where you will use this: a loan balance month by month, savings that grow each year, a spreadsheet filling down a column, and any problem where you can check an answer but cannot get it by a formula.

    1. A rule you repeat

    Iteration means repeating a rule. You put a number in, get a number out, and then put that number back in.

    • The start is called x0 (say “x nought”).
    • The next numbers are x1, x2, x3 and so on.
    • The rule is written xn+1 = ... Here xn is any term, and xn+1 is the next term. This is an iterative formula.

    xn+1 = 2xn + 1, with x0 = 3

    Read it as: “the next term is twice this term, plus 1”.

    Worked example: the first terms

    Use xn+1 = 2xn + 1 with x0 = 3. Find x1, x2 and x3.

    1. x1 = 2 × 3 + 1 = 7.
    2. x2 = 2 × 7 + 1 = 15.
    3. x3 = 2 × 15 + 1 = 31.

    2. Terms that home in

    Some rules make the terms settle down towards one number. Try xn+1 = √(xn + 2) with x0 = 1.

    The terms are getting closer and closer to 2. We say the iteration converges to 2. Each term is a better estimate of the number it is heading for.

    Why it heads for 2

    If the terms settle at a number L, then xn and xn+1 are both L. So L must fit the rule: L = √(L + 2). Square both sides: L² = L + 2, so L² − L − 2 = 0. This factorises as (L − 2)(L + 1) = 0, so L = 2 (the other answer, −1, cannot be a square root).

    Key idea: the number the terms settle at is a solution of the equation you get by writing L in place of both xn and xn+1. That is how iteration solves equations.

    Not every rule homes in

    Look at xn+1 = 2xn + 1 from the last section: 3, 7, 15, 31, 63... The terms keep growing. They do not settle. That is called diverging.

    3. Showing a solution lies in an interval

    Iteration finds an approximate solution. But how do you know there is a solution near there? Use a change of sign.

    Write the equation as f(x) = 0. For x³ + x − 3 = 0, let f(x) = x³ + x − 3. A solution of the equation is a place where the graph of y = f(x) crosses the x-axis.

    • f(1) = 1 + 1 − 3 = −1. That is below the axis.
    • f(2) = 8 + 2 − 3 = 7. That is above the axis.

    The graph of f is a smooth curve with no gaps, and it is below the axis at x = 1 and above it at x = 2. So it must cross the axis somewhere between. That crossing is a solution (also called a root).

    Key idea: if f(a) and f(b) have different signs (one positive, one negative), and the graph of f has no gaps, then f(x) = 0 has a solution between a and b. Always write both values, say they have different signs, and state your conclusion.

    Narrowing down

    You can repeat the idea with smaller steps. f(1.2) = −0.072 is negative, and f(1.3) = 0.497 is positive. So the solution is between 1.2 and 1.3. The interval is shorter, so we know the solution better.

    Worked example: show there is a solution

    3. f(1) is negative and f(2) is positive. The sign changes, and f is continuous (no gaps or jumps), so there is a solution between 1 and 2.

    4. Making an iterative formula

    To solve an equation by iteration, rearrange it into the form x = (something with x in it). Then use that as the rule.

    Take x³ + x − 3 = 0.

    1. Get x³ on its own: x³ = 3 − x.
    2. Take the cube root of both sides: x = ∛(3 − x).
    3. Use it as a rule: xn+1 = ∛(3 − xn).

    Start with x0 = 1 and press = again and again:

    The first terms of xn+1 = ∛(3 − xn), starting at x0 = 1
    TermValue, 4 decimal places
    x01.0000
    x11.2599
    x21.2028
    x31.2158
    x41.2129
    x51.2135
    x61.2134

    The terms bounce from side to side but get closer each time. They are settling at about 1.2134.

    Key idea: if the terms settle at L, then L fits the rule: L = ∛(3 − L). Cube both sides: L³ = 3 − L, so L³ + L − 3 = 0. So L is a solution of the original equation. That is why the method works.

    The same equation can also be written x = 3 − x³. Try xn+1 = 3 − xn³ with x0 = 1.2: the terms are 1.272, 0.942, 2.164, -7.138, and then 366.7… They run away. That formula is correct algebra, but it does not home in. In an exam the question gives you the formula to use.

    5. Starting values, steps and accuracy

    How many iterations? Keep going until the terms agree to the accuracy you want. For 2 decimal places, that means two terms in a row which round to the same number.

    For xn+1 = ∛(3 − xn) from x0 = 1: x2 = 1.2027… (1.20), x3 = 1.2158… (1.22), x4 = 1.2128… (1.21), x5 = 1.2135… (1.21). The last two agree, so the answer looks like 1.21 to 2 decimal places.

    But agreeing is not proof. A slow sequence might agree for a while and then change. To be sure, use a change of sign either side of your answer.

    Proving an answer to a given accuracy

    Every number that rounds to 1.21 is between 1.205 and 1.215. So check f(1.205) and f(1.215) for f(x) = x³ + x − 3.

    • f(1.205) = −0.045 to 3 decimal places (negative).
    • f(1.215) = 0.009 to 3 decimal places (positive).

    The sign changes, so the solution is between 1.205 and 1.215. So it is 1.21 to 2 decimal places.

    Key idea: to prove a solution to n decimal places, test the number half a unit of the last place below your answer and half a unit above it. For 2 decimal places, that is 0.005 either side. A change of sign proves the answer.

    Starting values

    A start closer to the answer needs fewer steps. A start that is far away may take longer, but the same formula still usually works. A formula that runs away (like x = 3 − x³ before) does not work from any start close to the answer, so you have to choose a different rearrangement.

    f(1.205) = 1.205³ + 1.205 − 3 = -0.045 (negative). f(1.215) = 1.215³ + 1.215 − 3 = 0.009 (positive). The sign changes, so the solution lies between 1.205 and 1.215, which means it is 1.21 to 2 decimal places.

    • M1 for f(1.205) = −0.045 (or negative, with evidence)
    • M1 for f(1.215) = 0.009 (or positive, with evidence)
    • C1 for a change of sign, so the solution is between 1.205 and 1.215, so it is 1.21 to 2 decimal places

    Why it works

    • The settled value is a solution. If the terms settle at L, then feeding L into the rule gives L back. So L = f(L), and that is the equation you started from, rearranged.
    • A change of sign proves a solution. A smooth curve cannot get from below the axis to above it without crossing. That is why the graph must have no gaps.
    • Why some rearrangements run away. Each step turns a small error in xn into a new error in xn+1. For ∛(3 − x), an error of 0.01 shrinks to about 0.002. For 3 − x³, the same error grows to about 0.04. Shrinking errors home in. Growing errors run away.
    • Accuracy by testing either side. Every number that rounds to your answer lies within half a unit of the last decimal place. A sign change either side catches them all.

    Common traps

    • Rounding the terms before using them again. Keep every digit with Ans.
    • Missing brackets, such as typing Ans + 10 ÷ 3 when you mean (Ans + 10) ÷ 3.
    • Stopping when one term looks right, instead of when two in a row agree.
    • Testing the answer itself instead of the two numbers half a unit either side of it.
    • Using a change of sign when the graph has a gap, as 1 over x does.
    • Muddling xn (the current term) with xn+1 (the next one).
