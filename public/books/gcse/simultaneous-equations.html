Simultaneous equations

Two clues, two unknowns. Use both clues together to find both numbers, and then check the answer in both.

Where you will use this: working out two unknown prices from two receipts, or how many of each pipe fitting a plumber ordered from the total count and the total cost.

Words you need

Tap a teal word anywhere on the page to see this again.

Simultaneous equations
Two (or more) equations that are true at the same time. Their solution is where their graphs cross.
Elimination
A way to solve simultaneous equations. Add or subtract the two equations so that one letter disappears, leaving one equation with one unknown. You may need to multiply an equation first so the letter matches.
Substitute
Replace a letter with a number, then work out the answer.
Unknown (variable)
A letter standing for a number. It is called an unknown when you are trying to find it, and a variable when it can take many values.

Two numbers add up to 11. The bigger number is 3 more than the smaller number. What are the two numbers? Type the bigger first, then the smaller, with a comma and no brackets, like 9,2.

1. Two clues, two unknowns

Sections 1 to 6 are for Foundation and Higher. The section with the Higher chip goes a step further.

One Equation with two unknowns, such as x + y = 5, has lots of answers: (1, 4), (2, 3), (3, 2), (0, 5) and many more. A second clue narrows it down to just one pair.

Simultaneous equations are two equations that must both be true at the same time. To solve them, find the pair of values that makes both true.

Key idea: a solution has to work in both equations. A pair that fits only one is not a solution.

Try it: does x = 3, y = 2 make x + y = 5 true? Does it make x − y = 1 true?

Worked example: by trying pairs

Find x and y when x + y = 5 and x − y = 1.

  1. List pairs that add to 5: (1, 4), (2, 3), (3, 2), (4, 1).
  2. Work out x − y for each: −3, −1, 1, 3.
  3. Only (3, 2) gives 1. So x = 3 and y = 2.
  4. Check in both: 3 + 2 = 5 and 3 − 2 = 1.

Trying pairs works for small numbers, but it is slow. The next sections show a method that always works.

Typing answers: type x first, then y, with a comma and no brackets, like 4,1. A negative is typed as -2,5.

2. Elimination: add or subtract

Elimination means making one letter disappear so you are left with a single equation to solve. Look at the coefficients, the numbers in front of the letters. If a letter has the same number in front of it in both equations, subtract. If the numbers are the same size but opposite signs, add.

Label the equations (1) and (2). Take care with signs when you subtract.

Key idea: same signs, subtract. Different signs, add. This is about the letter you want to remove: +2y and +2y have the same sign, so subtract. +3y and −3y have different signs, so add.

Try it: to remove y from 2x + 4y = 10 and x + 4y = 6, do you add or subtract?

Worked example: subtract

Solve (1) 3x + 2y = 16 and (2) x + 2y = 8.

  1. Both have +2y, so subtract: (1) − (2).
  2. 3x − x = 2x, 2y − 2y = 0 and 16 − 8 = 8. So 2x = 8 and x = 4.
  3. Put x = 4 into (2): 4 + 2y = 8, so 2y = 4 and y = 2.
  4. Check in (1): 3 × 4 + 2 × 2 = 16. Check in (2): 4 + 2 × 2 = 8. Both work.

Worked example: add

Solve (1) 2x + 3y = 12 and (2) 4x − 3y = 6.

  1. +3y and −3y have different signs, so add: (1) + (2).
  2. 2x + 4x = 6x, 3y − 3y = 0 and 12 + 6 = 18. So 6x = 18 and x = 3.
  3. Put x = 3 into (1): 6 + 3y = 12, so 3y = 6 and y = 2.
  4. Check in (2): 4 × 3 − 3 × 2 = 6. Check in (1): 2 × 3 + 3 × 2 = 12. Both work.

Now you finish it

Solve (1) 5x + 2y = 21 and (2) 3x − 2y = 3.

  1. +2y and −2y have different signs, so add: 5x + 3x = 8x and 21 + 3 = ___.
  2. So 8x = ___ and x = ___.
  3. Put x into (1): 5 × x + 2y = 21 gives y = ___.
  4. Check in (2).
Check my answer

8x = 24, so x = 3. Then 15 + 2y = 21, so y = 3. Check (2): 9 − 6 = 3.

3. Elimination: multiply first

Sometimes no letter matches. Then multiply one equation, or both, so one letter has the same number in front in each. You must multiply every term, including the number on the right.

Key idea: multiplying a whole equation by a number keeps it true, just as doubling both pans of a balance keeps it level. Do it only to make the coefficients match, then add or subtract as before.

Worked example: multiply one equation

Solve (1) 2x + y = 7 and (2) 3x + 2y = 12.

  1. Multiply (1) by 2 so both have 2y: (3) 4x + 2y = 14.
  2. Both +2y, so subtract: (3) − (2) gives x = 2.
  3. Put x = 2 into (1): 4 + y = 7, so y = 3.
  4. Check in (2): 3 × 2 + 2 × 3 = 12.

Worked example: multiply both

Solve (1) 3x + 2y = 13 and (2) 2x + 5y = 16.

  1. To match the x terms, use 6x. Multiply (1) by 2: (3) 6x + 4y = 26. Multiply (2) by 3: (4) 6x + 15y = 48.
  2. Both +6x, so subtract: (4) − (3) gives 11y = 22, so y = 2.
  3. Put y = 2 into (1): 3x + 4 = 13, so x = 3.
  4. Check in (2): 2 × 3 + 5 × 2 = 16.

Now you finish it

Solve (1) 3x + y = 13 and (2) 5x + 2y = 22.

  1. Multiply (1) by 2: 6x + 2y = ___.
  2. Both +2y, so subtract (2) from it: x = ___.
  3. Put x into (1) to find y = ___.
  4. Check in (2).
Check my answer

6x + 2y = 26. Subtract (2): x = 4. Then 12 + y = 13, so y = 1. Check (2): 20 + 2 = 22.

4. Substitution

When one equation already says y = (something) or x = (something), you can replace that letter in the other equation. To Substitute is to swap one thing for another that is equal to it.

Key idea: if y = 2x + 1, then wherever you see y you may write 2x + 1. Keep brackets round it if it is being subtracted or multiplied.

Worked example

Solve (1) y = 2x + 1 and (2) 3x + y = 16.

  1. Replace y in (2) with 2x + 1: 3x + 2x + 1 = 16.
  2. Collect: 5x + 1 = 16, so 5x = 15 and x = 3.
  3. Put x = 3 into (1): y = 2 × 3 + 1 = 7.
  4. Check in (2): 3 × 3 + 7 = 16. Check in (1): 7 = 6 + 1.

Now you finish it

Solve (1) y = x + 3 and (2) 2x + y = 15.

  1. Replace y in (2): 2x + (x + 3) = 15.
  2. So 3x + 3 = 15 and 3x = ___, giving x = ___.
  3. Put x into (1) to find y = ___.
Check my answer

3x = 12, so x = 4. Then y = 4 + 3 = 7. Check (2): 8 + 7 = 15.

Both methods give the same answer. Choose elimination when both equations look like ax + by = c. Choose substitution when one letter is already on its own.

5. From words to equations

Many exam questions give you a story with two facts. Turn each fact into an equation.

  1. Say what each letter stands for, with its unit: let a be the price of an adult ticket in pounds.
  2. Write one equation for each fact.
  3. Solve them with elimination or substitution.
  4. Answer in words, with the unit, and check against the story.

Worked example

2 adult tickets and 3 child tickets cost £44. 1 adult ticket and 2 child tickets cost £26. Find the price of each ticket.

  1. Let a = the price of an adult ticket and c = the price of a child ticket, in pounds.
  2. (1) 2a + 3c = 44 and (2) a + 2c = 26.
  3. Multiply (2) by 2: (3) 2a + 4c = 52. Subtract (1): c = 8.
  4. Put c = 8 into (2): a + 16 = 26, so a = 10.
  5. Check in (1): 2 × 10 + 3 × 8 = 44. An adult ticket costs £10 and a child ticket costs £8.

Now you finish it

A plumber buys 3 elbow joints and 2 valves for £19, and 1 elbow joint and 2 valves for £13. Find the price of each. (The prices are made up for practice.)

  1. Let j = the price of an elbow joint and v = the price of a valve, in pounds.
  2. (1) 3j + 2v = 19 and (2) j + 2v = 13.
  3. Both +2v, so subtract (2) from (1): 2j = ___, so j = ___.
  4. Put j into (2) to find v = ___.
Check my answer

2j = 6, so j = £3. Then 3 + 2v = 13, so v = £5. Check (1): 9 + 10 = 19.

6. The graph picture

Each equation on its own has lots of pairs of values that fit it. Plot them all and you get a straight line. For two equations you get two lines. The pair that fits both is the point on both lines: where they cross.

That is why simultaneous equations of this kind have exactly one solution, most of the time. Here the lines cross at x = 4, y = 2, which you can check: 4 + 2 = 6 and 4 − 2 = 2.

Key idea: the lines are two clues drawn as pictures, and the crossing point is the answer to both. Algebra finds that point exactly, without drawing.

The lines meet at x = 3, y = 2. Check: 3 + 2 = 5 and 3 − 2 = 1. Answer: 3,2.

The point (1, 4) is on the line x + y = 5. Work out the value of x − y at (1, 4). Is (1, 4) also on the line x − y = 1?

  1. x = 1 and y = 4.
  2. Work out 1 − 4.
  • That is 4 − 1. Here it is x − y, which is 1 − 4.
  • That is 1 + 4. The question says subtract.

1 − 4 = −3, which is not 1. So (1, 4) is on the first line but not the second, so it is not where they cross.

Two straight lines cross at one point. What does that point tell you about their two equations?

  • It is the point where x and y are equal.
  • It is where each line meets the x-axis.
  • The values that make both true.
  1. Every point on a line fits that line's equation. What is special about a point on both lines?

A point on a line fits that line's equation. A point on both lines fits both equations, so its x and y are the solution.

7. Harder pairs Higher

Higher questions use the same methods with trickier set-up. The equations may not be written as ax + by = c, so rearrange them first. Both equations may need multiplying, with negatives. Answers may be fractions or decimals.

Key idea: tidy first. Get every equation into the form ax + by = c, with the letters on the left and the number on the right. Then choose your method.

Worked example

Solve (1) 2x = 3y + 1 and (2) 3x + 2y = 21.

  1. Rearrange (1): take 3y from both sides to get 2x − 3y = 1.
  2. Multiply (1) by 2: 4x − 6y = 2. Multiply (2) by 3: 9x + 6y = 63.
  3. −6y and +6y have different signs, so add: 13x = 65, so x = 5.
  4. Put x = 5 into 2x − 3y = 1: 10 − 3y = 1, so y = 3.
  5. Check in (2): 15 + 6 = 21.

Check your knowledge: harder pairs Higher

Type x first, then y, like 2,5. If an answer is a fraction, type it as a decimal or a fraction like 1/2.

Solve (1) 3x = 2y + 8 and (2) x + y = 6.

  1. Tidy (1) first: take 2y from both sides.
  2. You get 3x − 2y = 8. Now match the y terms: multiply (2) by 2.
  3. 2x + 2y = 12. Add it to 3x − 2y = 8.
  • You swapped x and y. Type x first.

Add: 5x = 20, so x = 4. Then 4 + y = 6, so y = 2. Check (1): 12 = 4 + 8. Answer: 4,2.

Solve (1) 2x − 3y = 13 and (2) 5x + 2y = 4. Type your answer like 5,-1.

  1. Neither letter matches. Choose y: 3y and 2y make 6y.
  2. Multiply (1) by 2 and (2) by 3.
  3. 4x − 6y = 26 and 15x + 6y = 12. The y terms have different signs.
  • Check (1): 4 − 9 = −5, not 13. From 5 × 2 + 2y = 4, y is −3.

Add: 19x = 38, so x = 2. Then 10 + 2y = 4, so y = −3. Check (1): 4 + 9 = 13. Answer: 2,-3.

Solve (1) 4x + y = 4 and (2) 2x + 3y = 7.

  1. Make the y terms match: multiply (1) by 3.
  2. That gives 12x + 3y = 12.
  3. Subtract (2) from it. The answer for x is not a whole number.
  • You swapped x and y. Type x first.

(1) × 3: 12x + 3y = 12. Subtract (2): 10x = 5, so x = 0.5. Then 2 + y = 4, so y = 2. Check (2): 1 + 6 = 7. Answer: 0.5,2.

A rectangle has a perimeter of 34 cm. Its length is 3 cm more than its width. How long is the rectangle, in cm?

  1. Let l be the length and w the width. Write two equations.
  2. 2l + 2w = 34 and l = w + 3. Replace l in the first equation.
  3. 2(w + 3) + 2w = 34. Multiply out the bracket.
  • That is the width. The question asks for the length.
  • That is l + w, half the perimeter. Find l on its own.

2w + 6 + 2w = 34, so 4w = 28 and w = 7. The length is l = 7 + 3 = 10 cm. Check: 2 × 10 + 2 × 7 = 34.

Flip it: run it backwards

You have been given equations and asked for the answer. Now run it the other way.

Forwards

Given x + y = 5 and x − y = 1, find x and y.

Eliminate or substitute.

Backwards

Given x = 3 and y = 2, check them in both equations, or build equations they solve.

Substitute into each equation.

Key idea: a solution must work in both equations. Checking in only one is not checking. If the pair fails either one, something went wrong.

Worked example: check a pair

Is x = 3, y = 2 a solution of 2x + y = 8 and x + 3y = 10?

  1. In 2x + y = 8: 2 × 3 + 2 = 8. It works.
  2. In x + 3y = 10: 3 + 3 × 2 = 9, and 9 is not 10. It fails.
  3. So it is not a solution of the pair, even though it fits the first equation.

Worked example: build a pair

Write two equations that have x = 2, y = 5 as their solution.

  1. Choose any combination of x and y. For example x + y: 2 + 5 = 7, so x + y = 7.
  2. Choose another. For example 3x − y: 6 − 5 = 1, so 3x − y = 1.
  3. Check: x = 2, y = 5 works in both. There are many correct answers.

Check your knowledge: flip it

A student says x = 4, y = 1 solves both 3x − y = 11 and x + 2y = 7. Is the student right?

  • Yes: it works in the first equation, 3x − y = 11, so it is a solution.
  • No: it fails the second equation.
  • Yes: both equations work.
  1. Test the pair in the first equation, then in the second.

3 × 4 − 1 = 11 works, but 4 + 2 × 1 = 6, not 7. A solution must work in both, so the student is wrong.

The pair x = 4, y = 1 solves x + y = 5 and also ax − y = 7. Find the number a.

  1. Put x = 4 and y = 1 into ax − y = 7.
  2. That gives 4a − 1 = 7. Solve it for a.
  • That is 4a = 8. a is a quarter of 8.
  • You took 1 away instead of adding it. From 4a − 1 = 7, add 1 to both sides.

4a − 1 = 7, so 4a = 8 and a = 2. Check: 2 × 4 − 1 = 7.

Which pair of equations has x = 2, y = 3 as its solution?

  • x + y = 5 and x − y = 5, a matching pair
  • x + y = 6 and x − y = −1, adding up to 6
  • x + y = 5 and 2x − y = 1
  1. Put x = 2 and y = 3 into each equation in turn.

2 + 3 = 5 and 2 × 2 − 3 = 1, so this pair works in both. The others each fail one.

x + y = 10 and x − y = 4. Add the two equations. You get 2x = a number. What is the number?

  1. Add the left sides: x + y + x − y.
  2. Add the right sides: 10 + 4.
  • That is 10 − 4. The y terms have opposite signs, so you add the equations.

x + x = 2x and y − y = 0, so 2x = 10 + 4 = 14. That gives x = 7, and then y = 3.

Solve x + y = 12 and x − y = 2, then check your answer in both equations. Type x first, then y.

Add: 2x = 14, so x = 7. Then 7 + y = 12, so y = 5. Check: 7 + 5 = 12 and 7 − 5 = 2. Answer: 7,5.

Tia says x = 5, y = 1 solves 3x + 2y = 17 and 2x + y = 9. Work out 2x + y for her numbers. Is she right?

Spot the mistake

Finding an error in someone else's working helps you learn. For each one, decide what went wrong.

Leo says: for 3x + 2y = 11 and x + 2y = 5, add the equations to get 4x + 4y = 16. What went wrong?

  • Adding keeps y. He should subtract.
  • He added 2y and 2y wrongly.
  • He should have multiplied the equations first.
  1. Elimination should remove a letter. Did adding remove x or y?

Both y terms are +2y, so subtract: 2x = 6, so x = 3. Then 3 + 2y = 5, so y = 1. Check: 9 + 2 = 11.

Zara says: for 2x + y = 9 and x − y = 3, adding gives 3x = 12, so x = 4. Then she writes y = 3 + 4 = 7. What went wrong?

  • She should have subtracted the equations.
  • y is 4 − 3 = 1, not 3 + 4.
  • x should be 12, not 4.
  1. Put x = 4 into x − y = 3. What must y be? Then check it in 2x + y = 9.

4 − y = 3 gives y = 1. Check: 2 × 4 + 1 = 9 and 4 − 1 = 3.

Ravi says: x = 4, y = 1 solves x + y = 5, so it must solve x + y = 5 and 2x − y = 6. What went wrong?

  • 4 + 1 is not 5.
  • The number 6 cannot be on the right.
  • He did not check equation two.
  1. A solution must work in both. Test the second equation.

Check your knowledge: mixed review

Mixed up on purpose, like a real paper. Work out which method fits. Type x first, then y, when there are two answers.

Solve 4x − 5 = 19.

  1. Undo the − 5 first.
  2. Add 5 to both sides, then divide by 4.
  • You took 5 away again. Undo a subtraction by adding.
  • That is 19 + 5. There is still the × 4 to undo.

4x = 19 + 5 = 24, so x = 6. Check: 4 × 6 − 5 = 19.

Solve x + y = 15 and x − y = 5.

  1. The y terms have opposite signs. Add.
  2. 2x = 20.
  • You swapped x and y. Type x first.

Add: 2x = 20, so x = 10. Then y = 15 − 10 = 5. Check: 10 − 5 = 5. Answer: 10,5.

Solve (1) 6x + y = 20 and (2) 2x + y = 8.

  1. Both equations have +y.
  2. Subtract (2) from (1).
  • You swapped x and y. Type x first.

(1) − (2): 4x = 12, so x = 3. Then 6 + y = 8, so y = 2. Check (1): 18 + 2 = 20. Answer: 3,2.

A plumber buys 3 lengths of 15 mm pipe and 2 lengths of 22 mm pipe for £37. She buys 2 lengths of 15 mm pipe and 1 length of 22 mm pipe for £21. How much is one length of 22 mm pipe, in pounds? (The prices are made up for practice.)

  1. Let a be the 15 mm price and b the 22 mm price. Write two equations.
  2. 3a + 2b = 37 and 2a + b = 21. Multiply the second by 2 to match the 2b.
  3. 4a + 2b = 42. Subtract the first equation.
  • That is the price of the 15 mm pipe. The question asks for 22 mm.

(2) × 2: 4a + 2b = 42. Subtract (1): a = 5. Then 10 + b = 21, so b = 11. A 22 mm length is £11. Check (1): 15 + 22 = 37.

Solve y = 3x and x + y = 20.

  1. y is already on its own. Substitute.
  2. Replace y in the second equation with 3x.
  • You swapped x and y. Type x first.

x + 3x = 20, so 4x = 20 and x = 5. Then y = 3 × 5 = 15. Check: 5 + 15 = 20. Answer: 5,15.

A shop hires out bikes for a day. 2 mountain bikes and 3 road bikes cost £96. 1 mountain bike and 2 road bikes cost £58. How much is one mountain bike for the day, in pounds? (The prices are made up for practice.)

  2. 2m + 3r = 96 and m + 2r = 58. Multiply the second by 2.
  3. 2m + 4r = 116. Subtract the first equation.
  • That is the price of a road bike. The question asks for a mountain bike.

(2) × 2: 2m + 4r = 116. Subtract (1): r = 20. Then m + 40 = 58, so m = 18. A mountain bike is £18. Check (1): 36 + 60 = 96.

  1. Swap in: 5 × 3 − 2 × (−2).
  2. 2 × (−2) = −4, and taking away −4 adds 4.

Why it works

  • Adding or subtracting equations is allowed. If two things are equal, adding equal amounts to both sides keeps them equal. Adding two equations adds equal amounts to both sides.
  • Multiplying a whole equation is allowed. It is the same balance idea: do the same to both sides, so every term, including the number on the right, must be multiplied.
  • Why check in both. Each equation is a separate clue. A pair that fits only one clue is on one line but not where the lines cross.
  • One solution. Two different straight lines that are not parallel cross at exactly one point, which is why most pairs have one answer.

Common traps

  • Adding when you should subtract, or the other way round, so the letter does not disappear.
  • Multiplying only one term of an equation, and forgetting the number on the right.
  • Losing a minus sign when subtracting, especially with a negative right-hand side.
  • Finding x, then forgetting to find y.
  • Checking the answer in one equation only.

Going further

Look at the two lines x + y = 5 and x + y = 7. How many pairs of numbers make both equations true?

  • Exactly one pair
  • None: the lines never meet.
  • As many as you like, because each equation has many pairs
  1. Can x + y be 5 and 7 at the same time?
  2. Look at the picture: do the lines ever meet?

The same x + y cannot equal both 5 and 7, so no pair works. On the graph the lines are parallel and never meet, so there is no solution.

Look at x + y = 5 and 2x + 2y = 10. How many pairs of numbers make both equations true?

  • Infinitely many: they are the same line.
  • None, because the numbers on the right are different
  • Exactly one pair
  1. Halve every term of 2x + 2y = 10. What do you get?

Dividing 2x + 2y = 10 by 2 gives x + y = 5. They are the same equation, so every pair that fits one fits the other. The lines lie on top of each other.

Two numbers x and y have sum S and difference D, so x + y = S and x − y = D. Make x the subject of a formula using S and D. Use brackets where you need them.

  1. Add the two equations to remove y.
  2. The left side becomes 2x. The right side becomes S + D.
  3. Divide both sides by 2.
  • That halves only D. Put brackets round S + D.
  • That is y, not x. Add the two equations to get x.

Add: 2x = S + D, so x = S + D over 2, typed (s+d)/2. For example, a sum of 20 and a difference of 6 gives x = 13 and y = 7.

x + y = 10 and x − y = 4. Without finding x or y, work out x² − y². Higher

  1. There is a factorising pattern: x² − y² = (x − y)(x + y).
  2. You are told both brackets.
  • That is 10 + 4. Multiply the two brackets instead.

x² − y² = (x − y)(x + y) = 4 × 10 = 40. Check with x = 7 and y = 3: 49 − 9 = 40.

Two numbers x and y have x + y = 7 and xy = 10. Without finding x and y first, work out x² + y².

  1. You know x + y and xy. Which square, made from x and y, mentions both x² + y² and xy when you expand it?
  2. Expand (x + y)². You get x² + y² plus another term.
  3. Put 7 in for x + y, and 10 in for xy, then rearrange to find x² + y².
  • That is (x + y)². It also contains the 2xy from expanding.
  • That takes xy away once. Expanding (x + y)² gives 2xy, so take it away twice.

(x + y)² = x² + 2xy + y², so 7² = x² + y² + 2 × 10. That gives 49 = x² + y² + 20, so x² + y² = 29. Check: the numbers are 2 and 5, and 4 + 25 = 29.
